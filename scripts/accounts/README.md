# 负责人账号开通与恢复

网站没有注册、认领负责人或自助找回接口。管理员名单、飞书 allowlist 和开发代登不会自动得到负责人权限。

部署人先核对现有账号的真实使用者，选定唯一负责人和登录名，再在受控服务器交互终端执行 `node scripts/accounts/owner-access.ts provision`。指定已有账号编号可保留其既有审计身份；不能建立第二位负责人。初始密码随机生成，只显示一次，15 分钟内单次登录有效，登录后仅能修改密码。

负责人忘记密码时使用预先登记、固定版本的云控制台恢复操作执行 `node scripts/accounts/owner-access.ts recover`。恢复会撤销该账号的所有会话、清除该账号登录限速、替换为一次性临时密码，并记录恢复依据和脱敏提醒；不清除来源限速或其他账号限制。此入口不要求负责人使用 SSH，但云控制台必须提供不记录终端输出的受控交互模式，不得把临时密码送入任务输出日志。没有这种模式时保持关闭，由已授权部署人通过安全交互终端交付。

这里仅交付代码；尚未绑定真实负责人、登记腾讯云操作或修改生产账号。部署阶段须验证确切身份映射与恢复操作可用。每季度用隔离账号演练，留下执行日期、脚本版本、会话撤销和临时密码失效结果，记录中不含密码。

账号上限默认100。服务器配置表 identity.account_policy 可由受控部署操作调整，不提供普通管理员修改入口。停用账号仍计数，登录名和审计记录保留。
