# 法规阅读扩展

module声明既有法规列表、正文、历史版本、政策脉络及报告页面，保留全部地址和route ID；web提供原位置的桌面/手机入口及按页加载的法规收藏列表。公开页面只经HTTP读取现有内容，保留SSR首批正文、修订/撤回核验和部分完整性提示。

本轮不扩建法规业务、不接新模型。采集与模型处理随最终统一发布暂停，入口和已发布阅读保留。server注册法规公开读取接口、既有处理队列及三个定时任务，队列名/重试/并发/出刊节奏保留；国家地区查询留在通用站点入口，继续服务新闻筛选。模块队列通过统一worker注册器校验名称后安装，运行时仍执行原有暂停/许可/版本校验。read、reports、language与relations拥有法规公开列表/详情/正文/版本/报告、语言选择与关系投影的实际实现，旧publication入口只兼容转发。domain拥有原始资料采集、正文提取、版本、解读、证据与处理状态；provider、jobs和publication拥有既有模型适配、任务及发布/报告实现。处理状态直接从本模块读取，相关新闻经引擎具名只读入口取得；许可、现行修订和公开完整性仍在每次读取时核验。旧核心路径仅保留已登记消费者需要的兼容转发，模型设置、告警和恢复等共享消费者的扩展挂口仍待收敛。

目录新增或变化材料经on.materialDiscovered在同一事务交接，本模块使用实际policy.acquire队列定义与原directory单例键安排后续处理；重复任务视为已接收，无模块接收或入队失败不能提交材料应用结果。定时、手工收集与最终暂停规则保持。
