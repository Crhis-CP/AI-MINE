# 金属价格扩展

server入口注册原有metals.prices定时任务及/api/site/metal-prices读取接口。站点安装清单决定是否提供扩展；任务名称、半小时频率、停机补跑和原有HTTP缓存规则保留。COLLECT_ENABLED=false时不注册刷新任务。导入定义和读取价格都不触发取价或模型调用。

backend目录拥有来源适配、PDF/工作簿解析、期次与单位校验、存储、刷新和公开读取实现。对外仅提供read、refresh、diagnostics与registry入口；来源适配器和存储细节留在内部。数据仍使用既有publication.metal_prices表，来源ID、期间、单位和币种不变。

价格涨跌以同一品种最近已存的有效上一期为基期，允许跨越官方停发或未收录期次；页面逐行注明实际比较期，不把跨期比较称作相邻环比。单位、币种与换算汇率的资格检查继续生效，最近基期不兼容时留空，不跳过损坏记录借更早价格比较。NBS采集初始化仍只取最新一期，不因读端比较扩大历史回填。

web/prices.tsx拥有原/metals页面，模块声明保持旧路由ID；web入口提供桌面及手机菜单，站点分别安装地址、浏览器与服务端定义。页面只经公开api-client读取数据，核心web仅提供具名展示与服务端HTTP辅助入口。核心旧价格后端入口目前保留兼容转发，部分运维展示继续调用既有地址；运维挂口的归属继续迁移。公开读取沿用只读事务、当前网站官方链接和权限控制，不依靠源码路径变化绕过SQL归属检查。

网页扩展通过tabs声明金属价格的手机底部入口，通用网页据实际模块声明组装并高亮；侧栏、/more内入口与/metals原地址保留。

TASK-0384：延迟逐报价实际有效期计算，同来源任一已有报价超期时来源标为延迟，各期次提示仍独立计算。没有报价的品种保持空态，单位/币种和上一有效期的比较规则不变。

Cochilco原始发布版本保留文件摘要用于同一期修订辨识；公开价格出处仅显示可读发布日期与标题，不把文件摘要拼进读者文案。

TASK-0429/0431：现有notes出口列出各启用来源的发布节奏和最近一次完成检查的时间/结果。publication.metal_price_checks仅保存四个公开安全字段，由原刷新任务写入；即使来源版本未变、不重读工作簿，也记录真实成功检查。未产生新记录时诚实显示未知，预览不写记录。原报价所属期、单位、币种及私有fetched_at保持；页面请求不采集、不写入，也不把响应生成时刻当作检查时间。

TASK0437：价格抓取记录和页面诊断从通用引擎迁入backend/alerts，经server模块alerts插口唯一注册；原告警键、时段、期次和恢复语义保持。引擎仅负责聚合与发送，不重复执行金属检查。
