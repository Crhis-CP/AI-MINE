# 站点管理扩展

module声明账号、我的账号、网站资料和来源对账页面，保留旧地址及路由ID；web定义私有菜单。站点通过modules/admin清单安装后台菜单，公开构建不会引入这些菜单或私有客户端。

web/admin拥有页面和来源对账、覆盖组件。它们只通过HTTP客户端访问已有接口，共用引擎表单、操作原因、CSRF和幂等提交。强制改密、会话撤权、owner与模型管理权限仍由引擎鉴权执行。

server.admin.http注册网站资料和来源对账/覆盖接口，仅进入统一API或过渡私有API，旧公开API不注册这些接口。鉴权HTTP包装来自引擎具名入口，information拥有网站资料默认值、公开读取、owner校验、并发修订和幂等保存；原核心路径仅兼容转发。来源对账存储实现仍由核心兼容提供，继续迁移实际数据归属。迁移不修改账号、来源、网站资料或人工审计记录。
