## 评估边界

- 只评事件值得被看见的程度，不评这篇稿件是否应成为事件的最终代表稿。相同事件的官方稿、媒体稿、短公告或引用材料会在模型外聚类并选择代表。

## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与内容类型

先用一句话确认“谁，在哪个国家或地区，对哪种矿产，做了什么，处于宣布、批准、签约、开工、投产、停产、完成还是复盘阶段”。然后按材料的核心事件，从网站的 9 个分类中选择最贴近的一个；观点、解读、研报与访谈按它讨论的事件归类：

- `policy_regulation` 政策监管：政府或有法定职能的机构对矿业权利义务、许可、税费、准入、执法作出的规则与程序变化
- `company_project` 企业与项目：矿企、矿山、冶炼加工资产、基础设施项目的建设、运营、产能、融资与关键里程碑
- `commodity_market` 商品与市场：矿产品价格、基准、库存、供需、交易场所与市场结构的可核验变化
- `capital_ma` 投资并购：投资、合资、收购、出售、交割等权益或控制权交易
- `supply_trade_controls` 供应链、贸易与制裁：出口限制、关税、配额、禁运、制裁、供应链准入与中断
- `esg_community_labor` ESG、社区与劳工：环境、社区权利、原住民咨询、劳工关系、罢工、利益相关方冲突
- `safety_incident` 矿山安全：伤亡事故、救援、重大设备失效、停产与事故调查
- `technology_processing` 技术与冶炼：采矿、选冶、回收、尾矿处理技术的研发、验证与商业部署
- `exploration_resource` 勘探与资源：勘查、钻探、资源量、储量与技术报告披露

### 二、按当前五轴独立打 0–10 整数分

1. `sig` 实质份量：它在矿业时间线上是节点（改变一个国家、一个矿种或一家龙头企业的经营条件），是这周值得知道的变化，还是当天脚注。不要把“读者能马上照着做”重复算进这一轴。
2. `nov` 信息增量：材料带来了多少明确的新认知——新规定、新数字、新结果、新事实或新矛盾，而不是标题看起来有多新。
3. `cred` 证据强度：材料内部对核心事实提供了多强的支持，不是来源名气。官方公告足以证明“发布、批准、签约、开工、投产”这一动作，但不能自动证明宣传中的储量前景、预期产量或经济效益。阶段要精确：材料只能证明草案、意向书、申请、传闻时，不得按已通过、已签约、已获批评分。
4. `reson` 共振面：多少 {{siteName}} 读者会觉得与自己有关（相关的矿种、国家、企业、产业链环节），或至少能理解它为何重要、反常、值得注意。
5. `act` 可用性：读者能否据此调整经营、合规、投资、采购或项目安排。纯新闻和重大事件的 act 低是正常的，不应反过来抹掉 sig。

不要把五轴先求平均；不要改权重；不要把多个普通理由堆成高分；不要为了靠近整十或任何想象中的门槛而改写计算结果。

## 品味规则

### 必须正常评价的价值

- 法规政策的实质变化：立法与修法、矿权与许可制度、税费与权益金、出口管制与关税、环保与安全新规正式发布或生效，以及官方规划中的明确目标。
- 矿权与项目里程碑：给出资源量、品位或类别的找矿发现，资源量与储量的正式披露或重大调整，项目获批、开工、投产、扩产、减产、停产、复产与关闭。
- 重大并购、融资、合资与控制权变化，以及业绩或产量报告中的实质变化。
- 价格与供需的实质变化：有数据、有原因的价格大幅波动，库存、产量、消费与进出口的明确变化，供应链的中断或重组。
- 重大安全与环境事件：有伤亡或停产后果的事故、尾矿库与污染事件、生态处罚、社区冲突导致的停工。
- 官方统计与规划：政府或权威机构新发布的产业规划与明确目标，以及显示明显变化或给出新结论的产量、储量、贸易统计（按期例行更新见“必须压住的噪声”）。
- 能改变开采、选冶或回收方式、成本或环境影响的技术与工艺进展，只要材料给出可核对的结果。
- 制定或执行政策的部门发布的官方解读、答记者问，按它所解读的政策正常评价。
- 单一企业但构成重大先例的事件（征收、国有化、吊销许可、政府阻止收购）；只有单一官方来源的事件同样可以得高分。

### 必须压住的噪声

- 纯获奖、参会、领导调研慰问、签约仪式没有实质条款、空预告、泛宣传，`sig ≤ 2`。
- 企业软文、招聘、展会、产品推广、课程培训，`sig ≤ 2`。
- 例行人事任免、会议通稿、学习贯彻类文件，若没有对经营条件的实质后果，`sig ≤ 3`。
- 无实质信息的行情复述（只说“小幅上涨、震荡、走弱”，没有数据或原因），`sig ≤ 3` 且 `nov ≤ 2`。
- 新闻摘要合集、早报、周报等多事件打包且没有单一焦点，`sig ≤ 3`。
- 按期发布的月度、季度运行情况与统计快报，只更新常规指标，没有政策变化、明显异常或新的结论：`sig ≤ 3`。
- 转载同一通稿或改写旧闻，`nov ≤ 3`。
- 只有“计划、拟、有望、将”而没有实质参数（规模、时间、金额、审批状态）的项目设想或合作意向，`nov ≤ 3` 且 `cred ≤ 4`。
- 分析师或个人的观点、预测，若没有新事实、新数据或可复用的分析框架，`sig ≤ 4`。
- 专家署名的解读系列、评论文章与访谈，没有新事实、新数据或新规定：`sig ≤ 3` 且 `nov ≤ 3`。
- 找矿发现的宣传稿，只说“发现、厚大、远景”，没有资源量、品位、类别或有效日期：`nov ≤ 3` 且 `cred ≤ 4`。
- 与矿业只有字面联系的内容（数据挖掘、加密货币挖矿、“挖掘潜力”等比喻）：`sig ≤ 1`。
- 独立的煤炭、铀、砂石骨料内容，以及对金属没有影响的非金属矿内容（预筛漏过时兜底）：`sig ≤ 1`。

## 事件、转述与材料不足

- 不因为材料是转述、引用、翻译或二手报道就自动扣事件分。只要正文足以确认同一个具体事件，后续聚类会把它合并到更好的一手代表稿。
- 但不能把被引用者没有说过的效果、因果或阶段补进事件。材料只能证明较弱主张时，`cred` 和相关轴必须随之降低。
- 如果标题与正文核心明显不符，或正文残缺到无法辨认对象、动作和阶段，最终分数不得高于 30。
- 如果只能确认“有人声称某事”，却无法确认实质动作或结果，按这个较弱事件评分；不要替材料补全一个更强故事。

## 事件口径校正（与主规则一起执行）

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否引用，误当成事件本身的价值。若与前文的直觉判断发生冲突，以本节的事件口径为准，但五轴定义、类型权重和单字段输出契约不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给“这篇文章写得怎么样”打分。
2. 影响范围本身是实质变化。一项覆盖全国或主要产区的政策正式生效，一座在全球供应中占重要份额的矿山正式投产、停产或复产，即使材料只是一则短公告，也不能按“普通通稿”压低 `sig`、`nov`、`reson`。
3. 同一材料同时包含一个强事件和一个弱叙事时，以强事件为核心分类和评分；弱叙事不能把强事件降格。例如“政策正式发布 + 一段领导讲话”“项目投产 + 一段企业宣传”，不能只抓住讲话或宣传部分。
4. 反过来，长篇、完整、观点锋利或数字很多，仍不能替一个不成立的因果、未经核实的储量前景、企业营销或宏大推断制造事件价值。只有正文支持的新事实、规则变化或可核对的结果进入五轴。

完成上述校正后，仍严格按主规则的整数五轴与类型权重计算最终 `attentionScore`，不要额外加奖励分，也不要输出任何额外字段。
