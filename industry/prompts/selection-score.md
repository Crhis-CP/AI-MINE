## 评估边界

- 只评事件值得被看见的程度，不评这篇稿件是否应成为事件的最终代表稿。相同事件的官方稿、媒体稿、短公告或引用材料会在模型外聚类并选择代表。

## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与内容类型

先用一句话确认“谁，在什么时候，做了什么，处于宣布、申请、获批、开工、投产、停产、复产、生效还是调查结论阶段”。然后从以下 9 类中选择最贴近的一类。观点、解读、研报和访谈不单列，归到它所讨论的那一类事件。

- `policy_regulation`：政策监管。立法、许可、税费、环保与安全新规，含草案、征求意见、生效、废止。
- `company_project`：企业与项目。矿权、开工、投产、停产、复产、产量与重大合同。
- `commodity_market`：商品与市场。价格、库存、供需和官方统计。
- `capital_ma`：投资并购。并购、融资、重组，以及已写清阶段的交易。
- `supply_trade_controls`：供应链、贸易与制裁。贸易流向、关税、出口管制与供应中断。
- `esg_community_labor`：ESG、社区与劳工。社区冲突、劳工与环保社会责任事件。
- `safety_incident`：矿山安全。事故、伤亡、泄漏和调查结论。
- `technology_processing`：技术与冶炼。选冶、设备与已有放大验证的工艺进展。
- `exploration_resource`：勘探与资源。资源量、储量、品位和勘探成果。

### 二、按当前五轴独立打 0–10 整数分

1. `sig` 实质份量：它在金属矿业时间线上是节点、这周值得知道的变化，还是当天脚注。不要把“读者能马上据此行动”重复算进这一轴。
2. `nov` 信息增量：材料带来了多少明确的新认知，而不是标题看起来有多新。具体新事实、新数字、新阶段或新矛盾才是增量。
3. `cred` 证据强度：材料内部对核心事实提供了多强的支持，不是来源名气。官方文书足以证明“发布、批准、施行”这一动作，但不能自动证明宣传中的效果。材料只能证明草案、意向书、申请或传闻时，不得按已通过、已签约、已获批评。
4. `reson` 共振面：事件实际影响哪些矿业经营角色、项目或产业链环节，相关读者能否理解其重要性。按具体影响范围评价，不把国家大小、全球媒体热度或跨国传播当作分数前提；只影响一国的实质规则、关键项目或经营风险也可具有明确价值，但不得把当地关联本身当作加分。
5. `act` 可用性：读者是否能据此调整经营、合规或投资动作。纯新闻和重大事件的 act 低是正常的，不应反过来抹掉 sig。

## 品味规则

### 必须正常评价的价值

- 法规与监管的实质变化：立法、许可、税费、出口管制、环保与安全新规，含草案进入关键阶段、生效、废止、过渡期。官方文书足以证明“发布、批准、施行”，但不能自动证明宣传效果；草案和征求意见稿不得按已通过评分。
- 矿权与项目里程碑：获批、开工、投产、停产、复产。材料只能证明申请、意向书时，不得按已获批、已签约、已投产评分。
- 重大并购与融资：交易阶段与金额口径写清。传闻、意向书、协议、审批、交割分开评。
- 资源量与储量披露：按披露标准、类别、品位与有效日期评。推断、控制、探明资源量，以及可信、证实储量，不得互相替代。
- 价格与供需的实质变化：有基准、单位、时间窗才算实质。
- 重大安全与环境事件：已确认的伤亡和调查结论按真实份量评。初报与确认分开，未证实的伤亡和原因不得按已确认评分。
- 官方统计与规划：有基准、单位、时间窗。官方来源足以证明“发布”这一动作。

### 必须压住的噪声

- 独立的煤、铀、砂石内容，以及对金属没有影响的非金属矿内容，`sig ≤ 1`。
- 纯获奖、参会、泛宣传、招聘与活动推广，`sig ≤ 2`。
- 例行人事、例行许可延期、会议通稿，以及按期例行的运行通报，没有新的决定或后续动作，`sig ≤ 3`。 只延续原有条件、未产生新的经营约束、关键里程碑或实质风险的手续性延期仍属例行；期限日期改变本身不构成实质后果。确有批准、限制、撤销、暂停或附条件延长等决定，且材料说明具体对象与实质影响时，应按该决定本身评价；不得因为标题使用“延期”“公告”“会议”就自动按例行事项处理。申请或建议不得写成批准。
- 多事件打包而没有单一焦点的汇总稿，`sig ≤ 3`。
- 只报涨跌、没有基准、单位或时间窗的行情复述，`sig ≤ 3`。
- 没有新增事实、数字、角度或引文的转载同稿，`sig ≤ 3`。第一次报道该事件的稿件不受这一条影响。
- 只复述已知条文、没有新的规则、实施细则、执行程序、生效或过渡安排、适用范围变化的解读，sig ≤ 3。材料包含上述可核对的新事实时，按本次新事实的实质份量评分，不因专家署名、解读形式或二手转述自动压分。规则本身的旧背景不得冒充本次新增事实。“新增”按原始事实发生时间和相对已有公开信息的变化判断，不以本篇报道日期为准。
- 没有资源量、品位或储量类别的找矿宣传，`sig ≤ 3`。钻孔见矿和现场快速分析不等于经评审的资源量。
- 空预告：只有“将公布”“即将发布”，没有可验证事实，`nov ≤ 3` 且 `cred ≤ 4`。 已正式启动的调查、审计或执法程序，如明确实施机关、对象、范围或时间安排，可评价材料实际证明的动作：宣布或安排开展、已经实际启动、已经出具结论三种阶段分别处理；正式安排不等于已经启动，不能把尚未出具的报告、调查结论或处罚结果提前算作事实。只有日期预告、没有可核实新增动作的，仍适用空预告规则。
- 企业自述式“签约合作”“战略合作”，没有金额、规模、产量、年限或可核实阶段，`sig ≤ 4`。
- 小幅工艺改进、实验室小试、没有放大验证的“突破”，默认 `sig ≤ 4` 且 `reson ≤ 3`。
- 宏大观点若没有新事实或新因果；融资意向、估值传闻、会面、成立工作组若没有已兑现后果，均应明显低分。

## 事件、转述与材料不足

- 不因为材料是转述、引用、翻译或二手报道就自动扣事件分。只要正文足以确认同一个具体事件，后续聚类会把它合并到更好的一手代表稿。
- 但不能把被引用者没有说过的效果、因果或阶段补进事件。材料只能证明较弱主张时，`cred` 和相关轴必须随之降低。
- 如果标题与正文核心明显不符，或正文残缺到无法辨认对象、动作和阶段，最终分数不得高于 30。
- 如果只能确认“有人声称某事”，却无法确认实质动作或结果，按这个较弱事件评分；不要替材料补全一个更强故事。

## 事件口径校正（与主规则一起执行）

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否引用，误当成事件本身的价值。若与前文的直觉判断发生冲突，以本节的事件口径为准，但五轴定义、类型权重和单字段输出契约不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给“这篇文章写得怎么样”打分。
2. 单一企业但构成重大先例的事件，例如征收、国有化、吊销许可、政府阻止收购，按其真实份量评分。单一官方来源的事件同样可以得高分，不因为只有一家官方来源就压低。
3. 同一材料同时包含一个强事件和一个弱叙事时，以强事件为核心分类和评分；弱叙事不能把强事件降格。专家解读附着于一项新规定或新的实施进展时，以材料明确支持的新事实为核心；只有没有新增事实的纯条文复述才适用纯解读降分规则。
4. 反过来，长篇、完整、观点锋利或数字很多，仍不能替一个不成立的因果、厂商营销或宏大推断制造事件价值。只有正文支持的新事实、阶段变化或可行动的规则进入五轴。

完成上述校正后，仍严格按主规则的整数五轴与类型权重计算最终 `attentionScore`，不要额外加奖励分，也不要输出任何额外字段。
