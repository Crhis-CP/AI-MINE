- 只评事件值得被看见的程度，不评这篇稿件是否应成为事件的最终代表稿。相同事件的官方稿、媒体稿、短公告或引用材料会在模型外聚类并选择代表。

- 标题与正文冲突时以正文为准。正文很短不自动低分，只要对象、动作、阶段和核心事实清楚，仍可正常判断。

- 不要因为公司名气大而给“实质份量”加分；大型矿企的意义体现在它的动作对行业和读者的影响上，按事件本身评。

## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与内容类型

先用一句话确认“谁，在什么时候，做了什么，处于宣布、申请、获批、开工、投产、停产、复产、生效还是调查结论阶段”。然后从以下 9 类中选择最贴近的一类。会议、讲话、访谈或研报里宣布或披露了新的政策、交易、产量、项目等事实时，按那件事归类；只有观点、表态或人事、没有新的事实动作时才归 `events_opinion`。

- `policy_regulation`：政策监管。立法、许可、税费、准入、执法与矿权制度，含草案、征求意见、生效、废止；出口管制、关税、配额与制裁。
- `operations_output`：生产经营。在产矿山与矿企的产量、业绩、指引、成本、分红、停产与复产。
- `project_development`：项目建设。审批、可研、开工、扩建、投产与工程合同。
- `exploration_resource`：勘探资源。钻探结果、资源量、储量、品位和勘探成果。
- `capital_ma`：并购融资。收购出售、合资、融资配售、上市、包销协议，以及已写清阶段的交易。
- `commodity_market`：市场价格。价格、库存、供需、官方统计与行情分析。
- `technology_processing`：技术装备。采选冶工艺、设备与数字化，以及已有放大验证的工艺进展。
- `safety_environment`：安全环境。事故、伤亡、救援、泄漏、环境事件、社区与劳资冲突、ESG 和调查结论。
- `events_opinion`：会议观点。会议论坛、致辞、访谈、研报观点与人事，本身没有新的事实动作。

### 二、按当前五轴独立打 0–10 分（可到一位小数）

1. `sig` 实质份量：它在金属矿业时间线上是节点、这周值得知道的变化，还是当天脚注。不要把“读者能马上据此行动”重复算进这一轴。
2. `nov` 信息增量：材料带来了多少明确的新认知，而不是标题看起来有多新。具体新事实、新数字、新阶段或新矛盾才是增量。
3. `cred` 证据强度：材料内部对核心事实提供了多强的支持，不是来源名气。官方文书足以证明“发布、批准、施行”这一动作，但不能自动证明宣传中的效果。材料只能证明草案、意向书、申请或传闻时，不得按已通过、已签约、已获批评。
4. `reson` 影响面：这件事波及的范围有多大：涉及多少市场、国家和公司，占全球供应或需求的多大份额，会不会改变价格或政策走向。按三档给分，不看事件发生在哪个国家：
   - 全球性：改变一种主要金属的全球供需或价格，主要生产国或消费国的重大政策与政治变化，大型矿企或贸易商的战略级动作：7–10；
   - 区域或单一市场：一国或一省的重要政策与政治事件，中型项目，一种金属的区域供需：4–7；
   - 局部：单个小项目、地方事务、影响有限的企业动态：0–4。
5. `act` 可用性：读者是否能据此调整经营、合规或投资动作。纯新闻和重大事件的 act 低是正常的，不应反过来抹掉 sig。

### 三、五轴分的刻度

各轴用同一把尺：

- 0–2：当天的脚注或噪声；
- 3–4：例行、份量有限；
- 5–6：这周值得知道；
- 7–8：行业时间线上的重要节点；
- 9–10：罕见的标志性事件。

同一档里有强弱之分时，用一位小数表达（例如 6.3 和 6.8），不要都落在整数上；也不要为了显得精确而编造差别。各类型的权重由程序计算，五轴只按各自的定义独立判断，不要为了让总分靠近整十或任何想象中的门槛而调整五轴。

## 品味规则

### 必须正常评价的价值

- 法规与监管的实质变化：立法、许可、税费、出口管制、环保与安全新规，含草案进入关键阶段、生效、废止、过渡期。官方文书足以证明“发布、批准、施行”，但不能自动证明宣传效果；草案和征求意见稿不得按已通过评分。
- 矿权与项目里程碑：获批、开工、投产、停产、复产。材料只能证明申请、意向书时，不得按已获批、已签约、已投产评分。
- 重大并购与融资：交易阶段与金额口径写清。传闻、意向书、协议、审批、交割分开评。
- 资源量与储量披露：按披露标准、类别、品位与有效日期评。推断、控制、探明资源量，以及可信、证实储量，不得互相替代。
- 价格与供需的实质变化：有基准、单位、时间窗才算实质。
- 贸易措施：反倾销、反补贴、关税、出口管制与配额，包括钢、铝等金属产品，不论发起国和对象国；制裁与关键矿产储备、供应链安全政策。
- 资源国政治与安全风险：国有化与征收、合同重谈、权益金与税制大幅调整、出口禁令与强制本地加工、选举结果带来的矿业政策转向、民粹政策、社区封锁与大规模抗议、罢工、政变与武装冲突、制裁。按对生产和投资环境的实际影响评；只有表态、还没有政策或行动的，按较弱的事件评。
- 大型投资激励与制度改革：例如阿根廷 RIGI 等大型投资制度批准的项目、矿权与许可制度改革。
- 大型矿企和贸易商的业绩、产量指引、战略调整、重大项目决策与并购，包括它们在海外的项目与经营动态。
- 主要生产国和消费国的主管部门、行业协会发布的运行数据与政策，例如中国、美国、智利、秘鲁、澳大利亚、刚果（金）、印尼、阿根廷。
- 跨行业但约束矿企的法律：反海外腐败与反商业贿赂、制裁与出口管制、反洗钱、供应链尽职调查与强迫劳动、碳边境调节、关键矿产与外国关注实体规则、强制性的气候与可持续信息披露。这类法律的正式通过、生效、修订，以及执法机关依它对矿企、冶炼企业或金属贸易企业作出的处罚、和解、起诉，类型记 `policy_regulation`，按它约束的矿企范围和实际后果评分，噪声类型记 `none`，不按一般政务压低。
- 重大安全与环境事件：已确认的伤亡和调查结论按真实份量评。初报与确认分开，未证实的伤亡和原因不得按已确认评分。
- 官方统计与规划：有基准、单位、时间窗。官方来源足以证明“发布”这一动作。

### 必须压住的噪声

- 独立的煤、铀、砂石内容，以及对金属没有影响的非金属矿内容，`sig ≤ 1`。
- 纯获奖、参会、泛宣传、招聘与活动推广，`sig ≤ 2`。
- 例行人事、例行许可延期、会议通稿，以及按期例行的运行通报，没有新的决定或后续动作，`sig ≤ 3`。
- 多事件打包而没有单一焦点的汇总稿，`sig ≤ 3`。
- 只报涨跌、没有基准、单位或时间窗的行情复述，`sig ≤ 3`。
- 没有新增事实、数字、角度或引文的转载同稿，`sig ≤ 3`。第一次报道该事件的稿件不受这一条影响。
- 发在部门网站上的专家署名解读，以及只复述条文、没有新规定的稿件，`sig ≤ 3`。
- 没有资源量、品位或储量类别的找矿宣传，`sig ≤ 3`。钻孔见矿和现场快速分析不等于经评审的资源量。
- 大型矿企名单之外的小矿企，例行的钻探结果、资源量更新、技术报告、融资配售、季度活动报告、股东会，噪声类型记 `junior_routine`（程序封顶 55）。例外照常评价：世界级发现；被大型矿企收购或与之合作；构成所在国政策先例。
- 伤亡较少、没有造成大范围停产或政策后果的海外事故，按一般新闻评，不进“必须正常评价”。
- 空预告：只有“将公布”“即将发布”，没有可验证事实，`nov ≤ 3` 且 `cred ≤ 4`。
- 企业自述式“签约合作”“战略合作”，没有金额、规模、产量、年限或可核实阶段，`sig ≤ 4`。
- 小幅工艺改进、实验室小试、没有放大验证的“突破”，默认 `sig ≤ 4` 且 `reson ≤ 3`。
- 宏大观点若没有新事实或新因果；融资意向、估值传闻、会面、成立工作组若没有已兑现后果，均应明显低分。

## 噪声类型（程序按类型封顶总分）

按材料的主体选一个，拿不准时选 `none`：
- `none`：不属于以下任何一类。
- `out_of_scope`：与金属矿业无关，例如独立的煤、铀、砂石、一般建材，或与矿业无关的一般新闻（封顶 30）。
- `event_routine`：会议论坛、致辞、获奖、人事任免、例行分红与回购、宣传活动（封顶 35）。在会议上宣布的新政策、新交易，按宣布的那件事评，选 `none`。
- `price_tick`：只报单日涨跌、没有基准、单位或时间窗的行情（封顶 40）。
- `general_gov`：与矿业没有直接关系的一般政务文件，例如综合考核、采购管理、行政检查、普法宣传（封顶 40）。专门针对矿业、资源、安全生产、生态环境的法律法规，以及上文“跨行业但约束矿企的法律”，不在此列。
- `junior_routine`：见上文“小矿企”一条（封顶 55）。

## 事件、转述与材料不足

- 不因为材料是转述、引用、翻译或二手报道就自动扣事件分。只要正文足以确认同一个具体事件，后续聚类会把它合并到更好的一手代表稿。
- 但不能把被引用者没有说过的效果、因果或阶段补进事件。材料只能证明较弱主张时，`cred` 和相关轴必须随之降低。
- 如果标题与正文核心明显不符，或正文残缺到无法辨认对象、动作和阶段，把 `materialUnusable` 设为 true（程序会把总分压到不高于 30），五轴仍按材料实际能证明的内容给分。
- 如果只能确认“有人声称某事”，却无法确认实质动作或结果，按这个较弱事件评分；不要替材料补全一个更强故事。

## 事件口径校正（与主规则一起执行）

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否引用，误当成事件本身的价值。若与前文的直觉判断发生冲突，以本节的事件口径为准，但五轴定义、类型权重和上面的输出格式不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给“这篇文章写得怎么样”打分。
2. 单一企业但构成重大先例的事件，例如征收、国有化、吊销许可、政府阻止收购，按其真实份量评分。单一官方来源的事件同样可以得高分，不因为只有一家官方来源就压低。
3. 同一材料同时包含一个强事件和一个弱叙事时，以强事件为核心分类和评分；弱叙事不能把强事件降格。专家解读若只是附着在一项新规定上，分类仍按那项新规定，分数受“必须压住”里解读条款的约束。
4. 反过来，长篇、完整、观点锋利或数字很多，仍不能替一个不成立的因果、厂商营销或宏大推断制造事件价值。只有正文支持的新事实、阶段变化或可行动的规则进入五轴。

完成上述校正后，仍按主规则的刻度给出内容类型和五轴分；总分由程序计算，不要自己合成或改写。
