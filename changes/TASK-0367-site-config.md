随全站统一升级发布。

金属价格继续从原入口访问，电脑与手机菜单一致；页面刷新和暂时失败时保留已有价格的行为保持不变。

后台将网站资料和账号放在站点管理分组，原表对账保留在信源旁；旧书签与我的账号入口继续可用。

后台登录与账号权限继续逐次检查，公开阅读保持无需登录。

网站运行服务统一整理，保留公开阅读和后台登录权限；升级仍可恢复到上一版本。

清理未使用的运行入口，采集继续由后台任务自动执行。
