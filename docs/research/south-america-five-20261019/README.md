# 南美五国矿业信息源 · AI-MINE 接入包 V1

整理日期：2026-10-19。目标仓库：[Crhis-CP/AI-MINE](https://github.com/Crhis-CP/AI-MINE)，核对基线为 `main@e75f033d0e1b626c9af3fe274464171d4d6f6806`。

本包把原始清单 **83 条记录全部映射**到 **101 个监测入口**，补全官网、新闻栏目、法规目录以及确实存在的 RSS／API。入口数包含同一机构的不同栏目，不能当作独立网站数或独立新闻来源票数。其中另补 10 个公报、资源部门或历史对照入口。

已生成 **76 份 AI-MINE 原生配置草稿**：资讯线 65 份、法规线 11 份；其余 25 个入口给出完整网址与后续适配说明。所有草稿为 `enabled: false`。现有仓库和生产环境均未被本包修改。

## 怎么交给接入 AI

把整个 ZIP 发给具有目标仓库访问权限的 AI，让它先读 **`00_给接入AI的任务.md`**，再读取 `config/registry.json` 和增量核对报告。原文已有的来源优先复用或审阅优化；已有目录、真实运行记录和已经启用是三个不同状态。
