## 〇、先纠正一处理解

- **最初的定位没有错。**产品定义一直是“面向中文读者的全球矿业资讯”，这里的“中文”指阅读语言，不是读者国籍。
- **跑偏发生在 11 月 5 日。**那次按您的 119 条标注改评分：标注里涉及中国的稿件您选中了 80%，我据此把评分提示词里的读者写成了“关注海外投资和合规的中国读者”，并调高了“与中国读者的关联”这一项。这是我把标注里的规律当成了读者定义，责任在我。
- **从现在起，读者定义统一为：**用中文或英文阅读的**全球矿业投资者和从业者**。精选按**全球影响力**选，不偏向任何国家。读者想看某家公司，就用公司筛选。

## 一、北极星与工作原则（所有阶段都遵守）

1. **读者**：全球矿业投资者和从业者。他们要用最少的时间看到会改变自己判断的事，同时看不到无关的东西。
2. **四个出口各管一件事**：
   - 全部：在不在范围里；
   - 精选：值不值得一个忙人花时间看；
   - 热点：现在是不是很多家都在报道；
   - 分类：读者从哪个口子找到它。
   
   一个分数不再同时回答几个问题。
3. **编辑政策写成一份带版本号的文件**，作为唯一依据。提示词和代码里的门槛都从这份文件来，每条稿件都记下“按哪一版、因为什么”被收录或入选。任何 Agent 接手，读这一份就知道全部口径。
4. **先测量，再改规则**。改规则前，先在标注样本上回放，量出“漏了多少、多收了多少”。规则改动由您确认后才生效。
5. **环节少而稳**：
   - 能用代码判断的不交给模型；
   - 每个环节都要有明确的结束状态，不会卡住，可以安全重试；
   - 环节要合并时，先做“拿掉它再跑一遍”的对比，确认可以合并才动。
6. **模型**：
   - 主模型负责全部判断，保证口径一致、缓存命中高；
   - 后备模型平时抽查约 5% 当审计员，主模型中断时接上；
   - 翻译这类简单的活，用质量相当的最便宜的模型。
