## P12 最终集成和七天观察

- 输入：相关小卡完成、独立质量结果、Owner标准与群目标决定（仅依赖事项需要），代码/配置指纹和样本manifest。
- 验证：每卡focused通过后`npm run check`；最终准确SHA在非生产执行器`make verify`取得scope:full回执，PR合入main后按现有正式制品流程验证准确版本。不得把`make release-check`规划入口说成通过。
- 发布与观察：用户明确授权后才生产切换、启用目标；持现有release锁和回退规则。按acceptance.md连续168h，记录实际作业与人工干预；长周期另行回放/自然验证。
- 完成判据：代码验证、制品、上线健康、独立内容质量、非技术页面/后台验收分别登记。发布失败能回退；7天未满或月界未观察明确写缺项，不提前关闭质量。
- 估算：2—3人日集成/复核，另7天日历观察；不在本轮启动自动化或生产变更。

## 第二阶段先交可行性包

法规：官方原件+附件清单、文字/OCR分流、一个省试点、月份/生效与修订语义、翻译及法律复核样本、每页成本；恢复暂停需后续明确决定。行情：逐品种数据契约与三种时效方案报价，包含展示/再分发、币种单位、历史数据和超额费用；不先买LME。品牌：候选名称域名、费用、旧链接迁移和所有对外标识清单；不注册不改DNS。
