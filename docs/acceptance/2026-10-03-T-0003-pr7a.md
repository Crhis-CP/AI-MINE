# T-0003 PR7a：私有队列生产者

依据TASK-0004 D5，private-api的队列配置固定关闭建schema、迁移、维护与定时；ensureQueue每次只查既有队列。worker与test、旧api过渡行为保持，当前尚未激活API_ROLE必填或拆分main/Compose。

队列未安装、版本不匹配与队列缺失通过可识别异常进入原adminHandler，返回503、temporarily_unavailable与Retry-After:30；诊断为固定消息，不带连接地址或cause。失败启动先清理连接和计时器，再释放本次失败缓存，同一私有根的下一请求能够恢复。worker只负责安装和建队列，私有端不代建。
