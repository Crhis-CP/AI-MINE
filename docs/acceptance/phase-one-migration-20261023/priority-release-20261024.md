## 运行替换、回退及月报验收

- 价格继续由唯一metals.prices每30分钟执行；报告继续由reports.catch-up每30分钟补扫、reports.correction-sweep每5分钟递交修订，不另安装第二套定时器。正式发布先执行既有`dc stop -t 480 worker`并确认旧容器停止，再重建启动新worker；原cron身份复用，registerSchedules清理退役cron队列。原业务任务及账本不清空。
- 备份按正式脚本写入`/opt/aimine-backup/release-<最终SHA前12位>-<本次UTC尝试标识>`，实际位置在当次日志中登记。保存数据库、环境、主机及各角色程序、必要持久资料和摘要。候选健康失败时由原脚本EXIT处理调用restore：停止候选worker和API/web，恢复environment与host-program，设置原APP_IMAGE/AMP_RELEASE，执行`dc up --no-start --no-deps --no-build --pull never --force-recreate`重建原角色，逐角色恢复程序归档，核对原版本健康，再启动旧worker。脚本没有独立rollback参数，不能虚构该命令。新增迁移保持兼容；自动程序回退不回灌旧数据库覆盖新数据。
- 9月月报须由正常调度产出并取得执行链、实际报告和读者入口证据。若catch-up直接生成，其generated须含monthly:2026-09；若由已有修订调度经reports.reconcile生成，则核对该任务的领取/完成记录、attempts/result、月报内容和页面，不伪造另一条catch-up的generated。没有可读实际月报时均不验收；人工命令生成不算自动补刊通过。
