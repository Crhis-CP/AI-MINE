更新：2026-10-28。Owner最新目标：**以AIHOT为标准，把AI-MINE中所有与AIHOT不一致的底层架构迁移成AIHOT的做法；矿业特有的信源、评分规则、国别分发和历史数据保留并接入新架构。** 本文件是唯一架构迁移清单，进展与Grok意见统一回写[Issue #293](https://github.com/Crhis-CP/AI-MINE/issues/293)。上线结果另记[功能交付清单](delivery-checklist.md)，不另开协作入口。

## 当前发布前状态（2026-10-28）

本轮已确认的运行消费者和读者修复已整合完成，统一接入既有[PR333](https://github.com/Crhis-CP/AI-MINE/pull/333)，不再另开实现PR。关于页/读者文案和服务器报道比较分别保留独立提交；已知内容许可与旧事实卡兼容问题已修。新原帖准入默认关闭已经实施并通过定向回归，开启仍须Chris确认。当前是实施完成、待最终交付，不是全部上线或模型效果验收完成。

剩余交付只包括：最终准确head的必要检查和full、合并main的正式受测制品、备份回退与部署、一次公网页面及服务器自动任务接管核验。按Owner最新要求完成后结束本轮开发，后续运营由服务器承担。固定31篇真实模型评测尚未运行；日周同刻、10月月刊和真实价格恢复尚未取得自然结果，继续记为未验证，不追加持续人工运营。最终版本、发布与接管证据集中记入Issue293，不为补写这些结果再启动一轮代码发布。
