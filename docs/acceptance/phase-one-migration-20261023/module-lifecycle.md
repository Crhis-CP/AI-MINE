# 内容与报告模块事件承接

固定上游a0d1e75b中的内容、译文、公开投影、报告和来源重建调用点，与本站实际写入位置对照后接入已声明的emit。未创建新的总线，也未注册第二套采集、模型或发布任务。

文章修订、正文展示、完整或部分译文、公开投影、精选代表替换和原文日期更正，在原写事务内发articleChanged；政策材料不以资讯材料修订发送。普通出刊、历史补刊和既有更正路径在报告实际变化时发reportsChanged。来源重建在既有worker完成全部处理后发sourceRepublished，延后状态不发完成事件。

回调失败导致当前写事务回退；报告或投影未变化不重复发送。人工作业、控制状态及来源许可继续由原入口检查。消费者仍须在传入事务中登记自己的持久工作，不把外部请求塞进事务；本次不新增实际外部回调。

三项红测已复现未接通的内容、公开投影及报告事件；修复后检查真实事务回退、重复输入静默、法规材料隔离，并复用报告修订和分段译文检查。最终检查与完整准确版本验证分别登记，生产尚未切换。
