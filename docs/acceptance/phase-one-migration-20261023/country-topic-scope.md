# 国家主题与国家筛选一致

TASK0446发现同一处遗漏：国家下拉使用当前作用地，但国家主题目录、页面及topic筛选仍使用国名标签/标题摘要文字。因此背景国名、无地理证明和旧修订证明能进入主题；仅写卡塔马卡、但已有有效AR证明的文章反而可能漏掉。

红测使用独立合成材料复现：阿根廷主题返回背景、未知和过期三条，遗漏唯一有效作用地材料。修复复用现有topicCondition：单个国家标签对应的主题按当前文章修订、分析和有效配方的国家证明筛选；普通公司、矿种及混合业务主题保持原匹配。目录统计在原一次查询中取得同样的当前证明，未新增逐篇或逐国数据库查询。

同一条件覆盖列表、主题页、展开组、API列表/事件目录和筛选计数。撤回、未到出刊时间、不合格条目不恢复；多国证明可进入对应国家主题，正文搜索继续支持普通提及。未改评分、阈值或来源状态，没有另建阿根廷规则。
