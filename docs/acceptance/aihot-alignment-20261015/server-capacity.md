# 服务器容量结论

2026-10-18 UTC只读采样。当前不建议先采购CPU升级；先完成本轮程序整合，并在统一发布后的自然采集、翻译与出刊重叠时复核。4核、约4GB内存满足固定参考版本部署文档给出的“至少2核、4GB（包含构建）”建议。参考文档不是对方真实生产服务器配置，未取得其实际机器规格。

| 指标 | 本站观测 | 解释 |
|---|---|---|
| CPU | 4逻辑核；三次load约0.21–0.34 | 此短窗口没有CPU饱和证据 |
| 内存 | 可见总量3.64GiB，可用约1.46–1.48GiB | 当前有余量；不能代替新版峰值验证 |

| 空间 | 文件系统可用9.77GiB | 最终制品、备份与保留版本会占空间，发布前须按实际制品再核对 |

本次没有采购、扩容、重启、清理缓存或改变生产配置。新版本合并API后进程数量减少，但节省量须实际测量，不能提前扣除当前两个API的全部内存。新增来源批量初次导入与翻译可能提高负载；保留请求次数和采集并发限制，观察自然任务积压、可用内存、PSI、OOM及任务延迟。如果出现持续内存压力或内存不足重启，优先评估8GB内存；如果CPU持续饱和再判断计算扩容，不能用一次采样预先断言永久不需升级。
