本次没有采购、扩容、重启、清理或改变生产设置。新增来源首次导入、翻译和报告重叠可能形成更高峰值；维持既定采集并发与服务请求限制，发布后检查自然任务积压、可用内存、PSI、OOM和任务延迟。若持续低于约500MiB可用且伴随换页/延迟，或新增OOM，优先评估8GB内存；只有CPU持续饱和才评估更多核心。这些是运维判断依据，不是新增业务熔断阈值。
