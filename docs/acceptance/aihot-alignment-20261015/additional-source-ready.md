# 新增补充来源配置

本轮补充8家独立发布方：Gold Hunter Resources、Banyan Gold、Onyx Gold、Omai Gold Mines、Founders Metals、Westhaven Gold、Blackrock Silver、Kincora Copper。官方列表入口、配置、真实预览时间、样本和身份核对记录见同名JSON。

已与2026-10-16只读取得的440条运行库安全身份信息及原320个规划目标核对主机和公司名称/别名，未发现匹配；不以同机构多个入口凑数量。来源均写为停用、禁止全文公开，统一发布时按身份增量接入。原研究池中仅有列表可读但日期缺失的中间结果未计入这里。

预览发现并处理了两类真实日期差异：Banyan/Onyx的time元素提供带偏移的ISO时间，应按该字段解析；Omai/Westhaven/Kincora使用英文月名在前的声明格式，补齐有无逗号、缩写月份的解析，保持仅日期精度。最终8份配置的预览样本均取得标题、链接和日期。Omai列表返回真实官方PDF地址，列表通过不代表全文处理或公开许可通过。

替代研究保留失败：Silver North和Silver Viper的原生robots检查未通过，未接入；Silver47涉及已宣布的合并，身份未收口，不计新增。没有从搜索页面可读推定采集器也能通过访问规则。

同轮只读对账确认：生产仍有440条来源，10月14日创建的170条配置均与当前仓库相同，148条启用，144条同时具备有效标题/链接/日期条目与成功采集时间。该144仍须排除原规划重复、同机构入口及范围不符，不能直接称为本批最终验收数量。生产启用和自然采集验收在统一部署后进行。
