# 报告阅读契约准备

TASK-0360 的报告兼容扩展。站点引用可携带事实标识、来源数、旧日报刊期、补充选材标记与相关报道；头条原文通过可选leadItemId关联。v3报告的可选reading只携带公开引用关系，缺失保持未知。既有必填字段和既有接口地址不变。

契约测试覆盖旧值省略、新值往返、重复主条目、无效头条与未证明来源数的拒绝。`pnpm contracts:gen`重新生成公开OpenAPI和客户端类型；契约测试通过。快速检查及独立最终提交完整验证分别登记，不作为已发布功能的证明。

消费者须在合并后逐项核对相关引用的当前可读性和权限；父条目可读不等于相关条目可读，已撤回标题或来源不能由旧快照复活。本PR不接通消费者、不调用模型、不部署。
