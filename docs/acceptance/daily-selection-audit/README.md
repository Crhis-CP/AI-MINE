## 原因与规则

日报出刊日期为D时，覆盖北京时间D-1的08:00至D的08:00，不是D日00:00至24:00。归期以实际精选公开时刻与材料时间的较晚者计算。被核对的三条资讯均在10月13日08:00之后入选，属于14日报候选；13日报窗口没有新增精选。历史期保持冻结，截稿后稿件不回填。

筛选依次为材料准备、行业范围预筛、两次独立评分、来源分级门槛、中文标题导读、归组释放、公开资格和同事实折叠。T1/T1_5/T2门槛分别60/65/76，两次之和与两倍门槛比较，显示分数取平均值向下取整。不设各来源配额，也不等到某一小时统一精选。评分仅输出总分，不能还原未保存的五轴扣分理由。
