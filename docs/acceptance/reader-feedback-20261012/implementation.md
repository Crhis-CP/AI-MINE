## 已实施

新反馈先在网站持久收件并返回编号；worker每分钟向专用私有飞书群发送正文、相关页面、联系方式和截图。历史反馈不补发，public-api不读取飞书密钥或直接发送，反馈群独立配置、不回落到告警或内容群。截图上传结果、投递状态和消息编号持久记录；失败可重试，结果未知或进程中断保留待核对，不盲目重复发送。未知或明确失败的投递另向运行提醒群发一次数量提醒，不含读者材料，避免静默漏通知。网站保留截图、处理状态和备注，删除与投递用行锁排序。表单和隐私说明披露用途、接收者、本站180天删除与飞书副本人工管理。
