## 有具体依据的遗漏

### PIPE-04 · 不改变入口/分页时的检查点保留（P2）

新 activate_draft 分支无论入口/分页是否变化，均将 cursor 清空。旧编辑行为不作为正确规范；新版规格明确入口与分页不变时保留检查点。

**业务影响：**仅调整初始回填上限等非分页配置也会重新进入 firstImport 分支，重新限缩候选和标记回填，影响采集连续性。

**复现路径：**

1. 已有 RSS 来源 cursor.initializedAt 和 RSS validators。
2. 只修改 config._amp.initialBackfillLimit，入口 feedUrl 与分页规则保持不变。
3. 成功预览并激活草稿；updateSource 的 CASE 无条件把 cursor 写为 NULL。
4. 下一轮 collectSource 认为 firstImport=true，按初始回填分支执行。

**依据：**旧 `services/live_pipeline/source_admin.py:161-171`；新 `packages/backend/src/admin/sources.ts:121-162`、`packages/backend/src/sources/collect.ts:173-178`、`packages/backend/src/sources/collect.ts:214-231`；规格 `docs/01-product/04-private-operations.md:403`。

**口径：**这一项是当前规格要求未实现，不把旧 main 描述成已具备该能力。

### PIPE-05 · 信源归档与归档后的不可误恢复（P2）

旧 change_state 有 archived 状态，归档来源不能试抓；新版来源入口只有 enabled 暂停/恢复，未找到归档命令、归档状态和对应列表排除。

**业务影响：**弃用或错误来源只能长期混在暂停来源中；无法保留“已归档”语义及防误恢复约束。

**复现路径：**

1. 选择已不用的来源，希望归档并保留历史。
2. 现有 UI 仅有暂停/恢复；API source patch 更新 enabled，后端列表仍返回该来源。
3. 代码全范围搜索来源 archived/source.archive/归档无实现（反馈归档不属于信源）。

**依据：**旧 `services/live_pipeline/source_admin.py:173-201`、`services/live_pipeline/source_preview.py:11-16`；新 `packages/backend/src/admin/sources.ts:24-53`、`packages/backend/src/admin/sources.ts:110-165`、`apps/api/src/routes/admin.ts:200-218`、`apps/web/app/routes/admin/source.tsx:82-101`；规格 `docs/01-product/04-private-operations.md:392`、`docs/01-product/04-private-operations.md:433`。

### PIPE-23 · 事件/发展线/报告独立下架与恢复（P1）

旧 main 明确支持 item/event/story 并保存组成员快照、独立叠加下架；新版找到的运营入口只有单篇 visibility、拆分与合并，没有整事件/发展线撤回记录及成员快照。报告独立下架是当前规格另增要求，旧 main 的该 SQL 不支持 report。

**业务影响：**运营者无法一次撤下存在问题的整组并保证后续重组不复活；也无法独立撤回一份仍含公开文章的报告。

**复现路径：**

1. A、B 属于同一发展线 S，先独立下架 A。
2. 应可对 S 下架并保存 A/B 成员，再恢复 S 后 A 仍独立下架。
3. 新版只有 content/:id/visibility，逐篇操作只有每篇单一 visibility 值，没有 S 的独立持有记录/成员快照，无法表达上述恢复语义。
4. 报告仍有公开成员时也没有报告级撤回命令或报告读取撤回判定。

**依据：**旧 `db/migrations/0013_persistent_withdrawal_membership.up.sql:3-33`、`db/migrations/0013_persistent_withdrawal_membership.up.sql:154-183`；新 `apps/api/src/routes/admin.ts:229-257`、`packages/backend/src/admin/content.ts:103-126`、`packages/backend/src/publication/reports.ts:207-220`；规格 `docs/02-rules/01-business-rules.md:567`。

### PIPE-25 · 新闻报告跟随人工更正并形成修订（P1）

旧人工公开会重建快照并按报告正文变化增加修订；新版人工稿只刷新文章和事件摘要，报告成员仍公开时读取 raw.title/raw.summary，已刊报告 composeDaily 又直接返回，未找到更正传播任务。

**业务影响：**已更正文章的新事实不会自动修正已刊日报/周月报，报告继续展示旧数字或旧表述；撤回时只隐藏失效内容也未形成所要求的新修订记录。

**复现路径：**

1. 先刊日报，其中文章 A 的标题为“项目产量为100吨”。
2. 人工将 A 改为“项目产量更正为10吨”并公开，A 保持 public。
3. loadReport 的 availability 只给出可见性等元数据；citationFrom 继续使用报告中的 raw.title/raw.summary。
4. 再次执行 composeDaily，已存在条目直接返回，不生成更正修订。

**依据：**旧 `services/live_pipeline/operations.py:1037-1078`、`services/live_pipeline/processing.py:530-565`；新 `packages/backend/src/admin/content.ts:241-244`、`packages/backend/src/reports/compose.ts:205-210`、`packages/backend/src/publication/reports.ts:66-104`、`packages/backend/src/publication/reports.ts:160-193`；规格 `docs/02-rules/01-business-rules.md:681`、`docs/01-product/06-content-standards.md:989`。

**隔离复现已执行：**直接提取该版本 `citationFrom` 原函数体，仅删除签名中的 TypeScript 类型，在 Node vm 中传入合成的旧标题与已更正公开文章。函数仍返回旧标题“项目产量为100吨”和旧导读；没有导入应用、读库、联网或调用模型。其余遗漏是入口与状态写入的逻辑复现，未运行数据库集成。

### PIPE-30 · 反馈结果未知后的同一提交去重（P2）

旧 main 也没有稳定提交键；新版浏览器/API未传递/读取幂等键，后端每次 INSERT。当前规格明确采用幂等键。

**业务影响：**数据库已收件但客户端响应丢失时，用户重交会新增重复反馈并再次占用处理工作。

**复现路径：**

1. 提交有效反馈，服务器 INSERT 成功后丢弃201响应。
2. 客户端显示网络错误并保留草稿，用户重试相同内容。
3. 前后请求没有相同稳定键，第二次再次 INSERT，产生两个反馈ID。

**依据：**旧 `services/live_pipeline/operations.py:1187-1240`；新 `apps/web/app/routes/feedback.tsx:117-135`、`apps/api/src/routes/feedback.ts:42-47`、`packages/backend/src/operations/feedback.ts:57-83`；规格 `docs/02-rules/01-business-rules.md:710`。

**口径：**这一项是当前规格要求未实现，不把旧 main 描述成已具备该能力。

## 应保留的新决定

- 外文稿“中文标题和导读先公开，全文后补”来自 2026-10-10 的 DR-09，不能按更早的完整全文前置要求报为遗漏。
- 月度金额硬上限与“等下月”行为已被 Owner 取消；新版异常熔断、独立回执、用量报告应按新规则核验。
- 精选采用 AIHOT 矿业化规则、独立两次评分；报告只取精选候选并采用新的北京时间出刊窗口，是明确变更。
- 新闻/法规的运行控制和暂停持有者分开，是明确强化；不能要求恢复旧单一 processing_paused。

## 覆盖与未核边界

已核查来源录入与预览、启停与采集调度、目录继续执行、原表计数、时间与材料修订、用途许可、预筛/评分/翻译、费用回执/重试/备用路由、事件归组与人工优先、人工稿与下架、新闻出刊、账号与运行控制、运维可见性、反馈。

以下未核实，不能从“代码存在”推定完成：

- 旧库各国专用适配器与新来源配置的逐站真实样本等价性。
- 具体来源正文/日期解析的全部语言和附件格式；真实法域目录完整性。
- 真实模型的事实准确性、翻译质量、跨语言归组质量、备用供应商响应身份。

- 公网、移动端、60秒全出口撤回、持续调度、告警送达、备份恢复及生产账单核销。
- 旧 policy 未合并分支内法规解读、政策关系和政策报告专线。
