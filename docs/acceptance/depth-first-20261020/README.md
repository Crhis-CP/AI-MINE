## 验收方法

最终准确SHA在非生产Docker完整执行make verify。开发机使用PostgreSQL 17.11、Node 24.21做必要focused检查；已找到并启动既有Lima隔离环境用于真实恢复演练，最终full仍在独立Linux执行器取得。生产仅用正式脚本持既有锁，当前及两个回退先保护，独立恢复证据通过后再讨论精简。

部署后至少覆盖连续48小时（半小时任务至少96次、日报至少2期）的自然运行，并与本轮部署前同频率计数、队列年龄、公开结果、错误原因比较；任何手动干预逐项登记。48小时可覆盖此前20小时停滞线索，不能证明自然周/月边界。周月跨期、晚到和重启先在隔离环境重放；自然边界及真实手机另列待验收。错误恢复时间按原任务退避/租约而非新造统一阈值判断。

正文/日期/译文/归组样本按地区、语言、企业、时期和事件进展分层，保存部分未用于调试的样本。原始生产记录只留本地受控 `.verify/depth-first-20261020/`；公开仓库只含汇总、哈希、可复算命令和合成用例。
