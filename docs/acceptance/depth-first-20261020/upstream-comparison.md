| 机制 | 本站处理与取舍 |
|---|---|

| 模型故障隔离 | 对照新版按模型隔离思想，复现本站已批准备用流程按整服务冷却误跳过另一健康模型。改为服务+实际配置指纹隔离；既有10次/5分钟和独占探针不变。当前生产未启用备用，不因本次修复代开供应商。 |

| 事实、事件与代表 | 继续采用候选关系、确认归组、事实代表与实质进展分层；补未筛选全部动态API/RSS同代表同锚点。筛选某一来源时保留命中该条件的材料，不把全局代表替换成不符合筛选的文章。 |
| 日期与历史 | 保留原发布日期、发现、公开与报告窗口的不同含义；日期型来源不补时分，旧资料不重定为今天。稳定配置的304作为已有材料复查，不能当作新文章。 |
| 日周月报告 | 日报规则编排；周月从日报及自然期间事实汇编。按本次委托允许历史增量修订，加入持久变更日志、代际/租约、受影响期次传播、首次/最近时间及人工优先；这项明确产品要求优先于不可修改旧定稿的旧行为。 |
| 中文与全文 | 保留必要中文先公开、获准精选后台全文翻译、原文区块及严格manifest；无许可不外送/公开全文。修复相关卡片污染和后处理删条件；不通过压短或截断冒充完整结果。 |
| 分类与主题 | 保留矿业9类、国家/地区/矿种/企业语义，将一手来源属性与新闻类别分开组合；不照搬技术行业分类，也不凭发布地分配事件国。 |
| 读者交互 | 复用现有组件、SSR、HTTP校验和阅读记录机制，补深分页返回、同页更新、操作取消延迟滚动以及桌面横滑按钮，不换技术栈。 |
| 发布与容量 | 复用统一API、worker、web、模块安装、npm锁、CI与既有发布锁；以本站实际4核/约4GiB/约40GiB盘的测量准入。上游CI环境不能充当作者实购服务器，也不能替代本站发布峰值及恢复验证。 |
| 法规、权限及人工控制 | 保留独立业务线、当前暂停、旧阅读及完整性约束；不因通用机制对齐覆盖人工修订/撤回/暂停，不新增法规处理模型或整套知识库。 |
