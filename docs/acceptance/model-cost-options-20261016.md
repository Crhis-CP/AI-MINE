## 免费额度

- MiMo公开说明确认有新客赠金，但未明确普通注册一律得到多少。大陆账号注册3天内按有效邀请规则绑定，可获得10元体验金，赠金有效40天；不把邀请奖励写成所有新人无条件到账。[官方活动说明](https://mimo.mi.com/docs/zh-CN/quick-start/faq/promotions)
- 百炼当前规则为北京地域各模型独立额度，通常100万Token、有效90天；qwen3.8-flash价目表列为100万。输入输出共用额度，具体以账号控制台为准。[新人额度规则](https://help.aliyun.com/zh/model-studio/new-free-quota)

建议先使用现有可用连接。用户如选择增加MiMo，可先用2.6-flash验证中文矿业材料的整理、翻译和归组表现，再决定分配环节；复杂复核可保留另一家模型。价格不是质量排名，当前没有用生产材料调用新模型做付费评测。密钥最终由用户在后台填写，不在聊天或仓库保存。

实施待核对：同服务多模型统一请求限流；实际费用与估算费用区分；已登记价格可能只表达单一费率，峰谷价格不得作为实际账单展示。免费额度不作为保证长期供稿的前提。
