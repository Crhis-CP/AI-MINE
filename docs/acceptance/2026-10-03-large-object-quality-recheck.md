# 大型对象生命周期修复

PR #36 独立审查补充复现：原生 largeObject 对象在模块注销后仍可 write/seek/read，实际写入了测试字节。该接口在当前业务中无调用，但返回能力不应绕过模块注册的生命周期。

本次保留大型对象功能，为方法返回的待执行查询和原生读写流的每次新数据库操作加同根约束。流内部的异步拒绝进入流错误通道；注销或对象关闭后不再开始新的操作。close 使用原生清理路径并可重复调用；创建进行中注销时，迟到对象会先关闭其事务再拒绝返回。

真实数据库回归覆盖注销后保留方法/查询、正常流式读写、对象关闭后的拒绝、注销后的读写流错误与单连接池回收、迟到创建。夹具仅删除各自创建的 large object，不清空他人的对象。最终提交的PG16.14基线、完整回执、独立审查和main复验在对应PR留证；不代表整个项目或生产已验收。
