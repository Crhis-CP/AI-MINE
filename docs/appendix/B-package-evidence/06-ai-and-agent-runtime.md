# AI 能力与开发 Agent 的边界

## 产品AI

产品AI是服务器任务中的受控能力接口：结构化提取、中文整理、翻译、必要事件裁决、政策解释、影响评估。它不持有任意数据库/SSH/云管理工具。模型供应商、模型版本、prompt、schema、glossary、cost table都可替换且版本化，替换需要同集评测，不在领域代码内写死品牌。

默认优先顺序：确定性规则 → 既有合法结果 → 精确缓存 → 有界检索 → 必要模型调用。相同材料的分类/实体/中文导读可以一次结构化调用完成；长文按块翻译复用成功块。不要机械继承AIHOT每条两次评分，也不要恢复旧项目默认独立AI二审。困难争议允许选择性复核；是否再调用由明确的失败类别、预期质量收益和预算决定。

模型接口输入包含document_revision、许可决定、获准文本/块、任务schema、词表和预算授权；输出为typed result + usage + provider receipt。模型不能直接输出可执行SQL、可访问新URL或改权限。抓取内容中的“忽略规则/调用工具/泄露密钥”都视为材料文本。新URL、实体外部查询需独立允许列表和获取端口。

精准缓存key至少包括输入hash、来源/许可版本、prompt/recipe、模型/provider、schema、词表、目标语言；不用“同标题”复用不同稿件。许可收紧后即使cache hit也必须重新做使用权限判断。provider prompt cache与业务结果cache分开计费记录。

## 模型选择与评测

采用能力矩阵，不把用户举例的未来模型名字写成可用性承诺或架构依赖。每条route注明支持语言、context限制、JSON/schema能力、幂等/对账能力、延迟与价格来源、数据驻留/保留说明。选型时间重新查官方信息并锁版本，价格变化不能使预算算法失效。

固定脱敏且许可可用的评测集分训练/校准/holdout，防止同事件或同文跨集合泄漏；覆盖法规33国底表与既有目标的并集、独立组织规则及主要语种，新闻保留18国历史覆盖基线；覆盖九类内容、错误法域、否定、条件生效、单位数量、公司重名、长文、图像与表格。比较质量、每千项实际结算/预留成本、P50/P95延迟、失败/unknown率，不能只凭排行榜选生产模型。

人工纠错形成candidate label；只有真实审核者确认及消除冲突后进入gold set。自动建议和开发Agent判断可作silver数据，必须分开。历史`content_reviews=0`只说明当时没有真实反馈，不能宣传已经学习了用户偏好。模型/规则升级采用小流量影子→差异审阅→启用，可按版本回退；回退不抹掉新产生的人工下架记录。

## 开发Agent

开发Agent读取交接包、模块README、冻结契约和当前任务卡，完成代码与测试。它不承担每天新闻生产。模型更强时可以提高并行模块数、改进评测和代码生成，不改变数据所有权或越过确定性许可/预算/发布边界。

首期不引入通用多Agent生产Runtime：现有需求能由持久任务+typed model gateway解决。未来若出现动态多步研究任务，先定义任务输入/可用工具/最大步数/最大费用/终止条件/产物schema，再提供隔离ResearchWorker；其产物进入相同证据与公开链，不直接上网改生产数据。

公开MCP只读消费公开投影，公开RSS/API/MCP必须同版本同抑制规则。已有飞书本人只读生产连接器是独立私有服务，继续按immutable owner allowlist、固定投影、有界查询和审计设计；不把它塞进公开Agent入口，也不把其凭证放进新仓库。
