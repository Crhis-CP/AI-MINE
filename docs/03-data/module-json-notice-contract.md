# 模块JSON提示与主题标识兼容契约

TASK0451在独立契约中准备可选输出。现有V3ItemDetail.notice是正文说明字符串；模块提示使用独立的module_notice对象，不能覆盖原义。v1文档与V3成功响应同步声明，旧响应仍可省略；错误体保持原形状，站内页面不会由此自动加入请求提示。

主题可选brand复用ModuleBrand结构，只允许本地资源路径或文字回退，拒绝外部网址、协议相对网址、反斜线与空白路径。标识仍由已安装模块提供安全公开投影；本卡不改网站名称、域名或默认主题内容。

现有sendJsonWithEtag只追加可选notice参数类型，当前仍按原正文生成ETag，不执行回调或拼接提示。数据形状声明不授予来源处理许可，也不证明模块输出安全；后续消费者必须核对当前公开资格、模块公开投影和缓存行为。

契约回归覆盖旧响应兼容、正文notice不被对象替换、错误体拒绝模块字段、本地标识路径及v1文档的可选性。运行消费者另行验证跨请求隔离、private/no-store及提示参与ETag，包括既有etagOf覆盖场景；无提示时保留原正文、状态和缓存语义。

PR297已先行将现有v1文档路径纳入集成卡，本卡在该main基线上同步文件，没有放宽权限守卫。当前没有新提示或标识实际输出，没有模型调用、评分变化、群启用或生产部署；不据此宣布完整迁移。
