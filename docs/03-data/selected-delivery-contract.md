# 精选投递候选读取口

TASK0467独立提供publication/detail的selectedDeliveryCandidate(id, db?)，供后台投递在同一事务中重新读取；不注册HTTP，不发送消息或改写投影。

当前候选必须public、eligible、selected与selection_candidate同时成立、未人工撤回，来源为资讯编辑来源，并已有明确发刊门槛。返回必要卡片字段、总渠道seat及当前修订/分析/配方绑定的国家证据；无总榜seat不取消候选资格。来源名沿现有字段，不新增显示规则；不返回原始正文、分析、许可文书或私有来源配置。

接口保留未来visible_after以供调度等待，不代表现在可以发送。通知消费者仍须检查静默、backfill、12小时窗口、发刊时刻、目标启用时间、当前国家及去重/未知结果；总渠道继续要求seat，国别在当前合格候选范围内判断。既有人工控制、确认分组与评分规则不变。

消费者接入须在本独立契约合并之后；这次只交当前读取与验证，不能据此宣称国别投递漏项或发送前复核已经修复。

TASK0468在契约合并后接入内部消费者：初次取稿与目标锁内复核共用当前候选、静默和卡片逻辑。总目标按seat，国别按当前有效国家；实际传输前重新核对事实去重身份及启用时刻，当前payload与发送内容一致。本地模拟回归不构成渠道启用或真实发送验收。

目标围栏内遇未来发刊/同标题租约仍属于等待：正常及自动恢复保留not_sent重试时间且不消耗尝试，人工未知记录保持人工核对。到期复核通过后沿同一投递与去重身份发送，不以永久skipped替代暂缓。
