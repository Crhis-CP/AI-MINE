## 12. 每周节奏（建议）

- **周一**：Owner 回答本周 Q 卡片（不回复则按默认做法推进；硬前置类卡片除外——例如评分标准矿业版审阅（T-0323）：未确认即不生效，也不推进依赖它的工作）；架构 Agent 以“计划 PR”发布本周任务卡。

- **周五**：质量 Agent 出本周验收记录（`docs/acceptance/`，环境验收与业务验收分行），按“产品阶段 + 完成程度（百分比）+ 已能自动做什么”向 Owner 汇报，格式为“做了什么 → 证据（按 F-ID 分维度）→ 没做什么 → 风险 → 下一步”。
