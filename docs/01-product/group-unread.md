# 聚合报道的未读筛选

精选页可只显示本浏览器尚未阅读的内容。聚合组的代表稿已读，但组内仍有未读精选报道时，保留整组；展开后标明各篇阅读状态。全部成员已读才隐藏该组，日期数量按当前实际可见卡片显示。

GroupInfo.memberIds为可选字段，由公共投影提供本组当前筛选内、可公开且入选的成员ID，去重并包含符合条件的代表稿。不包含私有、撤回、不满足许可或不符合当前筛选的文章，也不在读取时补写状态。成员集合必须与实际组的范围一致，不能仅依据同一事件号扩大。字段缺失只代表旧响应未提供成员集合，不代表全部已读；兼容显示保留可读组，不推断未返回的私有状态。

阅读标记仅在本浏览器保存。重载、返回、跨标签与筛选切换继续遵守现行内容修订和撤回核验；分页有上限并提供明确继续入口，不为寻找未读而无限抓取。空态区分本批都读过与全部已读，开关始终可返回完整列表。
