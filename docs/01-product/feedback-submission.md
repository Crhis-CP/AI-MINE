# 反馈提交规则

本页承接统一升级的反馈输入规则；与旧PG-15中的10字、自由联系方式、2MB和小时/站点日配额冲突时，以本页为准。单独契约合并不提前改变正式站限制，读者页与后台处理一起随最终版本发布。

- 反馈正文去掉首尾空白后，长度为2至5000，按JavaScript字符串长度计数；前端剩余字数、HTML长度限制和服务端一致。
- 邮箱可不填；填写时去掉首尾空白，最多200字符，并满足基本邮箱格式。旧邮箱字段仍叫email，不把其他任意联系方式伪装成邮箱。
- 可附一张PNG、JPEG、WebP或GIF图片，原始上传最多8MiB；按实际字节和解码结果确认格式，总像素上限6000万。保留私有存储、元数据清除、无效图片拒绝与后台鉴权；不能只信浏览器声称的类型。
- 每个不可逆客户端标识在当前API进程的滚动60秒窗口内最多5次新提交尝试，文字与邮箱校验通过后计数，图片无效也占用一次。幂等成功回执复用不重复消耗次数；进程重启后窗口重新开始。历史小时/站点日配额记录保留，但不再控制新提交。
- 原HTTP路径、multipart与兼容JSON输入、Idempotency-Key、站内相关页面校验和201响应不变。涉及冲突或过期提交编号仍明确报错；不绕开来源封禁。
- 反馈仍由既有独立私有群与后台处理，不发给模型；处理完成180天后的联系方式/截图清理与已有隐私说明不改变。

FEEDBACK_LIMITS和FeedbackSubmissionFields只提供共享验证定义，不注册新路由，不新增付费服务或第三方转发目的地。原始反馈和截图不能作为公开示例提交到仓库。
