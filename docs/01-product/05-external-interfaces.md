## 1. 共同规则

1. **同源一致**：所有出口从同一公开读取层读取，与网页内容一致；下架即时同步到所有出口（INV-02、INV-03）。
2. **匿名只读**：不需要注册与密钥；不能触发任何写操作、采集或模型调用（INV-01）。公开 MCP 按协议使用 POST，但只暴露只读工具。
3. **只公开白名单字段**：不公开模型、提示词、成本与用量、置信度、内部评分细目（两次评分的单次分值、门槛、评分提示词版本）、审核身份、未许可正文（INV-10）。**公开的评分只有条目的 `score`**——两次评分的平均值（向下取整），没有评分时为空、不出现 0（沿用 AIHOT，Owner 2026-10-01 已定，DEC-10；BR-SEL-07）；热点榜的机器出口只给名次，热度值只在网页（BR-SEL-05）。
4. **可追溯与署名**：每条内容带来源、原文链接、发布时间与精度，以及机器可读的发布方署名 `attributions`；RSS 与 MCP 文本前置“据〔发布方〕原文整理：”（INV-20）。【已实现未验证】（旧站 Agent 页公布的再利用约定，`apps/web/components/reader/information.tsx:18-22@main`）
5. **AI 标识**：详情、报告、RSS、API、MCP 显式标注“AI 辅助生成/翻译”，并带机器可读标识 `ai_label`；任何出口不出现“已复核/已核实/已审核”（DEC-38，D06-content-012）。
6. **下架与缓存**：下架后 60 秒内所有出口不可见；JSON 与 RSS 用 `max-age=0, must-revalidate` 加 `ETag`，HTML 页面 `max-age` ≤ 60 秒，不使用 `stale-while-revalidate`（DEC-48）。取代 A 原稿“浏览器缓存不超过 5 分钟”的口径。
7. **全文再分发**：权限矩阵取九项（DEC-58；新建信源九项一律“允许”，证据 `owner_declared`，只由逐源收紧关闭，DEC-33），另预留第十项“站外再分发”（`syndicate_fulltext`，不在 Owner 2026-10-01 的许可声明范围内，仍按 Q-47 默认关闭：取值默认“未知”、未知按禁止，是否启用见 Q-47）；该项启用前，公开 API 的阅读分块、全文 RSS、MCP 一律只给导读与原文链接，启用后只对允许的来源返回正文（D05-api-017）。站内页面按 `public_original_fulltext` / `public_translation` 判断，来源被逐源收紧后，已公开的全文或译文随之撤回（与下架联动）。
8. **限流与错误**：按客户端限流，超限 429 并带 `Retry-After`；错误体统一为 `{code, message, request_id, retry_after_seconds?}`（DEC-52）。
9. **只提供真实可用的能力**：说明页不放尚未实现的“安装”“订阅”按钮；Agent 接入页的每个示例请求都必须真实可用（Owner 要求）。
10. **版本**：公开 API 只做追加，破坏性变更发布新主版本并行一个发布周期（ADR-0013）。
11. **分页（DEC-23）**：读者站自用的站点接口 `/api/site/*` 用页码 `page` + `page_size`（默认 20，≤50），返回精确的 `total`、`has_more` 与当前条件下各北京日的条数，页码越界返回 200 与空列表，页码写进地址栏可分享、可跳页；对外公开 API 用不透明游标 `cursor` + `limit`（默认 20，≤100），不承诺总数，游标绑定筛选条件而不是全站内容版本；两个通道读同一读取层、同一排序（契约 §2.3；AC-OUT-11）。

## 3. 旧站地址：不做任何兼容（OUT-13【已废弃】；F-055 / F-PUB-06；DEC-21）

> **规则（Owner 2026-10-01）：新站不为旧站的任何地址做兼容或重定向；不存在的地址（含旧站地址）一律 404；新公开 API 用 `/api/v3` 前缀。**

- 这条规则取代 v2.0 的“旧公开路径处置表”（旧 RSS 与旧页面链接 301、旧机器接口 90 天适配期后 410、迁移响应头、调用量记录与退场公告）：这些内容全部删除，本包不再有旧链接对照表、旧接口映射或“本站已改版”专页。依据：Owner 说“旧文章链接也全都不要，相当于从 0 开始做文章内容”；新站从空库开始，不迁移旧站任何数据（DEC-20、DEC-42）。
- 404 的形态只有两种，都是新站通用的：页面类地址走通用“页面不存在”页（带首页与搜索入口）；接口类地址返回统一错误体 `not_found`（契约 §2.7）。不带 `Location`、`Deprecation`、`Sunset` 头，对旧站地址也不设 410 专门响应（接口里“对象已下架”的 `gone` 410 是新站自己的语义，与旧站地址无关，契约 §2.7）。
- `/api/v3` 前缀只为避免旧客户端打到同名路径拿到形状不同的响应，不承担任何兼容义务；公开 ID 不复用是新站自身的规则（INV-18）。读者浏览器里的旧本地收藏，新站忽略、不报错。
