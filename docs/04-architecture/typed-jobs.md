# 类型化任务入口

当前发送入口接受任意string/object，处理器自行重复声明类型，生产者和消费者可能各自通过编译却传错字段。统一使用contracts/jobs的JobData映射；动态调用保持name/data对应关系，扩展使用ModuleQueue<T>及enqueueOn，不把开放字符串重载留作所有调用的后门。

本次只定义纯类型，消费者在契约合并后接入。没有运行时解析器、数据库迁移、HTTP变化或新队列；原队列积压、singleton、事务提交、次数、回执与停机语义均保留。新发送的JobData必须带lane；仅供旧积压消费的LegacyJobData允许省略lane。消费入口按真实来源/材料确认业务线，拒绝显式错线的载荷，不能把缺省解释成news或已授权处理；ProcessingPermit仍由执行入口核对。旧sources.fetch继续按来源真实业务线转交，再退役无消费者兼容层。

类型错误在既有typecheck覆盖发送和注册调用时发现。行为验证复用现有真实队列事务、停机、模块批处理和暂停恢复用例，不为类型表增加重复运行测试。模块批任务必须逐条回写结果，不能把整批结果当单一作业回执。
