## 背景

A 包把运营台设计成独立应用（admin-web、运营子域、api 运营端口、13 个功能区、M1 17 页），把死信重试、模型切换、权限审定等设计成人工日常操作；B 包方向正确但没写私有能力的载体。Owner 不使用终端，“命令”不能作为人的载体。

## 决定

1. **不设运营台**：没有总览页、审稿关卡、审计查看页、采集运行页、系统健康页；正常生产没有任何人工步骤。
2. **必要私有操作只有六组**，以“最小私有页面”承载：
   | 私有页面 | 承载的操作 |
   |---|---|
   | 账号（OP-01/15/16） | 登录、退出、修改自己的密码；负责人增停具名管理员、重置其密码（只用密码，服务端会话；DEC-05） |
   | 信源（OP-03/04/05/07） | 新增（加入时由负责人一次确认，按 Owner 声明许可建档）、试抓预览、启用、暂停、恢复、归档（按业务线的采集配置分别操作）；逐源逐项收紧权限开关（关闭后即时生效并联动撤回已公开内容）；robots 与 http 例外（留审计）；原始信源表对账（只读） |
   | 内容（OP-09） | 查找条目/事件/法规文书，下架、恢复、人工修订（中文标题、导读、正文、分类）；下架与恢复是独立命令，不混入审核 |
   | 用量与模型密钥（OP-12/13/20） | 查看本月用量与分线分能力明细、异常熔断状态与阈值（含预警记录；受控配置，负责人可调）、熔断后一键恢复、按业务线暂停/恢复处理、结果未知费用逐笔核对（不设月上限、提醒线与保底额设置项）；模型接入、密钥安全录入（只显示指纹）、每个环节指派模型（提交新路由修订，须经准入，ADR-0006）；告警渠道地址的安全录入（只显示指纹）、发送测试、未送达列表与告警规则只读清单（OP-20，修改渠道为高风险确认；这不是总览或系统页） |
   | 反馈（OP-14） | 读者反馈私有收件箱与处理状态 |
   | 网站资料（OP-17） | 关于、条款、隐私、联系方式等站点资料，以及 ICP 备案号、公安联网备案号、互联网新闻信息服务许可证信息（受保护配置，Owner 经安全方式提供；生产环境任一备案号未配置则公开站不得开放） |
3. **运行状态改为告警推送**：采集连续失败、某 lane 最老积压超阈值、发布新鲜度超阈值、用量提示（月内累计每增加 100 元）、用量预警（熔断指标达阈值的 70%）、异常熔断触发、死信、磁盘、备份失败、质量资格即将到期等，推送到 Owner 指定渠道——**渠道已定**【Owner 决定】2026-10-01（DEC-06）：飞书群自定义机器人 Webhook 为主、邮件为备（Owner 在告警渠道页〔OP-20〕经安全弹窗录入机器人地址与备用邮箱，加密保存、只显示指纹；`worker` 才能解密）；告警渠道至少两条独立路径，Owner 录入前渠道未就绪，不得宣布上线；随首次生产部署上线。（**2026-10-06 改为飞书自建应用**，只发飞书，不做邮件备用，见 08-owner-voice DEC-33；本条原文不改）
4. **载体**：不另起应用。私有页面是 `apps/web` 内需登录的独立路由组，只在私有主机名（配置项 `PRIVATE_HOST`）上响应；公开主机名访问私有路径返回 404 且不带 `Set-Cookie`；私有路由代码按路由拆包，不进入公开页面包；私有页面沿用读者站视觉与 `packages/ui`。`apps/api` 同一镜像以 `private-api` 角色运行私有路由组：接口前缀 `/api/admin/*`（`03-data/contracts/interface-behavior.md` §2.1；只读运维 MCP 在 `/mcp-ops`），只接受私有主机名，全部要求会话、防伪令牌，写操作与审计同事务；私有路由归各模块的 `privateRoutes`，没有一个“后台模块”（`03-module-map.md` 第 6 节）。
5. **首个负责人**由部署方在服务端一次性开通（没有公共 HTTP 开通端点），初始密码经安全渠道交给 Owner，首次登录强制改密（DEC-43）。
6. **架构必备的保留组件**（旧ADR-0037:37-38）：只读 MCP（面向开发 Agent，经服务身份，脱敏）、服务身份（worker、只读 MCP 不依赖浏览器会话）、费用回执、审计（照写，不设查看页；经只读 MCP 或导出查询）、持久下架。
7. **不做的事**：不提供把逐条重试、逐条审稿、逐条翻译、手工发布当作日常流程的页面、队列或待办；死信由自动策略重试，超限告警，缺陷修复后由受控服务身份按批重放（ADR-0005）。**唯一例外**是内容页上针对瞬时错误的单条“安全重试”工具（F-EDT-04、OP-09）：只对可安全重试的原因开放，保留已成功步骤，结果或费用未确认的步骤不提供重试，没有批量重试，正常供稿不依赖任何人去点它（验收 T-127 第⑥项“连续 7 天无人登录”）。这一例外的取舍见裁决表 DEC-63。
8. **拆成独立进程的触发条件**：私有页面依赖无法与公开包隔离，或安全审计要求物理隔离。

## 后果

- 不再有 admin-web 应用、运营子域与 api 运营端口（ADR-0008 作废）；私有能力的工作量压缩到六组页面；
- Owner 不需要每天打开任何后台；需要知道的事由告警推送过来；
- 私有页面的范围只减不增：新增私有操作需 Owner 点名，并登记在本表。
