# ADR-0029：退役未使用的任务金额上界

- 状态：【Owner 决定】已接受（Owner，2026-10-25；本轮对话明确“一周约50元不是预算上限，不设固定金额，但费用归属要可查”，DEC-77）
- 类别：Owner 决定 + 工程落地
- 日期：2026-10-25
- 决策者：Chris确认费用原则，Codex实施兼容退役
- 关联规格：DEC-77、成本与用量、TASK-0482

## 背景

周/月累计金额停止逻辑已按Owner要求停用，但网关还暴露可选TaskBudget参数，能按任务累计金额阻止调用。仓库现存生产调用方均未设置，只有旧功能测试引用；它与本轮不设固定金额的原则不符。历史尝试仍可能记录任务金额上界字段，不能据代码退役删除账目。

## 决定

1. 移除内部TypeScript网关的taskBudget参数、传播和任务金额准入/发送前阻断；独立PR更新所有仓库调用点，不更改HTTP契约。
2. 历史task_key/task_limit_micros列及其值保留，旧调用的费用/未知状态和价格证据不改写；它们不再作为新阻断条件。
3. 回执、滚动请求次数、人工停用和原异常检测保持。报价缺项仍明确未知，费用估算用于追溯，不成为固定金额上限。

## 后果

旧源码调用方不能再声明该参数；本仓库没有生产使用者，旧编译对象即使携带额外字段也不会启用金额门槛。回退旧程序可能恢复对历史字段的旧处理，具体发布须说明该差异；不生成新的历史任务上界。

## 推翻条件

无（Owner决定）。若以后提出新的金额限制，须另由Chris明确决定。

## 备选方案

保留可选参数但默认不用，仍可能在后续评测中误用，故不选。
