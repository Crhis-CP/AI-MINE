# ADR-0022：首次公开前切换到九类矿业分类契约

- 状态：已接受（九类产品定义已定，两张精确路径计划已合入；运行时按本ADR后续联合激活）。
- 类别：工程基线；不替代 Owner 已定的分类、范围或评分决定。
- 日期：2026-10-04
- 决策者：架构集成人；执行依据 TASK-0005 与 TASK-0010 的九类联合激活计划。
- 关联：BR-ENR-14、DR-100、DEC-26、DEC-42、DEC-64、ADR-0002、ADR-0013。
- 取代：仅取代新仓导入阶段六个 AI 分类键的过渡契约；不取代既有公开字段形状或最终 v3 业务规划。

## 背景

`packages/contracts/src/taxonomy.ts` 仍导出 ai-models、ai-products、industry、paper、tip、opinion；行业词表、结构化标签与 v1/RSS 的 tip/opinion 合并也沿用该含义。TASK-0005 D2 保持六键是当次 import 迁移的边界，不是最终矿业分类决定。正式九类及稳定 ID 已在 `01-product/09-glossary.md` §3、DR-100 写定。只替换前端标签会让模型判定、存储值与公开筛选含义不一致。

新站尚未首次公开，旧站代码与数据不导入。新仓已有的合成/内部分析、手工修订或同步账本仍可能含旧键；不能假定数据库永远为空，也不能把无依据的旧键自动映射成矿业事实。

## 决定

1. 九类按以下稳定 ID 与顺序公开，中文显示名使用全称。分类依据本条新增可证事实的核心动作；不按发布方、热度或评分 itemType 推断，九类不是主题轴。

| ID | 中文全称 |
|---|---|
| policy_regulation | 政策监管 |
| company_project | 企业与项目 |
| commodity_market | 商品与市场 |
| capital_ma | 投资并购 |
| supply_trade_controls | 供应链、贸易与制裁 |
| esg_community_labor | ESG、社区与劳工 |
| safety_incident | 人身与生产安全 |
| technology_processing | 技术与加工 |
| exploration_resource | 勘探与资源 |

2. 替换闭合枚举按 **breaking** 处理；联合激活时 public OpenAPI 预发布版本从 0.1.0 改为 0.2.0，私有版本保持。现有 URL、字段名、string/null 形状、分页/游标与同步 schemaVersion 字段、MCP 身份不随此片变动；不把本次前置改造伪称为 additive，也不顺带交付最终 v3 的 Labeled 对象。
3. 无法判断为 category=null，公开不显示待定/未分类标签。旧六键没有可靠的一对一映射时同样公开归一 null；私有原分析、回执、人工字段与账本原件保留，既有 snapshot/changes 的 default/minimal 出口也归一。不得重写旧值冒充新分类，不因无分类阻断已确认范围的中文稿公开。
4. 分类键属于 contracts；中文名、定义、guide 与标签属于 industry；两者无反向包依赖，通过集成测试核对身份与顺序。依赖分类的模型配方须包含实际注入配置摘要，避免改了 guide 仍复用旧分类回执；不重算未变的预筛和评分回执，不自动发起付费重跑。
5. 计划/本 ADR 先行。允许先交未激活的九类 schema、归一/配置摘要纯助手和必要用例；公共枚举和生成文档保持旧运行态。随后一个可运行的联合增量同批接通新键、行业 guide/标签/提示词、实际分析与发布、旧账本出口、真实页面和生成 public client，移除 tip/opinion 合并。不能先切前端标签或发布半套新文档。
6. 联合增量超400有效行时，先拆行为不变的归一、标签与配方准备，再原子激活；保留必要回归。生成物按既有规则单列，不压缩代码、删除测试或放宽数据归属预算。Task5 是契约/联合交付卡，Task10 提供行业消费。
7. 不修改评分 ITEM_TYPES、selection-score、精选阈值、模型路由/参数、报告选材和出刊时间；不启用来源或真实模型，不导入旧站数据。真实分类质量与矿业样本校准独立验收，合成测试不作为人工金标。

## 后果

- 页面、筛选、API/RSS/MCP 与同步数据使用同一九类语义；未知保持诚实，不通过旧键重标制造事实。
- 首次公开前的新仓内部工具/夹具须适配枚举断点。用九类、null、旧键、非法键与人工修订回归真实处理/发布/读取链，保留 ETag304、缓存截止、错误媒体类型、取消和中文降级行为。
- 私有生成物保持字节不变；原件和已合并迁移不改。执行路径与验证清单以两张任务卡为准，本 ADR 不表示已激活、模型质量合格或网站已上线。

## 推翻条件

若发现此新站契约已被外部生产消费者采用，或需要改变字段形状/可靠旧键映射，先另立 ADR 明确迁移方案；不得静默延用“首次公开前”假设。九类产品定义的改变仍以 Owner 新决定为准。

## 备选方案

| 方案 | 未采用原因 |
|---|---|
| 仅改六个标签，或将旧键映射到“相近”矿业类 | 数量和语义不一致，无法根据历史类型确定矿业核心事实 |
| 永久公开新旧15键或先换枚举后补业务 | 延续上游分类含义，或在中间运行态造成 schema/页面/模型互相冲突 |
| 清空原分析/账本、自动付费全量重跑 | 丢失可审计原件或产生未授权付费，不是分类契约切换所必需 |
