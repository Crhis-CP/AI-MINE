# ADR-0027：资讯日期筛选统一按时间线北京日期

- 状态：Owner 已接受（2026-10-12）；实现与部署分别验收。
- 决策：Owner 对 F2-RDR-009 选择“按时间线北京日期统一”。
- 依据：BR-TIME-08、AC-OUT-12、DEC-67；契约 TASK-0313，消费者 TASK-0314。

资讯站点、搜索、公开条目和事件目录的 `on/from/to` 均筛选 `timeline_at` 的 Asia/Shanghai 自然日，与列表日期分组及“今天”一致。日期范围包含起止两日，查询转换为北京起日零点至结束日次日零点的左闭右开区间；单边范围只限制对应边界。事件目录按符合日期条件的公开成员筛选。

来源发布时间未知，但具备当前公开资格的内容，可以按其已有时间线日期被检索；不填造来源日期，不更改发布时间、发现时间、日期精度或旧文归期。法规的生效、签署等法律日期不受此决策影响。参数形状及现有排序选项保持，API `by=published` 只决定排序，不改变日期筛选口径。

这是筛选含义的破坏性修正，替代公开契约中“按来源日期且排除未知日期”的旧说明。只为带日期条件的条目/事件游标加入语义版本绑定，旧口径游标返回既有 `invalid_cursor`，客户端重新从首屏读取；无日期条件的游标保持原行为。统一分支联调后仍由 PR208 独立交付契约；没有生产发布或旧数据迁移。

验证覆盖北京午夜前后、来源日与时间线日不同、来源日期未知、单日与单边/双边范围、旧文不入今天、列表/搜索/分面/API/事件目录一致，以及日期条件游标重新读取。
