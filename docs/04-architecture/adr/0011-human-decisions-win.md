# ADR-0011：人工决定永远优先于自动结果；人工不作发布关卡

- 状态：【Owner 决定】第 1、4 条——下架对未来采集、发布、升级持久有效、恢复须显式操作（旧ADR-0031）；正常内容自动公开、不以任何名称恢复逐条审稿（旧ADR-0037:21-22@policy，2026-09-26；DEC-14）。第 2、3 条为【设计】工程基线。
- 修订：2026-10-01 按 Owner 答复修订——第 1 条补“旧站的下架与人工修订记录不导入新站”（全重做，DEC-20）；自动流程与升级不得复活或覆盖新站自己的人工下架与修订，这一点不变。
- 类别：Owner 决定（产品层）+ 工程基线
- 关联：INV（人工下架/修订不可被覆盖）、`02-rules/01-business-rules.md`（BR-EDT）、ADR-0004、ADR-0018

## 决定

1. 人工下架（条目、事件、发展线、法规文书版本）立即覆盖所有公开出口（页面、搜索、收藏解析、报告、API、RSS、MCP、分享图），重采集、回填、重处理、软件升级都不能使其复活；恢复一个对象不会连带恢复另一个独立下架的对象。旧站的下架与人工修订记录不导入新站（Owner 2026-10-01 全重做，DEC-20）：新站按自己的相关性与准入规则重新判断，Owner 可在新站重新下架；新站自己的人工下架与人工修订，自动流程与升级不得复活或覆盖。
2. 人工修订（中文标题、导读、正文、分类、事件归属）与自动稿分开保存（editorial 模块只写自己的表，publication 投影时叠加；人工归组存在 events 自己的表），自动流程不能覆盖已生效的人工修订。
3. 模型原稿与每次修改都保留记录；人工写操作与审计在同一事务提交，审计写入失败则回滚该操作且不提示成功。
4. 正常内容自动公开；人工不作发布关卡。机器无法解决的少数异常以告警推送给负责人，人的处理动作限于最小私有页面的下架/恢复/修订（ADR-0018）。审稿工具默认关闭，只用于建设期抽样与标注；人工精选能力随精选上线、仅负责人可用（DEC-14）。
