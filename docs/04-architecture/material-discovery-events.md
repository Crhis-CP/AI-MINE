# 材料发现通知

已验证目录在保存变更材料时，通知安装模块继续处理。MaterialDiscovered只带实际业务线、来源ID、材料ID和原有目录唤醒哈希；不携带正文、凭据、人工状态或模型选择。字段沿用现有目录到法规任务的身份语义，旧队列名称和载荷不变。

引擎调用安装模块的on.materialDiscovered回调，模块依据lane决定是否接收，并在同一数据库事务中通过类型化队列定义安排后续工作。回调返回是否接收；没有模块接收时不能把材料更新与唤醒当成已完成。失败回滚，重复哈希沿用原单例键，人工暂停、修订和许可仍由原入口核对。引擎不导入具体模块，也不硬编码模块队列名字。

本契约片仅声明消息类型与交接规则。模块挂口、目录发送端与法规接收端在合入后同时接线；现有目录完整性、事务、重复、失败和队列用例继续验证，不另建事件平台，不更改公开HTTP或生产状态。
