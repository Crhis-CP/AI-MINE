# 手机导航扩展

WebModule.tabs声明已安装模块自己的手机底部入口，使用既有ModuleNavigation的地址、标签、图标和activePaths。核心保留精选、热点、日报和个人页面，模块入口排列在日报后、个人页面前；全部动态从精选顶部切换进入，原/all地址保留。

定义只来自受信任仓库模块，不接受读者数据作为代码、路由或图标。重复入口应在组装时拒绝，入口数量改变时网格同步布局，不保留固定列数。一个页面只高亮一个对应入口；已拥有独立底部入口的模块页不再同时高亮个人页。现有后台、收藏与侧栏声明保持可选兼容。

金属价格由自身模块声明入口；通用网页不硬编码矿业扩展的路由。法规入口及已发布内容继续保留，本声明不恢复法规后台处理。
