## 做什么

**AI矿策（AI Mining Policy）是矿业领域的 AIHOT**：7×24 小时从政府与监管机构、官方公报与法规库、交易所、矿企和行业媒体自动采集，用 AI 整理成可信、可追溯、以中文为主的矿业资讯与政策法规情报（面向中文读者的全球矿业资讯与政策情报产品）；读者免登录、匿名只读，外部 Agent 通过 API、RSS、MCP 调用。读者包括非专业人士，也要看得懂。核心价值是降低读者的**发现、判断、去重、核验**四种成本，每个功能都要能回答它降低了哪一种。

**总原则**（Owner 2026-10-01，DEC-64，共五条）：① **基础是 AIHOT**——新项目以 AIHOT 开源项目的功能和底层框架设计为基础；② **改造内容以本交接包为准**——本包（两份交接包交叉比对、完善优化后的完整版，加上 Owner 历次明确的想法）写明了怎样把 AIHOT 改成 AI矿策 的矿业版（功能、规则、页面、法规政策线、信源、内容标准等），写明的以本包为准；③ **本包没写到的，照 AIHOT 的现有设计并矿业化**——把评分标准、提示词、分类、话题换成矿业的；Owner 点名要学 AIHOT 的有精选评分机制、评分规则与显示、热点榜、同一事件折叠成一张卡、日报周报月报的选材与出刊时间；④ **明确不要的功能不移植**——模型榜与 Codex 重置监控直接删除，模型厂商标志、AI 话题与提示词等只对 AI 行业有意义的内容同样删除；⑤ **新建仓库，沿用 Owner 现有的服务器与域名**（仓库默认名 ai-mining-policy，私有），旧仓库只读存档，旧代码与旧数据一概不迁移。本包是功能文档交接包，新团队据此在 AIHOT 基础上全面重写；**旧代码、旧数据、旧仓库文件一概不带**。

## 为什么重建

旧项目（123 个 PR 与 57 个 Issue 共用 #1–#180 编号，其中 119 个 PR 已合并；36 份 ADR；20 个服务目录）的补丁式迭代留下了沉重包袱：三代数据模型并存、整站 JSON 快照（冷读 5–12 秒）、20 个服务目录共享数据、多套规则与模型网关并存但大多未接线、过度治理。最关键的产品结果——**信源接入**——停滞：原表 320 个目标中，启用身份经只读回执核实的仅 13 个（另有 8 个表外来源，合计 21，不能再加 8），持续供稿核实的目标为 0（旧项目接入进度，2026-09-15 更新）。这些数字分属不同口径、互不推导；口径名、日期与出处只看 `01-product/07-sources-and-coverage.md` §0.2 的数量口径表（全包数量的唯一出处）。Owner 于 2026-09-29 决定：旧代码只作证据，以 AIHOT 开源源码为工程基建，以本交接包为唯一依据重建。此前 2026-09-26，Owner 已批准法规政策主线与不依赖 GitHub Actions（旧ADR-0037、旧ADR-0038；旧分支部分实现、未合并、未上线）。2026-10-01，Owner 进一步明确：旧数据与旧仓库文件一概不带，全重做（总原则 DEC-64；DEC-20、DEC-42）。

## 最重要的规则（节选）

**收录与公开**

- 全部矿业动态**宽收录**，只拒绝明确无关；纯获奖、参会、空预告不收，含具体项目或经营信息的照收（DEC-12）。同一事件在全部矿业动态里折叠成一张卡（代表稿 + “另有 N 家来源报道”，沿用 AIHOT 的事件卡与事件页），搜索与筛选仍按篇显示（DEC-25）。
- 精选、热点另算，永不拦截全部动态；二者沿用 AIHOT 的评分机制、规则与显示并矿业化，随全面切换上线，旧 55/70/65/75 公式等自设参数作废（DEC-10）：有评分的条目显示“AI 评分 · NN”，没有评分的条目什么都不显示；矿业版评分标准是草案，生效前必须先交 Owner 审阅确认。
- 日报、周报、月报从精选候选里取材（同一事实去重，受版面容量限制），导语与综述由模型写；出刊时间沿用 AIHOT（日报每天 08:00、周报每周一 10:00、月报每月 1 日 10:30，北京时间）；全量内容在“全部矿业动态”里看（DEC-65）。
- 外文新稿公开条件：**中文标题 + 导读 + 可取得且获准的完整中文正文**；摘要不计全文；不编造译名（未核实的公司名公开页只写原名）；原生中文稿不等模型；全文翻译全部分段完成才标“全文”（DEC-35、DEC-37）。
- 法规线：取得官方原文与必要附件，完整中文，有据解读；不把不合格法规降成摘要继续公开；影响评估只做公开通用的条件化分析，不输出数值分、不做特定企业结论（DEC-11）。
- 只有日期的来源不显示时分；旧文不进“今天”、不进报告；资讯线报告的出刊时间与窗口沿用 AIHOT，跨过刊期边界才确定精选公开时间的归入下一期，不设“补录”小节，历史期不改写（DEC-65、DEC-49）；法规线周月汇总仍按北京时间自然周、自然月。
- 事件：拿不准就分开；同一政策的不同阶段是不同事件、同一政策线。

**安全、成本与合规**

- 人工下架与人工修订永远优先，任何自动流程与升级都不能复活或覆盖；下架 60 秒内全出口不可见。
- 付费调用先回执后调用，结果未知不重发（人工核对只改该笔回执，不改月度总额，DEC-55）；不存在月度金额上限，异常熔断（达到阈值的 70% 先预警，达到阈值才熔断）只停付费、不停公开；不降级（DEC-08、DEC-09）。
- 读者请求永不触发采集、模型或写操作；公开出口不暴露模型、提示词、成本；公开站匿名只读，收藏只存本机。
- 全局暂停必须带原因与到期时间，停更要告警推送；以内容新鲜度为健康信号。
- 每个公开页面页脚同时展示 ICP 备案号与公安联网备案号（任一未配置则公开站不开放），关于页与页脚展示新闻信息服务许可证编号；AI 生成内容显式与隐式标识。
- 新站空库起步：旧站数据一概不导入，不从旧仓库导出任何文件；旧链接、旧 RSS、旧接口不做兼容，不存在的地址一律 404（DEC-20、DEC-21、DEC-42）。
