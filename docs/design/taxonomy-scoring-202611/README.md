# 分类与评分重设计：基于线上文章的分析（第二版，待 Owner 确认）

> 2026-11-05。Owner 同日要求：分类不是非改成 6 类，要根据网站实际的文章量判断；评分一定要合理，可以学习 AIHOT。
> 本版取代第一版草案（第一版的 6 类方案是凭经验拟的，没有用数据，已撤回）。Owner 确认之前，代码、提示词和线上评分都不改。

## 数据从哪里来

- **来源：**2026-11-05 从线上公开接口读取，只读、限速，没有动生产数据库。
  - **全站总数：**接口按分类和“精选”筛选后返回的 `total`。公开资讯池共 7115 篇（另有约 1370 篇被预筛拦下，不公开），精选 550 篇。
  - **逐篇数据：**最近 3.4 天的全部 736 篇，加上全站每 5 页抽 1 页共 1280 篇，合计 2016 篇，来自 278 个信源。每篇都有标题、分类、分数、是否精选。
  - **近一个月的精选：**2026-10-08 以来入选的 144 篇，逐篇读取。
- **限制：**
  - 公开数据里没有信源分级（官方 / 准官方 / 媒体），也没有两次评分各自的分数；
  - 线上目前用的是整数评分的旧版本，一位小数的新版本要等这次部署后才生效。

看出四个问题：

1. **“企业与项目”太大**，占三成，选它等于没筛。抽样里这一类的标题大致三种：
   - 业绩、产量、指引、成本、分红，约 31%；
   - 审批、开工、扩建、投产、停产，约 26%；
   - 合同、融资，约 12%。
2. **两类太小，筛出来几乎是空页：**“供应链、贸易与制裁”占 1.6%（一个月约 4 篇），“矿山安全”占 2.2%。但这两类的入选率最高，内容重要。
3. **约 15% 的文章没有分类：**主要是会议论坛、领导致辞、访谈观点、行情评论、人事和股东会。九类里没有它们的位置。AIHOT 对这类内容有“观点”“教程”两类，并标为“评论性”，在日报里另行处理。
4. **“技术与冶炼”多是设备商软文：**占 10%，入选率只有 1.6%。

## 二、评分现状

| 指标 | 数据 |
|---|---|
| 分数分布（2016 篇） | 0–29 分 41%；30–49 分 28%；50–59 分 16%；60–69 分 12%；70 分以上 3% |
| 分数扎堆 | 一共只出现过 71 个不同的整数；最常见的 5 个值（22、58、42、12、62）占全部的 43% |
| 近一个月精选 | 144 篇，平均每天约 5 篇，最近 3 天平均每天 3.3 篇，约占每天新文章（约 220 篇）的 1.5–2% |
| 精选的分数 | 60、62、78 三个值占了精选的三分之二 |

逐篇看下来，有五个问题：

1. **精选太少，日报凑不满。**
   - 每天只有 3–5 篇精选，而日报的设计是正文最多 12 条（沿用 AIHOT）。
   - 不少分量很重的新闻停在 60–74 分没进精选，例如：
     - 哥伦比亚撤销 15 个特别矿区、释放 530 万公顷勘探空间（74 分）；
     - 印度内阁批准锂镍加工激励（74 分）；
     - Waratah 首次资源量 310 万盎司（72 分）；
     - Viridis 与索尔维签稀土包销协议并设价格下限（71 分）；
     - Gold Fields 称对 Northern Star 的 230 亿美元收购不保证达成（67 分）。
   - 原因是媒体稿的门槛照搬了 AIHOT 的 76 分。AI 圈几乎每件事都有官方原帖，所以 AIHOT 可以对媒体从严；矿业新闻多数靠行业媒体首发，这样卡就漏掉太多。
2. **噪声封顶只压住了一个维度，总分照样虚高。**
   - 现行规则写的是“煤、铀、砂石内容份量 ≤1”，但只封了“份量”这一项，其他四个维度照样加分。结果：
     - 煤矿延期开采 42 分；
     - 钢厂技改投产 40–55 分；
     - 单日铜价涨跌 31–56 分。
3. **重要事件反被低估。**
   - “印尼拟下调 2027 年镍矿生产配额”只有 53 分。
   - 规则里没写清：主要产国的配额和出口政策、大矿下调产量指引，属于本站读者最关心的事。
4. **官方信源门槛低（60 分），放进了与矿业关系不大的一般政务文件。**
   - 例如林草局、农业农村厅转发的《美丽中国建设成效考核办法》（66 分）、《严格规范涉企行政检查》（68 分），以及《紧急采购管理暂行办法》（62 分）。
   - 同一批里真正相关的也有：探矿权注销、探矿权出让征求意见、矿山顶板安全、出口管制条例。
5. **行情资讯站刷屏。**
   - 长江有色金属网、上海有色网、我的钢铁网三家占抽样的 13%，平均 34–40 分，没有一篇入选；
   - 内容多是单日行情和钢铁产业新闻。

## 三、AIHOT 现在怎么做（2026-11-05 读取上游主干）

| 做法 | AIHOT | 本站现状 |
|---|---|---|
| 评分框架 | 先判内容类型，五个维度各打 0–10 分，按类型加权成 0–100 分；“必须正常评价”“必须压住”两张清单；每篇独立打两次分 | 已沿用；本次部署后改为一位小数 |
| 门槛 | 按信源分级：官方 60 / 准官方 65 / 媒体 76 | 照搬，没有按矿业重新校准 |
| 信源类别 | 有些官方信源日常内容多、读者只看其中的大事（如芯片云服务、评测榜单），给它一个类别，门槛抬到 70 或 76 | 没有 |
| 浏览下限 | “全部动态”默认不显示平均分低于 40 的文章（多是转述和刷屏，曾占三分之一以上），搜索仍能搜到全部 | 没有 |
| 展示分类与评分类型 | 分开：展示用 6 类（模型、产品、行业、论文、教程、观点），评分用 7 种类型 | 合在一起，都是 9 类 |
| 校准方法 | 由读者口味的人标 100–200 条样本（多放难例），扫描 40–90 分的门槛；先改评分标准，再动门槛 | 没做过矿业样本校准 |

## 四、新分类建议：9 类，但重新切分

数量还是 9 类，按实际文章量重新切：
- 拆开占三成的大类；
- 合并太小、太散的类；
- 给“没有分类”的那 15% 一个位置。

| 新类 | 收什么 | 来自现在的 | 估计占比 |
|---|---|---|---:|
| 政策监管 | 法规、许可、税费、准入、执法、矿权制度；出口管制、关税、配额、制裁 | 政策监管 + 供应链、贸易与制裁 | 约 21% |
| 生产经营 | 产量、业绩、指引、成本、分红、停产复产 | 企业与项目（一部分） | 约 14% |
| 项目建设 | 审批、可研、开工、扩建、投产、工程合同 | 企业与项目（一部分） | 约 13% |
| 勘探资源 | 钻探结果、资源量、储量 | 勘探与资源 | 约 11% |
| 并购融资 | 收购出售、合资、融资配售、上市、包销协议 | 投资并购 + 企业与项目中的融资 | 约 9% |
| 市场价格 | 价格、库存、供需、官方统计、行情分析 | 商品与市场 + 没分类的行情评论 | 约 12% |
| 技术装备 | 采选冶工艺、设备、数字化 | 技术与冶炼 | 约 9% |
| 安全环境 | 事故伤亡、救援、环境事件、社区与劳资冲突、ESG | 矿山安全 + ESG、社区与劳工 | 约 8.5% |
| 会议观点 | 会议论坛、致辞、访谈、研报观点、人事 | 新增（现在没有分类） | 约 10% |

估计占比按 2016 篇抽样的标题关键词推算，只用来看分布，不是最终数字。

改完以后：
- 最大的一类从 30% 降到约 21%，最小的一类不低于 8%，不再有“没有分类”；
- 名字都是 4 个字，电脑上一行能放下；
- “贸易管制”“关键矿产”这类跨分类的话题，改用“主题”页呈现。分类管“发生了什么类型的事”，主题管“涉及哪个话题”。

**历史文章怎么办：**
- 政策监管、勘探资源、并购融资、市场价格、技术装备、安全环境六类，可以从旧类直接换算，不调用模型；
- “生产经营”和“项目建设”是从旧的“企业与项目”拆出来的，“会议观点”的来源是现在没有分类的文章。这三类的历史文章（约 3200 篇）需要用便宜的分类模型重分一次。按每篇约 1000 个 token 估算，总计约 320 万 token，费用以 Codex 跑之前报出的预计数为准，要 Owner 批准。

**接口：**分类是公开 API 的一部分（v3 接口、RSS、MCP 都在用），改分类属于不兼容变更。要另立 ADR-0023；旧分类在网址和接口参数里继续接受，自动换算成新类。

## 五、新评分建议：保留 AIHOT 框架，改四处

框架不变：五个维度、按类型加权、两张清单、两次打分取平均、一位小数。改的是下面四处，每一处都对应第二节的问题。

### 1. 门槛按矿业重新校准（对应问题 1）

按现有分数测算（未去重，同一事件多家报道会重复计数）：

| 统一门槛 | 每天够分的篇数 |
|---:|---:|
| 60 | 26 |
| 62 | 16 |
| 64 | 10 |
| 66 | 7 |
| 70 | 4.5 |

- **建议起步值：**官方 62、准官方 64、媒体 66。预计每天 8–12 篇精选，同一事件去重后约 6–10 件，日报能排满。
- **最终数值**用 Owner 标注的样本扫描后再定（见第六节）。如果扫描结果显示三档可以统一，就统一成一个门槛，这样读者看到的分数和是否入选能直接对上。

### 2. 噪声改为总分封顶（对应问题 2、5）

- 评分模型除了五个维度，另给一个“噪声类型”字段，由代码按类型把总分封顶。规则在代码里，模型改不了，和现在“材料残缺封顶 30 分”的做法一样。

  | 噪声类型 | 总分上限 |
  |---|---:|
  | 与金属矿业无关：煤、铀、砂石，钢铁及下游加工，一般建材 | 30 |
  | 会议论坛、致辞、获奖、人事、例行分红与回购 | 35 |
  | 只报单日涨跌的行情，没有基准、单位或时间窗 | 40 |
  | 与矿业没有直接关系的一般政务文件（综合考核、采购、行政检查） | 40 |

- 第一项“钢铁及下游加工”是新加的，请 Owner 确认：本站读者关心的是铁矿石，不是钢厂技改。

### 3. 写清本站读者最关心什么（对应问题 3）

“共振面”这一维的定义里写明加分情形：
- 涉及中资企业或中国市场；
- 涉及法规线的 36 个国家和组织；
- 涉及重点金属。

“必须正常评价”清单里补上矿业的高价值例子：
- 主要产国的产量配额、出口政策和矿权制度改革；
- 大型矿山下调或上调产量指引；
- 十亿美元级的并购和扩建；
- 首次资源量和储量升级。

### 4. 学 AIHOT 的“信源类别”和“浏览下限”（对应问题 4、5）

- **信源类别：**在后台给信源加类别，门槛只抬不降：
  - “综合政务”：林草、农业、市场监管等非矿业部门，以及各省厅“要闻”栏目，门槛不低于 70；
  - “行情资讯”：价格网站的日常行情栏目，门槛不低于 72。
- **浏览下限：**“全部动态”默认不显示平均分低于下限的文章，搜索仍能搜到全部。按现在的分布：

  | 下限 | 不显示的比例 |
  |---:|---:|
  | 20 | 17% |
  | 25 | 35% |
  | 30 | 41% |

  - 建议从 20 起步，先藏会议通稿、例行公示这类；
  - 25 分附近还有不少正常的小新闻（例如 BlackRock 增持 Northam 5%、Endeavour 续展回购），不宜一下子藏掉。

### 不改的

- **证据维度保持现状：**第一版草案提的“证据封顶”，在线上数据里没有看到对应的问题（传闻进精选），这次不改。
- **两次打分、推荐理由、分数显示（一位小数）**都不变。

## 六、怎么确认、怎么上线

1. **Owner 标注样本（AIHOT 的校准方法）：**
   - 我从线上文章里挑约 120 篇难例：分数在 45–80 之间，各分类都有，同一事件只留一篇；
   - Owner 逐条标“该选 / 不该选 / 两可”。标注页是 [label.html](label.html)，手机上直接点选，不显示现有分数，免得先入为主；120 篇候选和它们的现有分数在 [gold-candidates.json](gold-candidates.json)；
   - 标完先用现有分数扫描门槛，这一步不调用模型；再用新规则在同一批样本上重评，用 `scripts/eval-selection.ts`，调用次数约 120 × 2，先报预算再跑。
2. **对比结果交 Owner：**
   - 新旧两版的准确率、查准率、查全率；
   - 每天预计精选数；
   - 入选结果有变化的文章清单。
3. **Owner 确认后实施：**
   - ADR-0023；
   - 分类契约和英文词典；
   - 提示词、权重、噪声封顶、门槛、信源类别、浏览下限；
   - 历史文章重分类（报预算）；
   - 部署任务书改评分版本号。
4. **本次部署照常进行：**新界面和一位小数评分先上线。一位小数能直接缓解分数扎堆，24 小时审计里的分数分布正好作为改进前的基线。
