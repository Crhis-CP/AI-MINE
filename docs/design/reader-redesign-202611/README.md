## 现状诊断

依据：现有截图 `docs/assets/reader-preview/`、`apps/web/app/app.css`、`components/Logo.tsx`、规格 `docs/01-product/03-reader-pages.md`。

1. **品牌识别弱。** LOGO 只有“AI矿策”四个字；主色是标记为“临时”的 slate `#475569`。版式、暖纸色背景、正文字号和动效节奏都和上游项目几乎一样，读者分不出这是一个矿业产品。
2. **入口和层级。** 首页一打开就是按时间排的卡片流，没有“今天先看什么”。13 个分类标签横向排开，超出了屏幕。国家筛选要先选下拉框，再点“筛选”按钮，多了一步。
3. **卡片占位多、信息少。** “推荐理由”每张卡片都占一整行。矿业读者最关心的矿种、国家、项目阶段、有几家独立来源，反而没有突出。
4. **价格和监管日期离得远。** 金属价格单独一页，征求意见截止日、施行日之类的日期没有集中展示。读到一条资讯时，看不到它所处的市场背景和监管日程。
5. **规格要求、但还没做的部分。** 桌面端主区页脚、“公开内容更新于……（北京时间）”这两项还没做（通则 24、1.2 节）。

## 矿业读者的阅读逻辑

“去哪里，看什么，是否当真”：

1. **先定位**：哪个矿种、哪个国家或地区、哪家公司。
2. **再看阶段**：勘探、审批、建设、投产、贸易、关停；监管是在征求意见、已公布，还是已施行。
3. **核实可信度**：有几家独立来源，有没有新增事实，原文在哪里。
4. **结合背景**：价格最近怎么走，接下来有哪些监管日期。

三个方向都按这个顺序组织：先放今日要点，然后是常驻筛选（矿种、国家、产业链、公司），卡片上显示独立来源数和新增事实，页面旁边放价格和监管日历。法规页统一用“生命周期 + 关键日期 + 要点对照”，这样排是为任务书工作流 3 预留的。

## 设计依据与约束（实施时照此执行）

- **品牌约束**：不用上游品牌色（`#176b75`、`#2ce2e8`），不用 RingMark、环形 O、四角星和青绿色（`scripts/verify/names.json`，Q-16、Q-67）。三个方向都已避开。
- **评分规则**：
  - 85 分及以上用暖红，70 分及以上用强调色，其余用灰色。
  - 没有评分什么都不显示。演示数据里的第 8 条故意不给分，用来演示这种情况。
  - 手机列表上只显示分数数字。
- **AI 标识与声明**：
  - 导读、解读都标“AI 辅助”。
  - 法规页写明“以官方原文为准，不构成法律意见”，注明来源，并附更正和下架入口。
- **排版**：
  - 正文 17–18px，行高 1.8 左右。
  - 每行不超过 38 个汉字（`max-width: 37–38em`）。
  - 标题使用 `text-wrap: balance`。
  - 数字使用等宽数字（tabular-nums）。
- **无障碍**：
  - 第一个可聚焦元素是“跳到主要内容”。
  - 键盘焦点可见。
  - 触控区不小于 44px，筛选标签不小于 36px。
  - 表格放在可聚焦的滚动区里。
  - “减少动态效果”时，所有动效全部停止。
- **字体**：
  - 中文一律用系统字体（苹方、鸿蒙、思源黑体），不下载中文网络字体。
  - 拉丁字体只用 10–19KB 的 WOFF2 子集，自托管，符合 CSP `'self'`。
  - 许可证见 [shared/fonts/OFL.txt](shared/fonts/OFL.txt)：SIL OFL 1.1，所选字体都没有声明保留字体名。
- **读者端不加动画库**（`docs/04-architecture/02-tech-stack.md`）：原型里的动效全部用 CSS 和 View Transitions 实现，可以直接搬进现有代码。

## LOGO 收敛：铜 · 青铜 · 铁 · 硅晶（2026-11-04）

Owner 认可“三金旋 · 晶核”的方向，提了三点修改：

1. 三道都用金色，容易让人联想到紫金矿业，要改。
2. 改用人类自古以来用得最多的金属作为配色。
3. 旋臂加长，背景以代表大自然的绿色为主。

[logos-v8/](logos-v8/) 是修改后的结果，样式图见 [style-boards/logos-v8.webp](style-boards/logos-v8.webp)。

## LOGO 第 10 轮：星系（2026-11-04）

Owner 对第 8 轮（孔雀石绿底）和第 9 轮（星空背景，未提交）的评价是“背景颜色好丑”“更丑了”。Owner 要求：在三金旋的基础上修改，学习矿业资讯网站的设计，配色参考 GPT、Claude、Grok、Cursor 这类图标。另外给出的品牌设计要求是：高级、经典、一眼认得出，不追潮流，经得起时间。

[logos-v10/](logos-v10/) 是这一轮的结果，样式图见 [style-boards/logos-v10.webp](style-boards/logos-v10.webp)。

- **诊断**：前两轮让三条旋臂用三种不同色相，又加了绿底、星空、星云和立方体晶核，画面显得杂乱、廉价。这次参考的几家 AI 图标有共同之处：只用一个颜色家族，只有一个形状，层次靠明暗来表现。
- **定位**：网站把分散在各国、各种语言、各个来源的矿业消息和法规收拢起来，整理成清楚的变化。标识的三条旋臂由外向内收进一个核心，表达的就是这件事。
- **主标（长期不变）**：墨色旋臂（#14161A）加铜色核心（#C8612C），平涂，单色版也成立。旋臂按黄金螺线构建，半径每转 90° 放大 φ 倍，三条臂之间相隔 120°。两端收尖，头部贴着核心。最小尺寸：屏幕 16 像素，印刷 6 毫米。
- **App 图标（可以随时代更新）**：同一个形，提供四种质感：三金·微光（推荐）、曜石银、地层银、铜辉。
- **矿业资讯网站调研**：读了 14 家中的 9 家首页，色值都从 CSS 或 SVG 读取；Mining Weekly 等 5 家被反爬拦截。
  - 金色和琥珀色已经很拥挤：Kitco、Benchmark 用作主色，Northern Miner、长江有色、我的钢铁网用作点缀。
  - 藏蓝在数据服务商里很常见：Argus、我的钢铁网、上海有色网。
  - 红色和绿色在价格表里表示涨跌，而且中外相反：上海有色网红涨绿跌，Kitco 是绿涨红跌。
  - 由此确定配色为墨、纸加一点铜。
- 只借各家的思路，不使用任何一家的形状和颜色；没有做商标检索。
- **结果**：Owner 认为这一版“也不是特别好看”，要求重新设计。同时提出新命题：AI 引领矿业，矿业是 AI 的根基，造型用柔和曲线。重新设计改按 [brand/logo-brief.md](brand/logo-brief.md)（LOGO 任务书 v2）执行，第 1–10 轮只作为参考。任务书 v2 不再沿用三段绕中心旋转的结构，因为 ADL 仇恨符号数据库收录了三曲纹（triskele）及其曲线变体。
