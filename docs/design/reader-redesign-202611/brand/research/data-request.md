# 请 Codex 导出的网站数据（第 1 阶段）

> 这段话由 Owner 转给 Codex，Claude 不在 GitHub 上留言。导出的数据只用于品牌研究，不能包含任何个人信息。

**请从生产环境导出以下统计数据（只要汇总数，不要原始记录）：**

1. 最近 30 天入库的条目数，分别按以下维度统计：
   - 矿种（`industry/taxonomy.ts` 的 `MINERAL_TAGS`）；
   - 国家（`COUNTRY_TAGS`）；
   - 9 个分类；
   - 来源语言。
2. 最近 30 天读者打开最多的 20 个国家和 20 个矿种。如果没有这项统计，注明“无”即可。
3. 最近 30 天站内搜索的前 30 个搜索词（只要词和次数）。
4. 访问设备的比例：手机和电脑；微信内置浏览器单独列出，如果能区分的话。
5. 日报、周报、月报各自的打开次数。

**格式**：一个 JSON 或 Markdown 表格，放到 `docs/design/reader-redesign-202611/brand/research/site-data-<日期>.md`。

**约束**：不导出 IP、用户代理原文、邮箱、反馈正文或任何能识别个人的信息；数量少于 5 的项合并为“其他”。
