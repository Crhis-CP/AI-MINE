# AI矿策标识规范 v1：五臂星系（定稿 2026-11-04）

## 寓意

五条暖金色旋臂紧贴着一颗发光的核心：

- 旋臂代表人类从矿业积累下来的金属，核心代表 AI；
- 金属托住核心，核心带动整个星系旋转；
- 合起来就是：矿业是 AI 的根基，AI 引领矿业。

## 文件

| 文件 | 用途 |
|---|---|
| `icon.svg` | App 图标、社交头像、180px 以上的展示。浅色象牙底，9 级金色渐变，核心发光 |

| `construction.svg` | 构建图 |

## 色彩

- **主渐变**：从中心向外分 9 级，依次为 `#FFF4D2` `#FCE8AE` `#F7DA8C` `#F0CA6E` `#E8B957` `#DEA746` `#D09439` `#BE812D` `#A06A1E`。
- **小尺寸渐变**：依次为 `#B07B22`、`#956218`、`#7A4B10`，核心用实心 `#7A4B10`。
  - 在纸色上对比度不低于 3.35:1；
  - 在白底上不低于 3.68:1。
- **配色**：底色为象牙 `#F6F4EF`，深色场景用墨色 `#14161A`。

## 构建

- 共五条旋臂，彼此相隔 72°。
- 每条旋臂沿对数螺线展开，参数如下：
  - 起始半径 5.0，终止半径 20.5（48 网格）；
  - 扫角 200°，最大宽度 4.8，宽度在 30% 处达到峰值；
  - 头部紧贴核心，尾部收尖。
- 核心半径 3.2。
- 生成脚本：会话草稿目录中的 `v10/geo.py`（`edges4`）和 `s/s.py`。精修后要并入 `scripts/brand-icons.ts`，届时以仓库内版本为准。

## 使用规则

- **安全区**：四周至少留出一个核心直径的 2 倍。
- **最小尺寸**：屏幕 16px，印刷 6mm。32px 以下改用 `mark-small.svg`。
- **不要这样用**：
  - 改变旋臂数量，尤其不要改成三臂；
  - 给五条旋臂分别换颜色；
  - 加星空、星云等花哨背景；
  - 拉伸、倾斜；
  - 加描边或投影。
- **字标**：目前用 Noto Sans SC Bold 和 Instrument Sans SemiBold，两者都是 OFL 许可。定制字标完成后替换。
