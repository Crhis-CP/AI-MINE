# 第 2 阶段：草图筛选记录

- 共 86 张草图，分属 9 个隐喻：M1–M8 见 [../research/metaphors.md](../research/metaphors.md)；M9 是“AI 字母”，作为字标方向的对照。
- 打开 [index.html](index.html) 可查看全部草图，红框标出的是入选稿；入选稿的检查结果见 [checks.html](checks.html)。
- 每稿先过一票否决项：倒置、镜像、16px、单色下有没有歧义；再按评分表快速比较。

## 入选 8 稿

| 稿 | 入选理由 | 检查结果 |
|---|---|---|
| M8-01 广 · 石 | 对中文读者一眼是“矿”（石 + 广），剪影简单 | 16px 清楚；拉丁读者可能读成 r |
| M8-03 双层檐 | 檐由两道地层构成 | 16px 下两线粘连 |
| M8-07 四分之一拱 | 剪影最重，最稳 | 偏几何，曲线少 |

| M4-04 矿脉卵石 | 曲线最柔和，最自然 | 16px 下像带条纹的球 |
| M6-02 等高线 | 和方向 C 呼应 | 线细，16px 消失 |
| M9-04 i 在矿上 | “资讯”的 i 立在矿上 | 16px 偏弱，像小人 |

## 进入第 3 阶段的三条路线

| 路线 | 来源稿 | 理由 |
|---|---|---|
| A 广 · 石 | M8-01 | 线形 |
| B 矿洞之光 | M5-03 | 实形 |
| C 矿脉 | M4-04 | 有机形 |

三条覆盖三种造型语言，彼此差别最大。

岩芯也试做过两版：一版是 i 形，看起来像小人；一版是平头的地层柱，看起来像电池。两版都不如卵石，所以没有进入第 3 阶段。
