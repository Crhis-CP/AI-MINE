## 背景（为什么做）

INV-46 要求每个公开页面都显示备案号：ICP 备案号链接工信部备案查询；公安联网备案号带公安备案图标，链接全国互联网安全管理服务平台（验收场景 T-130）。现在三处各写一份：桌面侧栏（`Sidebar.tsx`）、“更多”页（`more.tsx`）、手机页脚（TASK-0034 新增的 `MobileFooter.tsx`），三份都没有公安备案图标。

公安联网备案 Owner 已经提交、在等审核（DEC-39 2026-10-05 更正）；号下发后集成人只在 `industry/site.ts` 填一次，三处要同时、同样地显示图标、文字和链接。所以先把三处合成一个组件，再填号（TASK-0034 交付记录：公安备案图标由本卡做，本卡合并前不填号）。

互联网新闻信息服务许可证：个人备案拿不到，页脚与关于页都不显示（DEC-40 2026-10-05 更正）。`industry/site.ts` 里 `newsLicense` 是 `null`，三处和关于页都是“有号才显示”，所以现在已经不显示。本卡保留这个字段和关于页那一行，组件照样“有号才显示”：DEC-40 更正要的是不显示，字段为 `null` 已经做到；Owner 定的规矩是不擅自删功能。规格里 INV-46、F-RDR-20、T-130 的新闻许可证与“备案号没配置就不开放公开站”由 TASK-0051 写回（从登记卡 TASK-0031 拆出的规格写回卡），本卡引用这三处时以 TASK-0051 写回后的版本为准；本卡按 DEC-39、DEC-40 的更正做。

## 交付内容（做什么）

1. **共用组件** `apps/web/app/components/shell/Filings.tsx`：
   - 输入：显示的位置（侧栏 / “更多”页 / 手机页脚，只决定字号与颜色，沿用三处现在的样式）和备案号（默认取 `industry/site.ts` 的 `SITE`，测试可以传入）。
   - ICP 备案号：文字是 `SITE.icp`，链接 `https://beian.miit.gov.cn/`。
   - 公安备案号：官方图标 + `publicSecurity.text`，整体是一个链接 `https://beian.mps.gov.cn/#/query/webSearch?code=<publicSecurity.code>`；图标在文字前，`alt` 为空（旁边已有文字）。
   - 链接都在新窗口打开（`target="_blank"`、`rel="noopener noreferrer"`），每个链接带 `data-filing="icp"` 或 `data-filing="public-security"`，给测试认。
   - 新闻许可证：`SITE.newsLicense` 有值时照现在三处的写法输出“互联网新闻信息服务许可证：<号>”（不加链接），为 `null` 时不输出。
   - 哪个号没有就不输出哪个，三个都没有就什么都不输出，不写占位。
2. **三处改用组件**：`Sidebar.tsx`、`more.tsx`、`MobileFooter.tsx` 原来各自的备案号写法（ICP、公安备案号、新闻许可证）换成组件；三处的位置、顺序与其他链接不变。关于页那一行新闻许可证不在三处之内，不动。
3. **图标**：用全国互联网安全管理服务平台提供的官方公安备案图标，由 Owner 电脑上的会话从官方网站下载（地址在平台页面上找，本卡起草时没有核实），提交到本卡实施分支的 `apps/web/public/filings/public-security.png`。下载地址、时间与 sha256 写进交付记录，并在组件文件头用一行注释写明出处。
   - 放 `apps/web/public/` 而不放 `industry/brand/` 的理由：`industry/brand/` 里的站点图标由 API 进程按固定清单发出（`apps/api/src/routes/static.ts`），这些地址还登记在共享契约 `packages/contracts/src/http-policy.ts` 的 API 路径里，加一个就要改契约、加一条公开路由和它的角色夹具；公安备案图标是官方标识，不是本站品牌，只在网页上用。`apps/web/public/` 的文件由网页构建原样带上、网页服务器直接发出（`.png` 已在它认的类型里），不经过 API，也不用改契约。
4. **测试**：
   - `apps/web/tests/filings.test.ts`（组件单测）：在测试里用 Vite（`@amp/web` 已有的开发依赖，`ssrLoadModule` 或同等办法，不连网）加载 `Filings.tsx`，传入测试用的号码（例如 `{ icp: "测试ICP备00000000号-1", publicSecurity: { text: "测试公网安备00000000000000号", code: "00000000000000" } }`），三种位置各渲染一次：都有图标、文字和带这个 code 的查询链接，ICP 链接也在；再传一个测试用的新闻许可证号，三种位置都输出它；只给 ICP 时没有公安备案的任何元素（没有图标、没有 `beian.mps.gov.cn`、没有 `data-filing="public-security"`），也没有新闻许可证；三个都没有时输出为空。
   - `apps/web/tests/cache.test.ts`（页面测试，用现在的配置：有 ICP、没有公安备案号）：桌面侧栏、`/more` 页正文、手机页脚三处都有 `data-filing="icp"` 的链接；三处和关于页都没有公安备案的任何元素；`newsLicense` 为 `null`，三处和关于页都没有“新闻信息服务许可证”字样；`/filings/public-security.png` 能取到（200、`image/png`）。

## 输入输出与错误状态

- 输入：`industry/site.ts` 的 `icp`、`publicSecurity` 与 `newsLicense`。输出：三处页面上的备案号链接与许可证号。
- 错误与边界：号是 `null` 就不输出；`publicSecurity` 只有在 `text` 与 `code` 都有时才输出（类型就是这样定的）。
- 数据与事件所有权：只改网页；不改行业包，不涉及数据库、接口与事件。

## 明确不做

- 不填公安备案号的数值（号下发后由集成人另开一个小 PR 填，那个 PR 附产品更新片段）。
- 不附产品更新片段：本卡合并后读者看到的和现在一样（仍只有 ICP 备案号，位置、样式不变），号填进去时才对读者可见。
- 不删 `newsLicense` 字段，不删关于页那一行新闻许可证（DEC-40 要的是不显示，字段为 `null` 已经做到）。
- 不改规格里 INV-46、F-RDR-20、T-130 的旧写法（TASK-0051 改，以它写回后的版本为准）。
- 不改导航、页面布局与“更多”页的其他链接。
