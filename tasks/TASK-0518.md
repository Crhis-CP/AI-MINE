方向 C 的阅读页要求（DEC-78）：行宽约 37–38 个汉字、衬线字体开关、j/k 快捷键。阅读进度条和目录原来就有。

## 做了什么

- **行宽：**`.prose` 最大宽度为 `38em`，即每行约 38 个汉字。详情页的 AI 导读同样限宽。
- **宋体/黑体切换：**
  - 详情页操作栏新增“宋/黑”按钮（`components/ui/ReadingFace.tsx`），偏好只保存在本机浏览器（`amp-reading-face`）。
  - 页面首次绘制前，启动脚本就设好 `data-reading`，所以不会先闪一下黑体再变宋体。
  - 宋体只用系统自带字体：Songti SC、STSong、Noto Serif SC、思源宋体、SimSun，不下载任何字体。
- **j/k 快捷键：**`components/shell/Chrome.tsx` 中的 `ListKeys`，挂在公开页面外壳上。
  - 在列表页按 j/k，跳到下一条或上一条标题，并滚到屏幕中间。
  - 正在输入、按着修饰键或打开对话框时不响应。

## 没做什么

- 报道详情页（story）没有加宋体开关，因为它没有长正文。
- 没有加快捷键帮助面板。

## 验证

- `npm run typecheck` 通过；改动文件的 biome 检查通过。
- 在生产构建的隐私页上读取计算样式：
  - 默认是黑体；切到宋体后，字体栈为 Songti SC 一组；
  - `.prose` 宽度为 608px（16px × 38）。
- 本容器的无头 Chromium 读不到本机安装的思源宋体，所以截图里看不出宋体。苹果设备自带 Songti SC，Windows 自带 SimSun。
