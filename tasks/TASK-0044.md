- 2026-10-05 22:47Z：「我现在就需要有那个直接站内选定价格你想想看怎么样爬为尽量能免费就免费」「一切在保质保量的情况下尽量的降低成本」。

- 23:17:34Z 卡片「只用免费的」：不买 LME 等交易所的行情授权。
- 2026-10-06 00:28:46Z 卡片「全部金属」：国家统计局的铜、铝、铅、锌与 6 种钢材；世界银行的 LME 铜、铝、铅、锌、镍、锡，铁矿石，金、银、铂；IMF 的钴、钼、钯；没有锂。
- 00:49:38Z：「金属价格这个上线写写好这个可以给我看上线前问我」。

这些原话由登记卡 TASK-0031 记入 `docs/01-product/08-owner-voice.md`，本卡只引时间。对应功能 F-RDR-12 与它的规格卡 F-062（`docs/01-product/02b-functional-specification.md` :526-532）。

依据的是集成人 2026-10-06 写的价格表方案（要点都写进了本卡，实施不需要另找方案文件）：照上游导入提交 `f4392e1`（本仓库原样导入上游 `885b736` 的第一个提交）里有、后来删掉的模型榜（`packages/backend/src/leaderboard/**`）的抓取与刷新做法——仓库里的登记文件列信源和品种（本仓库放在行业包 `industry/` 下），每个来源一个抓取器，合理性检查不过就整期扣下，数据没变的重抓只更新“最后看到”的时间。来源条款（集成人 2026-10-05 的来源调研）：国家统计局允许以公共免费信息为目的引用，须在显著位置注明“转自国家统计局网站”并标明网址。

价格表分五张卡：本卡（存储与国家统计局抓取，只入库）、TASK-0048（规格写回，只改 docs）、TASK-0045（站内接口与页面，先显示国家统计局）、TASK-0046（世界银行）、TASK-0049（IMF、摘要提醒与检查脚本）。方案原来分三块、每块估 430–450 行，超过单卡 400 行的目标，所以规格写回单拆一张，世界银行与 IMF 各一张。本卡与 TASK-0048 先后不限，TASK-0045 在两者之后。TASK-0045、0046、0049 做好后一起给 Owner 看一次预览，Owner 同意前这三张都不合并；本卡只入库，可以先合。

本卡只入库，页面和接口都不出现价格，所以合并后 INV-47 的现行写法（授权行情落实前任何出口都不出现价格数字）仍然成立；部署后数据先在库里攒着，TASK-0045 合并后才显示。PG-11 的写回（TASK-0048）还没合、Owner 也还没看预览，先抓先存的理由：存进库里的只是官方公开发布的原数，读者看不到，Owner 不同意显示时不开页面即可；而国家统计局每旬只发一期、本卡不回填历史，晚开抓就少攒几期，预览时没有可比的上一期。

```sh
D=/opt/aimine/.ops/fixtures-raw/$(date -u +%F) && mkdir -p "$D" && cd "$D" || exit 1   # 原件就放在这里，不进 Git、录完不删
UA='Mozilla/5.0 (compatible; AIMiningPolicyBot/1.0; +https://aiminingpolicy.com/about)'   # 与正式站抓取时报的名字相同
rec() {   # rec <保存名> <地址>：存原件与响应头；record.tsv 记抓取时间、地址、保存名、HTTP 状态、最终地址、大小、sha256
  curl -sS -L --max-time 60 -A "$UA" -D "$1.headers" -o "$1" -w '%{http_code}\t%{url_effective}' "$2" > "$1.status"
  printf '%s\t%s\t%s\t%s\t%s\t%s\n' "$(date -u +%Y-%m-%dT%H:%M:%SZ)" "$2" "$1" "$(cat "$1.status")" "$(wc -c < "$1")" "$(sha256sum "$1" | cut -d' ' -f1)" >> record.tsv
}
rec nbs-robots.txt https://www.stats.gov.cn/robots.txt
rec nbs-terms.html https://www.stats.gov.cn/wzgl/202302/t20230217_1912857.html
```
