## 做法

- `scripts/brand-icons.ts` 从 `industry/brand/source/` 的母版生成全部图标，新增 `icon-96.png`、`icon-144.png`、`icon-maskable.png`，`apple-icon.png` 改为母版去掉圆角和细边线后的不透明方块（标志不变）；其余文件重新生成后逐字节不变。脚本改成导出 `brandIcons()`，命令行照旧 `node scripts/brand-icons.ts`。
- 头部图标声明放在 `apps/web/app/lib/icons.ts`，`root.tsx` 和测试共用；Organization 的 logo 地址也取自这里。
- api 按名称提供新图标，并在两个苹果默认地址提供 `apple-icon.png`；`http-policy.ts` 把这些路径交给 api（只增不改，契约 additive）。
- `scripts/smoke.ts` 加上新图标，部署后的整站检查会经网页进程实际取一遍。
- 读者片段 `changes/TASK-0559-site-icons.md`；`industry/release-note.json` 由集成人汇总，本卡不改。

## 没做什么

- 不能让 Google 立即换图标：Google 按自己的节奏重新抓取首页和图标文件，官方说法是几天到几周；部署后由 Owner 在 Search Console 请求重新编入首页。
- MCP 握手信息里的图标（serverInfo icons）没有加，那要改 MCP 契约，另开卡。
- 百度等其他搜索引擎的站点标识需在各自站长平台设置，本卡不涉及。
