## 背景（为什么做）

## 交付内容（做什么）

1. 新增 `packages/backend/src/lib/concurrency.ts`，导出 `export async function mapLimit<T, R>(items: readonly T[], limit: number, fn: (item: T) => Promise<R>): Promise<R[]>`，保持结果顺序。配 `tests/concurrency.test.ts`。
2. `v3.ts` 和 `v3-collections.ts` 里所有 `Promise.all(xxx.map((item) => v3Item(...)))` 改为 `mapLimit(xxx, 4, …)`。用搜索命令 `git grep -n "v3Item(" -- packages/backend/src/publication` 找全，在 PR 列出每一处。
3. `eventCoverage`：给 `loadItemDetail` 加一个可选的请求内缓存参数（例如 `{ coverage?: Map<string, …> }`），按事件 ID 缓存。同一次 v3 请求里同一个事件只算一次。缓存只活在一次请求里，不跨请求。
4. 测试：用测试库造 30 条精选，`v3Snapshot({ limit: 30 })` 的结果与改动前逐字段一致；同时在途的 `v3Item` 不超过 4 个（可在测试里包一层计数）。

代码量预算：实现约 80 行；测试约 80 行。
