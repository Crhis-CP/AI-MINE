## 背景（为什么做）

`docker-compose.yml` 固定的数据库镜像是 `postgres:17.11-alpine`（第 27 行），HTTPS 入口是 `caddy:2.11.4-alpine`（第 113 行）。Docker Hub 上已有 `postgres:17.12-alpine`（2026-11-12）和 `caddy:2.11.9-alpine`（2026-11-06）。Caddy 2.11.5～2.11.9 之间有多次安全加固。PostgreSQL 的小版本通常也带安全修复。

## 交付内容（做什么）

1. `docker-compose.yml:27` 改为
   `image: postgres:17.12-alpine@sha256:34261f594522cf41dfcb76aefd42b9d201098b0e6b23c9c68733f169e4218b6f`
2. `docker-compose.yml:113` 改为
   `image: caddy:2.11.9-alpine@sha256:0bbb055bda6793c999bde78b1b5ce3e89f829fb031af2cf50056ea1246559fee`
3. 两个摘要是 2026-11-12 从 Docker Hub 读到的多架构索引摘要。有 docker 时用 `docker buildx imagetools inspect <镜像:标签>` 复核，不一致以复核结果为准并在 PR 里写明。
4. 第 26 行注释里的 “T-0005 moves to PostgreSQL 18.6” 保持不动，本卡不升大版本。

代码量预算：只改两行镜像和必要的注释。
