Owner 2026-11-06：“充满科技感的动态设计”。对象是 TASK-0563 上线的更新日志“重大更新 2.0”收束线：细金线从五个环节一路收成一点，再分到三个出口。线形、配色和文字都不变，只让它动起来，看上去像一台正在工作的仪器。

## 做法

`AggregationFlow.tsx`，以及 `app.css` 里新增的 `flow-*` 动画：
- **光脉冲**：一小段发光的光沿每条线跑过去。被筛掉的线上的光随线淡出；留下的线上的光一直跑到出口。各条线的速度和起点错开，看上去连续不断。
- **扫描**：在“筛选”那一段，一道扫描线来回扫过，好比逐篇读过。
- **信号环**：
  - “归并”段末，几股线并到一起的地方有一圈光一闪即散；
  - “发布”的三个出口依次向外发出信号环。
- **准星**：“精选”的亮点外有一圈缓缓旋转的虚线准星，四周有刻线。
- **底纹**：浅浅的点阵网格，底边一排刻度尺。
- **代号**：每个环节编号旁加一个英文代号：INPUT、FILTER、MERGE、SELECT、OUTPUT。它是装饰，读屏会跳过。
- **手机**：竖排的线上光一段接一段往下传；“筛选”段有一道横向扫描线；“发布”的亮点外有旋转的虚线圈。

## 减少动态效果

- 全部动效用 CSS 动画实现，不再用 SVG 的 `<animate>`。
- 读者开启“减少动态效果”时：光脉冲、扫描线、信号环隐藏，准星停转，只剩静止的线图。
- 服务端和浏览器画出来的结构完全一样；不再需要等浏览器确认读者允许动画后才挂上动画。

## 测试

`apps/web/tests/changelog-page.test.ts` 断言：
- 页面里有这四种动效（`flow-pulse`、`flow-scan`、`flow-spin`、`flow-ping`）和五个代号；
- 页面里没有 SVG `<animate>` 或 `<animateMotion>`（这两种 CSS 停不住）。
