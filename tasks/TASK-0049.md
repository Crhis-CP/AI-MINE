## 夹具怎么录（实施前做，只录一次）

由 Owner 电脑上的会话登录上海服务器录；这一步同时就是“上海服务器能不能直连 IMF”的检查。Owner 说过“你可以直接用我的服务器”，这一步只是对官方网站的只读请求（可以和 TASK-0044、TASK-0046 的录制一次做完），不碰容器、数据库、配置和正在运行的网站，不用另问 Owner。

- 原件存在服务器上的 `.ops/fixtures-raw/<录制日期>/`（和 TASK-0029 放评测原始输出的 `/opt/aimine/.ops/eval/` 同在 `.ops/` 下），不进 Git，录完不删。
- 交付记录与夹具 README 逐个文件写地址、抓取时间、大小、sha256（就是 `record.tsv` 的内容）。
- 仓库里只放裁剪件：由录制的会话从原件裁出（裁法见“交付内容”第 6 条），连同 `record.tsv` 交给实施的会话（例如直接提交到本卡的实施分支，只加 `tests/fixtures/metal-prices/**`）。
- 第三方数据的标注与钴、钼、钯的序列代码，由录制的会话对着原件核对（只读），结论与原文位置写进交付记录。

```sh
D=/opt/aimine/.ops/fixtures-raw/$(date -u +%F) && mkdir -p "$D" && cd "$D" || exit 1   # 原件就放在这里，不进 Git、录完不删
UA='Mozilla/5.0 (compatible; AIMiningPolicyBot/1.0; +https://aiminingpolicy.com/about)'   # 与正式站抓取时报的名字相同
rec() {   # rec <保存名> <地址>：存原件与响应头；record.tsv 记抓取时间、地址、保存名、HTTP 状态、最终地址、大小、sha256
  curl -sS -L --max-time 120 -A "$UA" -D "$1.headers" -o "$1" -w '%{http_code}\t%{url_effective}' "$2" > "$1.status"
  printf '%s\t%s\t%s\t%s\t%s\t%s\n' "$(date -u +%Y-%m-%dT%H:%M:%SZ)" "$2" "$1" "$(cat "$1.status")" "$(wc -c < "$1")" "$(sha256sum "$1" | cut -d' ' -f1)" >> record.tsv
}
rec imf-robots.txt https://www.imf.org/robots.txt
rec imf-commodity-prices.html https://www.imf.org/en/research/commodity-prices
grep -o '<a [^>]*external-data\.xlsx[^>]*>[^<]*' imf-commodity-prices.html | head -n 3   # 找文件链接；版本说明在它附近
rec imf-external-data.xlsx '<上一步找到的完整地址；调研时是 https://www.imf.org/-/media/files/research/commodityprices/monthly/external-data.xlsx>'
rec imf-terms.html https://www.imf.org/en/about/copyright-and-terms
cat record.tsv
```

`curl` 失败、HTTP 状态不是 200、或拿到的是验证页，都按停止条件处理。

## 输入输出与错误状态

- 数据与事件所有权：IMF 与强制入库只写 `publication.metal_prices`；摘要提醒只读 `job_runs`（ops）；不发事件。
