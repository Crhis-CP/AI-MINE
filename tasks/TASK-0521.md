任务书 v2 工作流 1：英文界面放在 `/en`，用类型化词典；中文站的地址和链接保持不变。英文内容（每条资讯的英文标题和导读）本轮不做（Q5）。

## 做了什么

- **路由：**每个公开页面的路径前加可选段 `en?/`（React Router 可选静态段），首页用 `en?`。
  - `/all` 和 `/en/all` 共用同一个页面模块，路由 id 不变，中文地址完全不变。
  - 模块页面（法规、金属价格）同样处理。后台不变。
- **词典** `apps/web/app/i18n/`：
  - `zh.ts` 是源，`en.ts` 的类型为 `Dict`，由中文词典推出。英文缺键或多出键都会让类型检查失败，这对应验收要求“词典没有缺键”。
  - `useT()`、`useLocale()` 按路径判断语言；`fmt()` 负责填占位符。
  - `localizedPath()` / `basePath()` / `otherLanguagePath()` 处理地址；接口、订阅源、后台、图片等共用地址不加前缀。
- **链接：**`IntentLink` 在英文界面下自动给站内地址加 `/en`。`tabIsActive` 和手机页脚判断当前栏目时会去掉语言前缀。
- **已翻译的部分：**
  - 顶栏：栏目、“更多”、搜索、语言切换；
  - 桌面页脚；
  - 手机底栏；
  - “跳到正文”；
  - 资讯地图：全部文字；英文界面下国名用浏览器自带的 `Intl.DisplayNames` 显示（如 Chile）；
  - `<html lang>`。
- **语言切换：**桌面顶栏右侧有“English / 中文”按钮，手机“我的”页底部链接行里有语言切换，都跳到同一页面的另一种语言。
- **搜索收录：**英文界面带 `noindex, follow`，canonical 仍指向中文页，等 I2 上线时再去掉。

## 没做什么（I2 继续）

- 各页面正文区里的界面文字，如热点榜、筛选、卡片、文章页、报告、法规、“我的”页各分组，仍是中文，要逐页迁到词典。
- 资讯内容仍是中文，并保留原文链接。

## 验证

- `npm run typecheck` 通过；改动文件的 biome 检查通过。
- 用生产构建和演示 API 检查：
  - `/en`：lang 为 en，带 noindex，导航链接是 /en、/en/all、/en/hot，没有横向溢出；
  - `/en/all` 深色、`/en/more` 手机宽度：同样正常；
  - `/`：lang 为 zh-CN，没有 robots 限制，链接是 /、/all、/hot。
