## 交付内容（做什么）

1. **候选评分规则** `industry/prompts/selection-score-global.md`：以现行 `selection-score.md` 为底，只改口径不改结构，便于对照：
   - 读者改为全球矿业投资者与从业者，不偏向任何国家；
   - 第四轴“共振面”改为“影响面”：波及多少市场、国家和公司，占全球供需的份额，是否改变价格或政策走向，按全球、区域、局部三档给分；中国的事按影响面正常评，不加分也不打折；
   - 去掉专给中资的条目（“对华贸易措施”改为不论发起国和对象国的贸易措施；“中资企业的海外项目”并入大型矿企动向；小矿企例外里的“中资收购、与中资合作”改为“被大型矿企收购或合作”）；
   - “必须正常评价”加入资源国政治与安全风险：国有化与征收、合同重谈、权益金与税制大幅调整、出口禁令与强制本地加工、选举带来的矿业政策转向、民粹政策、社区封锁与大规模抗议、罢工、政变与制裁。
2. **候选预筛规则** `industry/prompts/prefilter-four-layers.md`：在现行 `prefilter.md` 上加四层 PASS：资源国法律政策；资源国政治与安全风险（含资源民族主义、民粹、选举、社区冲突、政变、制裁）；中国对外投资与中资动态；写明了对具体金属影响的下游需求与宏观。只谈宏观、没落到金属的仍 BLOCK。
3. **回放工具** `scripts/rules-replay.ts`（只读业务数据，只产生模型调用回执）：
   - 金标集：Owner 11-05 标注的 116 篇（不含两可），现行与候选评分规则各跑一遍，算与 Owner 标注的一致率、查准、查全，列出两版判断不同的篇目；
   - 最近 N 天打过分的稿件：只用候选规则重评分数可能跨线的那一段（旧均分 45–80），与线上结果比，列“多选了哪些、少选了哪些”；另抽一小批用现行规则重跑，量出模型自身的波动，免得把波动当成规则效果；
   - 最近 N 天被预筛挡掉的稿件：按抽样用候选预筛重判，新放行的再用候选评分打分，按天推算每天多收几条、其中几条会入选，附抽样；
   - 费用：每批调用后按回执累计实际费用，到 `--max-yuan`（默认 30）就停，报告写明停在哪一步；
   - 输出：JSON 和中文 Markdown 报告，写到 `--out` 目录；不写任何业务表。
4. **设计文档** `docs/research/selection-v2-20261113.md`：本次候选规则的口径；回放怎么看；之后“算法全部重做”的方案：事件级入选（同一件事按最好的那篇定）、入选的滞后保护（已入选的不因一次重评就掉出）、T1/T1.5/T2 的判定规则与“一手”按篇判断、参与方式简化、门槛是否统一（看回放数据定）。
5. **决定台账**：记 Owner 2026-11-13 定的事（3.1 规则、回放费用、热点榜规则、3.0 公告做法、信源扩到 1000 个的目标）。
