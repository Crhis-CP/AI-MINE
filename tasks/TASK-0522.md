在 TASK-0521 的基础上，把首页的阅读路径迁到词典。中文输出逐字不变：词典中文值就是原来的字面量，`npm run check` 的网页测试全部按中文断言通过。

## 做了什么

- **词典新增 `feed`、`hot`、`list`、`categories` 四组：**
  - 覆盖国家筛选、来源和分类标签、手机筛选面板、搜索框、来源/矿种/日期组合筛选；
  - 热点榜：趋势、“另有 N 家来源”、热度；
  - 日期分组、只看未读、空状态、加载与翻页；
  - 卡片：已读、推荐理由、收藏、来源署名；
  - 报道组：另有 N 家信源、N 条进展。
- **分类名：**英文界面用词典里的英文分类名（`useCategoryLabel`），中文界面仍用行业包的标签。
- **日期：**英文界面用 `Intl.DateTimeFormat`，按北京时区显示（Oct 4 · Sunday）；中文不变。
- **“精选”角标**已翻译。
- **中文内容标注：**英文界面下，资讯卡片和热点榜条目带 `lang="zh-CN"`，中文按中文字形显示（任务书要求“中文导读加 lang 标注”）。
- **工具：**迁移用的替换脚本只在本地使用，不进仓库。规则是：属性、对象字面量、三元式、文本节点里的中文字面量，换成词典键；每个组件注入 `useT()`。带变量的模板（如 `另有 ${n} 家`）手工改用 `fmt()`。

## 没做什么

## 验证

- `npm run typecheck`、`npm run check` 通过，中文网页测试全部通过。
