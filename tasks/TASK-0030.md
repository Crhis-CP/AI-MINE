## 背景

商务部是出口管制（锑、镓、锗、钨、稀土等）和对外投资规则的第一手来源，在 Owner 审核的首批信源里。它的列表页由脚本填充：浏览器向 `/api-gateway/jpaas-publish-server/front/page/build/unit` 发一个普通 GET，返回的 JSON 里 `data.html` 就是整段列表 HTML（链接、标题、`[2026-10-03]` 这样的日期）。现有的网页列表读取器只认 HTML 页面，读不到。

## 交付

- `web_list` 新增配置 `htmlJsonPath`（例如 `data.html`）：取回列表地址后按路径从 JSON 取出字符串，再用同样的选择器解析；相对链接按 `baseUrl` 补全。不是 JSON、路径上没有字符串时，这次采集明确失败，不静默当空列表。
- 改了 `htmlJsonPath` 等于改了日期从哪里来，计入日期配置哈希。
- 测试：本地假服务器返回这种 JSON，读出链接、标题和日期；不是 JSON、路径不对时报错。
