Owner 2026-11-05：LOGO 之外，字体、字号也要随之变化。本卡做视觉底座；方向 C 的版式留给 R3–R7。

## 做了什么

- **字体：**
  - 拉丁字母和数字改用 Instrument Sans（400/600/700），等宽数字和时间改用 JetBrains Mono 500。
  - 字体文件是 OFL 许可的 WOFF2 子集，放在 `apps/web/app/assets/fonts/`，由网站自己提供，共约 58KB，只预加载 400 一个字重。
  - `unicode-range` 不包含中文共用的标点（· — … “ ”），这些标点和中文一样仍用系统字体（苹方、鸿蒙、思源黑体），保持原宽度。
- **字号：**
  - 页面默认字号由 14px 改为 15px，筛选标签由 12px 改为 13px、高度不小于 32px。
  - 信息流、热点榜、外壳、详情页、报道、收藏、主题、更多、关于等读者页面中，15px 及以下的字号统一加大 1px，共 204 处；后台页面不动。
  - 长文正文（`.prose` 17/18px）不变。
- **配色：**中性色整体转暖，与象牙底、金色标识协调；强调色沿用 R1 的金色。
  - 浅色：纸色 `#f9f6f0`，墨色 `#221e19`。
  - 深色：暖炭 `#15130f`，暖白 `#ece6da`。
  - 灰青色的 `--note` 改为橄榄色。
  - 全部正文和弱化文字对各级底色的对比度都在 4.5:1 以上；最低是弱化文字在灰底上，浅色 4.61、深色 4.75。
- **浏览器颜色：**`theme-color` 和 manifest 的颜色同步更新；manifest 改用浅色底，与图标的象牙底一致。
- **分享图和海报：**
  - 站名改用金色字标图片 `industry/brand/lockup*.svg`；配色改为暖炭底加金色（分享图）、象牙底加金色（海报）。
  - `OG_TEMPLATE_VERSION` 和海报模板版本都已更新，已缓存的图会重新生成。
- README 截图已重拍。

## 没做什么

- 版式、导航、卡片结构都没有改，留给 R3–R7。
- 后台页面的字号没有改。

## 验证

- `npm run typecheck` 通过；`tests/media-performance.test.ts` 12 项通过。
- 用演示 API 对比改前改后截图（浅色、深色、手机），人工查看。
- 实际渲染了一张分享图和一张海报，确认字标和配色显示正确。
