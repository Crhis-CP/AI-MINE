## 交付内容（做什么）

1. **页面** `apps/web/app/routes/metals.tsx`（PG-11 档 2），loader 只经 `@amp/api-client` 取 `/api/site/metal-prices`，照首页的写法（react-router 的 `data`，首页里叫 `withHeaders`，加 `headers({ loaderHeaders })`）设缓存。页面只照接口画，不出现任何来源名、来源键与来源网址（第 3 条 verify）：
   - 结构：标题“金属价格”和一句说明 → 常驻提示“本页是官方定期发布的旬度或月度数据，不是实时、也不是每日行情；不同来源、基准和单位之间不换算、不比较。” → 接口给的各个分区（分区标题照接口写）→ 可折叠的“说明与许可”（默认收起；各来源的许可说明与条款链接，加接口给的那句 LME 的话）→ 官方查询入口（接口给的清单，新窗口打开）→“浏览矿业市场动态 →”（保留）。
   - 每个来源一块。表上方写来源、发布标题（链接原文；链接地址以 `.xls` 或 `.xlsx` 结尾时在链接后写“（Excel 文件）”，按地址判断，不按来源写分支，链接文字照原文）、发布日（有才写，只写日期）、币种、频率与发布延迟。
   - 表的列依次是品种、价格、单位、规格、基准/市场、所属期（Owner 已定）。手机上左右滑动时“品种”一列固定在左边，它右侧有一条细线和向右的淡阴影（表头与表身都有；用伪元素画，合并边框的表格里单元格自身的阴影画不出来；深色模式下照样看得见），看得出滑到下面的字是被盖住了。缺值写“暂缺”，不写 0；价格照接口给的数显示，可以加千分位逗号，接口给了小数位的块按它显示。表下面是出处行，原文照写、始终可见（国家统计局一块就是“转自国家统计局网站 https://www.stats.gov.cn”和“原文数据来源：中国统计信息服务中心、卓创资讯”两行）。表头写“所属期”；任何地方都不写“旬均价”“月均”，也不出涨跌。
   - 状态，每块只有一种：有数据（表格）；陈旧（表格保留，加“数据已陈旧”和最新一期的所属期）；没有数据（“暂无已授权价格数据”加这个来源的官方查询入口，不画空表、不写 0）。接口出错时页面标题与“浏览矿业市场动态”照常，正文只有一句“价格数据暂时无法读取”（没有任何一块、官方查询入口与 LME 的话，它们都来自接口；也不出现“暂无已授权价格数据”），页面回 HTTP 503（和 `loadOr404` 读不到接口时一样，搜索引擎不收录出错的页面）、不缓存（`no-store`）；正常时和现在一样 `public, max-age=0, s-maxage=300, stale-while-revalidate=600`。
   - 去掉“站内价格表尚未开通，暂无已授权价格数据。”这一句和写死的 LME 入口；页面描述（`meta`）改为说明官方定期发布的金属价格，不写来源名。
   - 手机上每张表包在单独横向滚动的容器里，整页不横向滚动。
   - 样式照首页的规矩（Owner 已定）：用站里已有的版式、字体、颜色与组件，不为这一页另起一套；编排是本站自己的，不照搬国家统计局页面（#162 评论 6010092753）。
2. **站点地图与冒烟清单**：`packages/backend/src/publication/sitemap.ts` 的静态条目加 `/metals`（任何状态都可收录，规格见 TASK-0048 改的通则 18）；`scripts/verify/names.ts` 的 `SITE_OUTPUTS` 加 `["/metals", [200]]` 与 `["/api/site/metal-prices", [200]]`（新库上国家统计局一块是“没有数据”，仍回 200）；`tests/fixtures/public-role-routes.json` 里 `sitemap.xml` 那一项的 `contains` 加 `/metals`。
3. **网页测试** `apps/web/tests/cache.test.ts`：原来那条“金属价格只有官方入口”的测试改写；合成接口按模式回有数据、陈旧、没有数据、出错四种（合成数据先过 `publicSchemas.MetalPrices.parse`）；出错那种断言页面是 503 加 `no-store`，另三种是 200。合成数据用编的来源名和分区标题（例如“合成来源甲”“合成分区”），页面照样画出来，证明页面只照接口画。断言表头的顺序；合成的月度块用 `.xlsx` 地址发布，断言链接后有“（Excel 文件）”且全页只有这一处；侧栏入口与“更多”页顺序的断言保留。

## 输入输出与错误状态

- 输入：`GET /api/site/metal-prices`（TASK-0045）。输出：`/metals` 页面、`sitemap.xml` 里的 `/metals`。
- 错误与边界：接口回 503 或读不到 → 页面回 503、只有“价格数据暂时无法读取”、不缓存；某个来源“没有数据” → 这一块“暂无已授权价格数据”加它的官方查询入口；某个来源陈旧 → 表格保留并标陈旧，不隐藏（PG-11）。
- 上线后发现显示错了：网站先回到上一个版本（发布的回滚规矩），修好后照常部署。
- 数据与事件所有权：页面只经 `@amp/api-client` 读接口；不写库、不发事件；读者请求不触发抓取（铁律 4）。
