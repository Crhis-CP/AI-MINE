## 交付内容（做什么）

1. **页面** `apps/web/app/routes/metals.tsx`（PG-11 档 2），loader 只经 `@amp/api-client` 取 `/api/site/metal-prices`，照首页的写法（react-router 的 `data`，首页里叫 `withHeaders`，加 `headers({ loaderHeaders })`）设缓存。页面只照接口画，不出现任何来源名、来源键与来源网址（第 3 条 verify），不按频率写分支（第 4 条 verify）：
   - 从上到下：标题“金属价格” → 接口的 `intro` → “最新一期” → 价格表 → “说明” → “官方查询入口” → “浏览矿业市场动态 →”（保留）。
   - **最新一期**：先一个小字“最新一期”，再照接口 `latest` 的顺序每项一段：频率小标签（`tag`，和表里的小标签同一个样式）加期名（`label`）；`extras` 的每一组接在后面的括号里，写“（<品种名用“、”连接> <期名>）”，例如“（铁矿石 8月）”；`stale` 为真的那一组，在它的期名后面写“数据已陈旧”；`label` 为空时这一项写“<小标签> 暂无已授权价格数据”。期名照接口给的写，页面不自己去年份。
   - **价格表**只有一张，列依次是品种、报价、价格、单位、较上期。每个品种一个 `<tbody>`，品种那一格是 `<th scope="rowgroup">`，`rowspan` 等于它的报价数；每个报价一行。报价那一格：先是这个报价的来源在 `sources` 里的 `tag`（页面按报价的 `source` 找，不认识频率），再是报价标题；标题按“ · ”分段，换行时脚注号跟着最后一段；`footnote` 不为空时，最后一段右上角是脚注号，链到说明里同号那一条（`#n<号>`，读屏读“见说明第 N 条”）；下一行小字写 `spec`，为空就不写。每行不写日期、不写取数方法。
   - **价格**照接口给的十进制文字加千分位逗号；接口给了小数位就按它四舍五入显示（世界银行的 `64.599999999999994` 两位小数显示 64.60；俄罗斯央行换算出来的长小数按两位显示），没给就照原数（`108770.0` 显示 108,770.0）。格式化直接用文字（例如把十进制文字直接交给 `Intl.NumberFormat`），不先转成浮点数。缺值写“暂缺”，不写 0，较上期那一格空着。
   - **单位**在电脑上是单独一列；手机上（390 像素宽）并到价格下面一行，单位那一列不显示，不用左右滑就看得到品种、报价、价格与较上期；表仍包在单独横向滚动的容器里（可以用键盘聚焦、有名称），整页不横向滚动。
   - **较上期**照接口的 `percent` 写，后面加“%”：正数前面加“+”、红色；负数把“-”换成减号“−”（U+2212）、绿色；`0.0` 不加号、不着色；接口没给就空着。颜色用站里已有的红、绿两种，正负号本身就说明涨跌，颜色只是辅助。品种与报价的顺序照接口给的，页面不排序、不自己算。
   - **说明**：标题“说明”，下面是一个有序列表，照接口 `notes` 的顺序每条一项；带 `ref` 的那几条加锚点 `id="n<ref>"`（脚注号链到这里；接口保证它们排在最前、从 1 连续，所以列表的序号就是脚注号）。`text` 里的 `{link}` 换成链接：文字是 `link.name`，指向 `link.url`，新窗口打开（另有读屏用的“（在新窗口打开）”）。原文照写，始终展开，不折叠。
   - **官方查询入口**：接口给的清单，照接口的顺序，新窗口打开；每一项只把 `name` 做成链接文字，`note` 写在链接后面、不放进链接里（上期所的免责声明只许链到它的首页、用交易所的名称作文字链接，见 TASK-0045）。
   - **几种状态**（写法是【设计】，TASK-0045 截图时告诉 Owner；标点与位置截图时定，Owner 说要改就改）：
     - 有数据：照上面写。
     - 某一类陈旧：“最新一期”里那一组的期名后面写“数据已陈旧”；它的报价照常显示，不隐藏（PG-11）。
     - 某一类没有数据：“最新一期”里那一项写“<小标签> 暂无已授权价格数据”；它的报价都写“暂缺”、较上期空着；页面下方的官方查询入口照常。
     - 全都没有（接口里一个报价都没有价格）：不画“最新一期”、价格表与说明（它们说的是表里的数）；只有标题、导语、一句“暂无已授权价格数据”、官方查询入口与“浏览矿业市场动态 →”。
     - 出错（接口回 503 或读不到）：页面标题与“浏览矿业市场动态 →”照常，正文只有一句“价格数据暂时无法读取”（没有导语、最新一期、价格表、说明与官方查询入口，它们都来自接口；也不出现“暂无已授权价格数据”），页面回 HTTP 503（和 `loadOr404` 读不到接口时一样，搜索引擎不收录出错的页面）、不缓存（`no-store`）；正常时和现在一样 `public, max-age=0, s-maxage=300, stale-while-revalidate=600`。
