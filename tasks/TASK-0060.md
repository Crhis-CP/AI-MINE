## 交付内容（做什么）

1. **页面** `apps/web/app/routes/metals.tsx`（PG-11 档 2），loader 只经 `@amp/api-client` 取 `/api/site/metal-prices`，照首页的写法（react-router 的 `data`，首页里叫 `withHeaders`，加 `headers({ loaderHeaders })`）设缓存。页面只照接口画，不出现任何来源名、来源键与来源网址（第 3 条 verify）：
   - 从上到下：标题“金属价格”和一句“官方机构定期发布的金属价格，照发布的原数显示，注明出处与所属期。” → 每个来源一行（照接口的顺序）：“<分区>最新一期：<最新一期>（<来源名>，<频率>）”，例如“国内最新一期：2026年9月中旬（国家统计局，每旬一期）” → 接口给的那句提示（“不是实时行情，也不是每日价格。”）→ 价格表 → “说明”（始终展开，不折叠）→ 官方查询入口（接口给的清单，照接口的顺序，新窗口打开；每一项只把 `name` 做成链接文字，`note` 写在链接后面、不放进链接里：上期所的免责声明只许链到它的首页、用交易所的名称作文字链接，见 TASK-0045）→“浏览矿业市场动态 →”（保留）。
   - 价格表只有一张，列依次是金属、报价、价格、单位、较上期。每种金属一组：金属那一格跨它的几行（`rowspan`），每个报价一行。报价那一格先写报价标题，下面一行小字写规格、“ · ”、所属期（例如“铜含量不低于 99.95% · 2026年9月中旬”；没有规格只写所属期；暂缺时只写规格）。
   - 价格照接口给的十进制文字加千分位逗号；接口给了小数位就按它四舍五入显示（世界银行的 `64.599999999999994` 两位小数显示 64.60），没给就照原数（`108770.0` 显示 108,770.0）。格式化直接用文字（例如把十进制文字直接交给 `Intl.NumberFormat`），不先转成浮点数。缺值写“暂缺”，不写 0，较上期那一格空着。
   - 较上期照接口的 `percent` 写，后面加“%”：正数前面加“+”、红色；负数把“-”换成减号“−”（U+2212）、绿色；`0.0` 不加号、不着色；接口没给就空着。颜色用站里已有的红、绿两种，正负号本身就说明涨跌，颜色只是辅助。金属与报价的顺序照接口给的，页面不排序、不自己算。
   - 手机上（390 像素宽）单位并到价格下面一行，单位那一列不显示，不用左右滑就看得到金属、报价、价格与较上期；表仍包在单独横向滚动的容器里（可以用键盘聚焦、有名称），整页不横向滚动。不再固定第一列。
   - 来源那一行的几种状态（每个来源只有一种）：有数据（照上面写）；陈旧（照写最新一期，后面加“数据已陈旧”，它的报价照常显示）；没有数据（“<分区>：暂无已授权价格数据（<来源名>，<频率>）”，后面接这个来源的官方查询入口，新窗口打开；它的报价都写“暂缺”）。标点与位置截图时定，Owner 说要改就改。
   - 全都没有价格（接口里一个报价都没有价格）时不画表：只有标题和那一句、各来源那一行、官方查询入口与“浏览矿业市场动态”；提示那一句与说明也不出（它们说的是表里的数）。
   - 说明：每个来源一段，把它的 `notes` 依次连成一段（某句末尾没有句号一类的标点就补一个“。”），段末接条款链接（`terms` 的名称，新窗口打开）；整页的 `notes` 每句一段。原文照写，始终可见。
   - 不画发布标题的链接（第二版预览里没有；接口照样带出发布信息）。
   - 接口出错时页面标题与“浏览矿业市场动态”照常，正文只有一句“价格数据暂时无法读取”（没有来源那几行、价格表、说明与官方查询入口，它们都来自接口；也不出现“暂无已授权价格数据”），页面回 HTTP 503（和 `loadOr404` 读不到接口时一样，搜索引擎不收录出错的页面）、不缓存（`no-store`）；正常时和现在一样 `public, max-age=0, s-maxage=300, stale-while-revalidate=600`。

## 输入输出与错误状态

- 输入：`GET /api/site/metal-prices`（TASK-0045）。输出：`/metals` 页面、`sitemap.xml` 里的 `/metals`。
- 错误与边界：接口回 503 或读不到 → 页面回 503、只有“价格数据暂时无法读取”、不缓存；某个来源“没有数据” → 它那一行写“暂无已授权价格数据”加官方查询入口，它的报价“暂缺”；某个来源陈旧 → 照常显示并标“数据已陈旧”，不隐藏（PG-11）；全都没有价格 → 不画表。
- 上线后发现显示错了：网站先回到上一个版本（发布的回滚规矩），修好后照常部署。
- 数据与事件所有权：页面只经 `@amp/api-client` 读接口；不写库、不发事件；读者请求不触发抓取（铁律 4）。
