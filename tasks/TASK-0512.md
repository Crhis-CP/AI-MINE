Owner 2026-11-04 定稿：五臂星系，浅色象牙底，金色由内到外 9 档渐变（DEC-78 补充）。

## 做了什么

- 定稿母版放到 `industry/brand/source/`：`app-icon.svg`（应用图标）、`mark.svg` / `mark-dark.svg`（浅色、深色页面用，只有核心颜色不同）、`mark-small.svg`（16–32px 专用，金色加深、实心核心）。
- `scripts/brand-icons.ts` 改为从母版生成 `industry/brand/{logo.svg, icon.png, icon-192.png, apple-icon.png, favicon.ico}`，不再用字体生成“矿”字；苹果图标铺象牙底 `#F6F0E3`，favicon 用小尺寸版。运行：`node scripts/brand-icons.ts`。
- `Logo.tsx` 的站名字标前加上星系标：以缓存的 SVG 文件引用（不内联路径），24px 以下用小尺寸版，其余按主题切换浅色、深色版。侧栏、手机页头、加载页、重大更新弹窗随之更新。
- README 四张截图用演示 API 重拍。

## 没做什么

- 没有改主题色（站名“矿策”仍用现有强调色），色彩令牌留给 R2。
- 没有改日报刊头、OG 图和海报；定制字标仍待 Owner 看对比图后决定。
