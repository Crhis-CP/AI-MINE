Owner 2026-11-04 定稿：五臂星系，浅色象牙底，金色由内到外 9 档渐变（DEC-78 补充）。

## 做了什么

- 定稿母版放到 `industry/brand/source/`：`app-icon.svg`（应用图标）、`mark.svg` / `mark-dark.svg`（浅色、深色页面用，只有核心颜色不同）、`mark-small.svg`（16–32px 专用，金色加深、实心核心）。
- `scripts/brand-icons.ts` 改为从母版生成 `industry/brand/{logo.svg, icon.png, icon-192.png, apple-icon.png, favicon.ico}`，不再用字体生成“矿”字；苹果图标铺象牙底 `#F6F0E3`，favicon 用小尺寸版。运行：`node scripts/brand-icons.ts`。
- 新增 `scripts/wordmark.ts`：把星系标和站名“AI矿策”组合成一个字标 `industry/brand/lockup{,-dark,-small}.svg`（Owner 2026-11-05：站名用金色渐变，标志不小于字）。
  - 字形转成路径，各系统显示一致：“矿策”用 Noto Sans SC Bold，“AI”用 Instrument Sans Bold，均为 OFL 字体。
  - 标志高度约为字高的 1.3 倍。浅色主题用渐变的深半段，深色主题用浅半段。
  - 运行：`node scripts/wordmark.ts <NotoSansSC-Bold.ttf> <InstrumentSans-Bold.ttf>`。
- `Logo.tsx` 改用这套字标，以缓存的 SVG 文件引用，不内联路径。
  - 24px 以下用小尺寸版，其余按主题切换浅色、深色版。
  - 字标整体比原来的文字字标略大。
  - 侧栏、手机页头、加载页、重大更新弹窗随之更新。
- 主题强调色从临时的灰蓝（T-0006 占位）改为标志的金色：浅色 `#8a5a17`（在纸色上 5.6:1），深色 `#e2b04f`（8.9:1）。
- README 四张截图用演示 API 重拍。

## 没做什么

- 正文字体和字号没有改，留给 R2 排版。
- 没有改日报刊头、OG 图和海报，海报里的强调色仍是旧的 `#475569`。这些留给 R2，届时一并把 `OG_TEMPLATE_VERSION` 加 1。
