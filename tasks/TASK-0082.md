本卡把商务预报加成一个登记的免费官方来源：铜、铝、锌各多一行“周”的国内报价，单位元/吨，注明“信息来源：商务预报”。改的是表的检查（加周度）、登记、一个新的抓取器；读取、接口、页面与契约不改（TASK-0045、TASK-0060 都按来源通用），规格由 TASK-0048 一次写全。本卡合并时还没有接口与页面，读者看不到；合并以后的下一次部署（当时问 Owner）起，正式库开始定时存商务预报的数。

许可调研的结论（2026-10-06，报告 `/mnt/project-files/research/metal-price-paid-daily-2026-10-06.md`）：

- 商务预报的数据中心有每周的全国价格：1# 铜、A00 铝、1# 锌，元/吨。2026-09-25 那一期是 111975、24340、26689。
- 数据页：铜 `https://cif.mofcom.gov.cn/cif/html/dataCenter2021/index.html?jgsczlzdjc_yousejinshu_224011`，铝把最后的数换成 224012，锌换成 224014。页面带 indexId（224011 等）请求 `/cif/getWeekLineChart2019.fhtml` 取数。这个主机上没有 robots.txt。
- 转载说明在商务预报网站的文章页上：注明“信息来源：商务预报”就可以转载。数据页上没有任何条款。本站使用的依据就是文章页的这一条；登记里的许可说明与夹具 README 照实这样写，不说成数据页许可了转载。
- 数据中心里的国际现货（铅、镍、伦敦金银等）来自商品价格网，它的 robots.txt 全站不许抓：不用，不在本卡。
- 回应的格式还没人见过，仓库里也没有原件。所以第一步是集成人安排录下三个回应作夹具（见“夹具怎么录”）；没有夹具不开工。
