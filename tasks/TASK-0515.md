Owner 2026-11-05：外壳改为方向 C（勘探图）的顶部导航；配色保持 R2；要适配 iPhone 和折叠屏、双屏设备。

## 做了什么

- **顶栏** `components/shell/SiteHeader.tsx`（桌面端，宽度 ≥961px），取代 180px 的左侧栏。
  - 从左到右依次是：字标、“内容”8 项横排（栏目和顺序不变）、“更多”菜单、搜索、深浅色切换。
  - “更多”菜单用原生 `<details>`，不运行脚本也能打开；在页面跳转、点击菜单外或按 Esc 时关闭，更新日志的未读红点也显示在“更多”上。
  - 背景是 7 条金色等高线，90 秒漂移一周；开启“减少动态效果”时静止。
  - 主导航带 `data-site-nav`，供测试定位。
- **桌面主区页脚** `SiteFooter.tsx`：字标、AI 辅助说明，以及关于、服务条款、隐私、更正与下架入口；配置了备案号才显示备案号，另有版权行。
- **外壳布局：**
  - 顶栏、主区、页脚共用一个居中的 `.site-frame`；
  - `--page-max-wide` 和 `--page-max-reading` 不再扣除侧栏宽度；
  - 手机端的左右边距会避开刘海和灵动岛（`safe-area-inset`）；
  - 跨两块屏幕显示时（双屏、折叠屏展开），主区只放在第一块屏幕上，避开中缝。
- **规格同步：**`docs/01-product/03-reader-pages.md` 中凡是讲“侧栏”的地方都改为“顶栏”和“更多”菜单，栏目与顺序不变。
- **测试同步：**`apps/web/tests/cache.test.ts` 里的导航断言改为按 `data-site-nav` 截取。
- **截图：**README 截图已重拍。

## 没做什么

- 页脚的“公开内容更新于”需要改契约，留到 R4。
- 手机外壳（顶部字标、底栏）没有变化。
- 报告页自己的期次侧栏没有变化。

## 验证

- `npm run typecheck` 通过；改动文件的 biome 检查通过。
- 用演示 API 和生产构建截图，13 个状态都没有横向溢出：
  - 桌面 1440 浅色、深色，以及“更多”菜单展开；
  - iPad 1024、820；
  - 折叠屏内屏 768、外屏 344；
  - iPhone 横屏 844×390；
  - iPhone 430、390、375；
  - 法规页和日报页。
