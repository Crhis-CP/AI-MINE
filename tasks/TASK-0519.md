方向 C 的报告和法规页（DEC-78）：报告刊头带品牌；法规页依次展示生命周期、关键信息和要点。

## 做了什么

- **报告刊头**（`features/report/ReportPaper.tsx`）：报名下方原来是大写的站名文字，改为金色字标，就像报纸印出版者。
- **法规生命周期**（`modules/policy/web/features/PolicyUI.tsx` 中的 `PolicyLifecycle`）：放在“法律状态与适用时间”一节的开头。
  - 依次是拟议、征求意见、已通过、已公布、施行，每个阶段用一个测量三角点表示，并在旁边标出废止状态。
  - 只标出记录中确认的当前阶段，不暗示前面的阶段都经历过，因为文件可能跳过征求意见。阶段未确认时一个点也不标。
  - 数据直接取 `legal_brief`（契约规定它逐项照抄法律状态，不从日期推断），证据仍在下方的表格里。

## 没做什么

- 报告的期号、报眼、日历都没有改。
- 法规页的要点对照版式没有改。
- 演示 API 没有报告和法规的详情数据，所以这两页没有截图。

## 验证

- `npm run typecheck` 通过，改动文件的 biome 检查通过。
- `npm run check` 中的网页测试用合成数据渲染了报告页和法规详情页。
