## 背景

INV-46 要求每个公开页面都显示备案号，检验层级是 L4，桌面和手机都要遍历（验收场景 T-130）。桌面上备案号在侧栏里；手机上侧栏不显示，只有“更多”页有，首页和文章页的底部都没有。

## 交付

- 手机上每个公开页面底部显示 ICP 备案号，链接工信部备案查询。
- 有公安联网备案号时，手机页脚显示备案号的文字和链接（全国互联网安全管理服务平台，INV-46）；公安备案图标三处一起由 TASK-0047 做，TASK-0047 合并前不填号（集成人 #151 评论 6007259471、6007293955）；没有就不显示，不写占位。
- 不显示互联网新闻信息服务许可证编号：个人备案拿不到这个许可证（#150 评论 6000757490 第 3 点）。
- “更多”页（`/more` 与 `/more/`）已有完整页脚，不重复。
- 桌面不变（仍在侧栏）。
- 随手输错的地址（没有对应页面的网址）落到公开布局的错误页：读者外壳里的“这里没有内容”和“回到精选 / 浏览全部动态”，状态码仍是 404，照上游；纯文字的 404 是 10 月 4 日拆分公开与私有构建时（#81）加的（集成人 #163 裁决第 3 条）。
- 测试：首页、全部动态、关于页、文章详情页各有一份手机页脚；错误页（文章不存在、随手输错的地址）是读者外壳里的 404，也有一份；`/more/` 301 到 `/more`，`/more` 没有手机页脚，备案号出现两次（侧栏和它自己的页脚）。
- 在 TASK-0033 实施 PR 合并后的 main 上做（两张卡都改 `apps/web/tests/cache.test.ts`）。

- 桌面侧栏和“更多”页的公安备案图标由 TASK-0047 做（三处共用一个组件），TASK-0047 合并前不填公安备案号（集成人 #151 评论 6007259471）。
