Owner 2026-11-13 定了法规页的新样子（解读和原文并排，点条款号原文跳到并高亮，TASK-0657），并要求（原文）：“规定了什么、涉及谁……公布实施，你都要考虑好后面算法怎么样。因为每天它的报道不一定都是一样的，你比如说过渡安排……有的没有……后面这个算法确实又要想好这个怎么去做……如果说能把这个算法全部连接好就很好了。”Owner 同日要求“每条新出或者即将出的”法规都要有这样的解读。这改变了 2026-11-07 的决定（TASK-0576：法规栏只收正式公布的文书，草案放在资讯里），由本卡记进决定台账。后端由实现线做，页面由 Claude 做，先做阿根廷和中国。

> 计划版（status: specified）：下面是实现 PR 要满足的要求，不是本计划 PR 的交付结果。

## 交付内容（做什么）

1. **收录**：法规栏在“已正式公布”之外加一类“即将出台”：官方发布的草案、征求意见稿和已提交立法机关的法案。仍然只收官方来源上的文书本身，不收关于它的新闻报道。TASK-0576 的判定增加一个结果“即将出台”，其余判定不变。
2. **字段**：从文书或官方通知原文里抽取意见征集的起止日期和提交渠道；抽不到的留空，不推算。
3. **页面**（Claude）：同一版式；生命周期横带停在“拟议”或“征求意见”；标题下显示“意见截止 某年某月某日”和官方提交页面的链接；截止日过后自动改为“意见征集已结束”。列表页可按“已公布 / 即将出台”筛选。
4. **同一地址延续**：草案之后正式公布的，沿用同一个法规条目，版本记录里保留草案版，可以和正式版对照。
5. **范围**：先开阿根廷（联邦和已接入的省）与中国；其他法域保持只收正式公布的。

- 截止日前后页面文字不同；没有截止日时不显示截止信息。
- 草案转正式后同一条目有两个版本，可对照。
- 阿根廷和中国以外的法域行为不变。
