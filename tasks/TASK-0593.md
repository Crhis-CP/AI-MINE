Owner 2026-11-08 要求页面打开和切换更快。优化前的线上基线：电脑打开首页约 1.8 秒，手机打开文章页约 2 秒，站内切换约 1 秒。

## 背景（为什么做）

第一次打开页面时，读者会下载一些用不到的东西。第一，所有页面共用的脚本里带着英文界面的整张词表（`phrases.ts`，约 80 KB，压缩后约 28 KB），中文页面也要下载。第二，浅色、深色、小尺寸三版网站标识每次都全部下载，实际只显示其中一版。第三，文章正文的图片在打开时全部下载。手机网速慢的时候，这些文件和页面脚本抢带宽，页面要等更久才能点击。

## 交付内容（做什么）

- `i18n/index.ts`、`entry.server.tsx`：英文词表改为只在英文页面使用时才下载。服务器启动时就把词表装好，所以两种语言的页面都照常直接渲染。浏览器打开英文页面，或在页面内从中文切到英文时，先取词表再显示，取到之前页面保持原样（React `use`），中文页面从不请求这份词表。`Phrase` 类型和 `tr()` 的写法都不变。
- `components/Logo.tsx`：三版标识改为 `loading="lazy"`，被主题或屏幕宽度隐藏的那版不再下载，显示的那版照常加载。
- `lib/body-images.ts`、`features/item/ArticleBody.tsx`：渲染文章正文时，第二张起的图片加上 `loading="lazy" decoding="async"`；第一张保持原样，因为它可能一打开就在屏幕上；正文里已经写明 `loading` 的图片不动。接口返回的正文不变。
- `docs/acceptance/speed-20261108/measure.mjs`：测速脚本，本地和线上用同一套方法。电脑 1440×900 不限速，手机模拟 iPhone 13 并限速到 1.6 Mbps / 750 kbps / 150 ms。测首页、全部动态、文章页、带 8 张图的文章，以及首页 → 全部动态、全部动态 → 文章两次站内切换，每项 5 次取中位数。指标包括 TTFB、FCP、LCP、可交互时间、JS/CSS/总传输字节和请求数。本地模式启动生产构建和演示接口，前面加一层 gzip，模拟 Caddy 的压缩。
- `docs/acceptance/speed-20261108/local-measurements.md`：前后对照表和每项改动的效果。手机上页面能点击的时间提前 0.26～0.32 秒，带图文章提前 0.5 秒（传输量从 671 KB 降到 466 KB）。共用脚本从 118.0 KB 降到 89.6 KB（压缩后）。FCP、LCP 和站内切换都在误差范围内，没有变化。
- 缓存头没有改：带哈希的静态文件本来就是一年且 `immutable`。字体没有改。没有引入动画库。

## 同类问题（举一反三）

- 模式：首次打开就下载当前页面用不到的资源，包括只给另一种语言用的词表、被样式隐藏的图片、屏幕外的图片。
- 怎么搜的：
  - 统计读者构建里共用脚本各模块的体积（构建时临时插件，不提交）；
  - `grep -rn "<img" apps/web/app modules/*/web`；
  - `grep -rn "dark:hidden\|hidden dark:block"`；
  - `grep -rn "dangerouslySetInnerHTML"`（覆盖读者页、法规阅读页、条款页）；
  - `grep -rn "PHRASES\|trFor"`。
- 一起改了：上面三处。
- 有意不改的同类及理由：
  - `en.ts`（英文界面字典，压缩后约 2.7 KB）仍然直接打包，因为分类名称等地方要同步读取它，收益小。
  - `BrandMark`、`OriginalPost`、`BeforeAfter` 的图片原本就是按需加载。
  - 法规阅读页和条款页的 HTML 里没有图片。
  - 分享海报是用户点了才生成的。

## 明确不做

- 不改接口、契约，也不改撤回检查（`ContentVersionGuard`）。第一次打开时的那次重读、103 Early Hints、brotli 预压缩、契约包按需引用、列表页预载文章脚本，这几项都列在验收记录的“还没做的较大改进”里，附估计收益，需另开卡或由 Codex 先在服务器上确认条件。
- 不把“按下才预取”改成悬停预取（TASK-0367 的规则）。
- 线上重测由 Codex 部署后用同一脚本执行（用法见验收记录文末），本卡只有本地数字。

## 验收要点（人读）

- [x] 中文页面的脚本里没有英文词表。英文页面直接打开、从中文页面切换过去，都显示英文，没有报错，也不会整页重新加载（`page-weight-browser.test.ts`）。
- [x] 浅色主题不下载深色标识，深色主题不下载浅色标识，显示的标识已经加载（同上）。

- [x] 页面、文字和排版不变：读者端、英文界面和全文相关的网页测试全部通过。
