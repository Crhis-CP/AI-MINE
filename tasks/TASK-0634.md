## 交付内容（做什么）

**1. 地址和范围**
- 新地址 `/country/:code`（英文界面 `/en/country/:code`），`code` 是两位大写国家代码。
- 只对 `HOME_COUNTRIES`（`apps/web/app/features/region/home-country.ts`，现为 CN、AR）开放；其他代码、小写、多余字符一律走通用 404 页。以后加国家只改这个名单。

**2. 页面由服务器渲染（搜索引擎要能读到内容），依次是：**
- 标题（H1）：“阿根廷矿业动态”。国名取自 `/api/site/jurisdictions` 的 label，英文界面用 `useRegionName`。
- 一行数字：“今天 N 条 · 近 7 天 N 条”，取自 `/api/site/news-map` 的 `1d`、`7d` 两个时段里该国的 count；某个时段读不到就不写那一段，不写 0 充数。
- **最新动态**：`/api/site/pool?jurisdiction=CODE&readingGroups=reports-v1` 第一页，用现有的 `DayList` 组件原样显示（与“全部矿业动态”页同一种卡片）。底部“更多 X 动态”链接到 `/all?jurisdiction=CODE`。
- **法规政策**：`/api/site/policies?jurisdiction=CODE&page_size=5` 的前 5 条，每条显示标题和现有法规列表卡片上的那一行状态信息，链接到 `/policies/:id`；底部“全部 X 法规”链接到 `/policies?jurisdiction=CODE`。该国 `policy_scope` 为 false 或一条都没有时，整段不显示。
- 页面右上角一个“换国家 / 地区”下拉（复用 TASK-0633 的同一份选项和文字），选了就跳到对应国家页并记住；选“全球”回首页。
- 三个接口里“最新动态”读失败 → 显示现有的“暂时不可用”空态；它为空 → 一行“X 近期没有收录动态”加“看全球精选”链接。其余两个接口失败只是少一段，不影响页面。

**3. 首页本国块的链接改指这里**：`HomeCountry.tsx` 里“看 X 全部动态”从 `/all?...` 改为 `/country/CODE`。

**4. 搜索引擎**
- 标题“阿根廷矿业动态”，描述“阿根廷矿业的最新公告、企业动态和法规政策，附中文导读和原文链接。”（英文界面给英文描述，用 `pageMeta` 的 `descriptionEn`）；canonical 自指。
- 两个国家页加入站点地图：生成处在 `packages/backend/src/publication/sitemap.ts`，照其中固定页面的写法加，并在它现有的测试 `tests/module-sitemap.test.ts` 里补断言。国家名单在后端另写一份常量并注明“与 `HOME_COUNTRIES` 保持一致”，不要让后端去引用网页端的文件。

**5. 文字**：中英文都进 `zh.ts`、`en.ts`，不写死在组件里。读者可见文字不出现“jurisdiction”“pool”“演示”这类内部词。

**6. 规格和更新说明**：`docs/01-product/03-reader-pages.md` 路由表加一行；`changes/` 片段一条（type: 更新，title 不超过 24 字，例如“每个国家有了自己的动态页”）；`industry/release-note.json` 同步。
