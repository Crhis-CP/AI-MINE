任务书 v2 工作流 2 第 3 条：开源后任何人都能部署，所以部署脚本里的域名和安装目录改为可配置，同时删掉代码注释里的个人名。

## 做法

- **路径与域名：**`/opt/aimine`、`/opt/aimine-backup`、`/opt/aimine-release-stage` 以及域名改为环境变量，例如 `AIMINE_ROOT`，默认值与现在逐字相同。
  - 变量写进 `.env.example` 的“部署”一节，并加注释。
  - 不改任何发布步骤的顺序和逻辑。
- **个人名：**在上面列出的源码文件里，注释中的个人名改为角色名，例如把“由 Chris 确认”改为“由 Owner 确认”。
  - 文档、决定记录、任务卡里的署名不改：它们属于历史记录，并且在上游名称检查的豁免路径内。
- **验证：**
  - `bash -n deploy/production-release.sh`；
  - 在 PR 里贴一段用默认值展开后的路径对照，证明与修改前逐字一致；
  - `npm run check`。

## 不做

- 不在生产上试运行修改后的脚本，留到下一次正式发布时按正常流程使用。
- 不改 Caddy 的路由规则，只改其中写死的域名（如果有）。
