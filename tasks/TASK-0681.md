## 明确不做（各有原因，留给后续卡）

- **pg-boss**（12.34.0 → 12.38.2）：队列有表版本围栏（`packages/backend/src/jobs/queue.ts:24` 的 `schema_mismatch`），小版本可能带队列表结构升级，要单独验证。
- **pdfjs-dist**（6.4.299 → 6.5.438）：会影响法规和金属 PDF 的文字提取，要用固定样本对比后再升。
- **@biomejs/biome**（2.5.15 → 2.6.7）：新规则可能产生大批格式和告警改动，单独做。
- **@playwright/test**（1.63.0 → 1.65.0）：要换浏览器包，单独做。
- **大版本**：postgres（3.4.9 → 4.1.1，4.0.0 是 10-29 才发的，事务句柄提交后再用会直接报错）、motion（13 → 14，属于改版区，随集成分支）、satori（0.33.5 → 0.63.2，0.x 的小版本按大版本对待）、opentype.js（1.3.4 → 2.0.0，只用于开发脚本）。
- **domhandler 不要单独升**：cheerio 1.2.0 要求 `^5.0.3`，单独升到 6 会出现两套类型。
- **@types/node 保持 24**：与运行时 Node 24 一致。
- `package.json` 里 `overrides.fflate` 保留：satori 最新版仍锁 fflate 0.7.3。
