Owner 2026-11-05：所有页面的交互按钮和布局都要重新设计，后端功能不变，举例点名了“主题”里的分类按钮。

## 做法

- **主题目录 `/topics`：**
  - 三组（国家与地区、金属、矿企）改为一个切换条，一次只看一组，组名后面带数量；分组写在地址里（`?g=`），不运行脚本也能用，返回时停在原组；
  - 卡片改为紧凑格：名称、近 30 天数量（大号数字）和一条按本组最大值换算的长短条，最活跃的主题一眼可见；鼠标悬停显示定义；
  - 法规入口改为一张卡片：“法律监管 / 按国家和经营主题查看官方法规”。
- **主题页 `/topics/<slug>`：**
  - “主题栏目”的三个文字链接改为“最新动态 / 精选”切换条，加一个“法规 →”按钮；
  - 搜索框、国家选择、来源矿种日期筛选收进一个面板；
  - “近 30 天 N 条”并入页头统计行，去掉单独的一行。
- **收藏页：**标题旁显示“已收藏 / 上限”；导入、导出改为按钮，放在标题右侧；空状态的“去看精选”改为主按钮；每条收藏的“移除”改为小按钮。
- **Agent 接入页：**MCP 工具清单由纯列表改为两列小卡片。
- **演示 API：**新增 `e2e/demo-topics.ts`，用真实主题表和合成数量提供 `/api/site/topics` 与主题页，供截图核对。

## 不做

- 不改接口和数据：主题、数量、筛选参数都沿用原有字段。

## 验证

- 网页类型检查通过；`topic-marks`、`topic-module-parts`、`cache` 三个测试文件 41 项通过。
- 用演示 API 截图核对桌面 1440 与手机 390：目录分组切换、长短条、主题页切换条和筛选面板显示正常。
