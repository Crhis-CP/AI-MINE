Owner 2026-11-08：“为什么我的这个在谷歌搜索上面，或者说百度搜索上面搜索不到……我希望就是全球的用户都能在那种搜索引擎上也能搜索到我这个呀。”

## 背景（为什么做）

线上核查（2026-11-08）：

- **正常的部分：**
  - robots.txt 允许抓取；站点地图有 2467 个地址；
  - 用 Googlebot、Baiduspider、bingbot 的身份访问都返回 200，页面在服务器端就已渲染好；
  - 文章页带结构化数据。
- **英文界面实际上对搜索引擎不可见：**
  - `root.tsx` 给所有英文页加了 `noindex`。当时的约定是“英文界面上线（I2）前不进搜索”，Owner 这次要求全球用户都能搜到，本卡解除这个限制；
  - 英文页的 `<title>` 和描述仍是中文；
  - 英文页的规范地址（canonical）指向中文页；
  - 页面之间没有 hreflang 互指；
  - 站点地图里一个英文地址都没有。
- **其他：**
  - 站点还没有在 Google Search Console、Bing、百度搜索资源平台登记；
  - 已有的 IndexNow 推送默认关闭（`INDEXNOW_SUBMIT_ENABLED=false`）。

## 交付内容（做什么）

- **`apps/web/app/lib/seo.ts` 的 `pageMeta` 按页面语言输出：**
  - 英文页的规范地址就是它自己的 `/en` 地址；
  - 标题逐段用短语库翻译，带日期的页名也翻译（“矿业日报 2026-11-06” → 英文页名加日期）；没有专门描述的英文页用新增的英文站点描述；
  - `og:locale` 为 `en_US`，并给出另一种语言作为 `og:locale:alternate`。
  - 可以收录的页面互相标注 `hreflang`：`zh-CN`、`en`，`x-default` 指向中文。
  - 不收录的页面（未标记收录的文章、搜索结果、收藏、反馈等）仍然是 noindex，不加互指。
- **meta 函数拿不到请求，所以用请求路径判断语言：**
  - `apps/web/server.ts` 在渲染页面时用 `AsyncLocalStorage` 记住当前请求的路径；
  - `requestLocale()` 在服务器端读这个路径，在浏览器里读地址栏。
- **`apps/web/app/root.tsx`：**
  - 去掉英文页统一的 noindex；
  - 首页（`/`、`/en`）在设置了 `GOOGLE_SITE_VERIFICATION`、`BING_SITE_VERIFICATION`（输出为 `msvalidate.01`）、`BAIDU_SITE_VERIFICATION` 时，输出对应的站长平台验证 meta；值只允许字母、数字和 `_.-`。
- **站点地图（`publication/sitemap.ts`）：**
  - 每个读者页面列出中、英两个地址，每个地址都用 `xhtml:link` 标出两种语言和默认语言（Google 的站点地图 hreflang 格式）；
  - feed、接口、图片等只有一个地址的不翻倍；
  - 超过 45,000 个地址照旧自动拆分成多个文件。
- **IndexNow（`operations/indexnow.ts`）：**每个地址同时推送中、英两个版本；默认仍关闭。
- **配置：**`runtime-env.ts` 允许 web 读取三个验证码变量；`docker-compose.yml` 的 web 服务传入这三个变量（空值即不显示）；`.env.example` 用中文写明怎么填。

## 没做什么（只能由 Owner 或 Codex 做）

1. **Google Search Console**（https://search.google.com/search-console）：
   - 添加“网址前缀”资源 `https://aiminingpolicy.com/`，验证方式选“HTML 标记”；
   - 把 `content` 里的那串字符填进生产 `.env` 的 `GOOGLE_SITE_VERIFICATION`，重建 web 后点“验证”；
   - 在“站点地图”里提交 `https://aiminingpolicy.com/sitemap.xml`；
   - 用“网址检查”对首页和 `/en` 各请求一次编入索引。
2. **Bing Webmaster Tools**（https://www.bing.com/webmasters）：
   - 可以直接从 Google Search Console 导入；或者选“HTML Meta 标记”，把值填进 `BING_SITE_VERIFICATION`；
   - 提交站点地图；
   - 在后台生成 IndexNow 密钥，填进 `INDEXNOW_KEY`，再设 `INDEXNOW_SUBMIT_ENABLED=true`（这个开关已有，本卡没改它）。
3. **百度搜索资源平台**（https://ziyuan.baidu.com）：
   - 添加网站（需要百度账号，网站已备案），验证方式选“HTML 标签验证”，把值填进 `BAIDU_SITE_VERIFICATION`；
   - 在“普通收录”里提交站点地图。
4. **预计时间：**
   - Google：登记并提交站点地图后，几天到几周开始出现；
   - Bing：类似；IndexNow 开启后新内容会更快被发现；
   - 百度：新站一般要几周到几个月。百度的“API 主动推送”可以加快，本卡没有实现，另开卡（需要百度后台给的推送令牌，属于凭据）。
5. **以后再做：**
   - 文章页英文版的标题和描述仍是中文 AI 导读，界面已经是英文。要让英文搜索能按内容命中，需要英文标题和摘要；这需要模型生成，有费用，单独评估；
   - 未标记收录的文章默认 noindex（现有设计：精选自动收录），是否放宽是另一项决定。
