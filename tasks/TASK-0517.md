Owner 2026-11-05：资讯地图要随每天的资讯变化，不能总是累计总数里那几个国家；点一个国家，下方列表自动只看该国。

## 做了什么

- **后端：**
  - `currentNewsJurisdictionCounts(range?)`（`publication/items.ts`）新增可选的时间范围，按归档时间 `timeline_at` 计数。国家归属、可见性规则与原来的计数完全相同，SQL 仍在 publication 模块内。
  - `site/stats.ts` 新增 `loadNewsMap(window)`：返回最近 1 天、7 天或 30 天的各国计数，并附上前一个同长时段的计数，用于判断增长；每个时段缓存 60 秒。
- **接口：**新增 `GET /api/site/news-map?window=1d|7d|30d`，默认 7 天，其他取值返回 400。
  - 契约是 `SiteNewsMap` 和 `NewsMapWindow`，只增不改。
  - OpenAPI 已重新生成。
  - `contract-tests` 和 `public-role-routes` 已登记这个接口。
- **读者端地图** `WorldMap.tsx`：
  - 可在今天、7 天、30 天之间切换，圆点大小按该时段的资讯数。
  - 摘要行显示“近 7 天 · N 个国家 · N 条 · 增加最多：某国”。
  - 资讯数比前一时段多 2 条以上、且至少是前一时段的 1.5 倍，就在国名后加 ↑。
  - 点击圆点后原地筛选下方列表，页面不跳回顶部；再点一次同一个国家即取消。
  - 地图下方显示“下方只看：某国（近 7 天 N 条）· 取消”。
- **测试：**`tests/news-geography.test.ts` 新增一项：资讯在时段内计入当前计数，过期后转入前一时段计数；不合法的时段返回 400。
- **演示数据：**`e2e/demo-reader.ts` 和 `demo-api.ts` 加入按时段的合成数据。

## 没做什么

- 列表本身仍显示该国的全部资讯，时段只用于地图统计。“按国家分组”的列表视图没有做。
- 手机端不显示地图，国家筛选照旧。

- `npm test -- tests/news-geography.test.ts tests/public-role-routes.test.ts`：13 项和 4 项全部通过（本地 PostgreSQL 16 隔离测试库）。
- 用演示 API 和生产构建截图，人工查看：
  - 7 天视图；
  - 30 天深色视图；
  - 选中智利后的视图；
  - 其余 13 个设备状态，均无横向溢出。
