## 公开入口

通过 `@amp/backend/db` 使用原生 `sql`、`identitySql`、`feedbackSql` 和显式事务。身份查询与公开反馈分别使用专用连接；其余业务使用sql。三个导入均为随组合根初始化更新的ES绑定，不是查询代理。

应用/CLI入口先 `await initializeDb(processRole)`，退出时 `await closeDb()`。import不会创建连接，web不持有数据库；相同URL共用连接池，公开读取、反馈写入、账号和运维的实际角色由配置选择。相同角色和同一env引用允许重入，不同根须先关闭；并发关闭共享一次清理。工作进程先结束消费和在途工作，再关闭数据库。

- 不在模块加载时保存驱动或创建待执行查询；字段、联接等片段用函数在查询时生成。
- `sql.begin`和事务内`savepoint`使用postgres原生对象；所有应原子提交的写入使用同一个tx。
- 关闭后旧待执行查询留在已关闭的驱动，不转发到新根；重开后重新创建查询。取消、游标和保留连接遵循驱动自身接口，不再包一层通用代理。
- 真实表权限继续由数据库角色控制；静态文件归属登记只用于检查跨表写入，不能授予权限。保留的UNKNOWN位置仍是未静态证明，不当成安全或完整验收。

内容处理通过现有 `@amp/backend/content/materials` 入口的 `commitProcessingResult` 提交结果：content 开启事务并锁定材料修订，调用方在传入的同一个 tx 中写本模块结果和完成回执，content 最后更新当前修订的处理状态。过期修订仍保留结果与回执，但不覆盖新材料状态；回调或状态更新失败会一起回滚。

```ts
import { initializeDb, sql, closeDb } from "@amp/backend/db";
await initializeDb("worker");
try {
  const columns = () => sql`42 AS answer`;
  const rows = await sql`SELECT ${columns()}`;
} finally {
  await closeDb();
}
```

withCustomPlans在直接连接的事务中设置计划策略，搜索不会继承其他请求的设置。历史注入阶段的机械改写和输入指纹仍保留于scripts/db-injection，仅用于核对历史记录，不再运行它重建已删除的代理。

队列接口经 `@amp/backend/jobs/queue` 使用，getBoss返回原生pg-boss实例，方法、事务和监听器遵循驱动自身语义，不再包通用Proxy。组合根必须先stopBoss、后closeDb；队列正常drain期间仍允许在途handler结算并排入后续任务。ensure/enqueue保留所属根检查，旧异步结果不能写入新实例缓存；私有生产者不创建schema/队列，分区变动时只替换客户端、不自动重发未知请求。临时启动失败不永久缓存被拒绝的Promise。


翻译的逐段存储准备由enrichment独占：`translation_segments` 区分材料修订、配方、原文hash和段序号，原始模型text与恢复后HTML分别留hash；公开读取不读该明细表。`translations` 新增的recipe/source_hash/manifest保持旧记录为null，不补造完整度或回执依据。严格逐段调用、事务写回与首次公开门已接入实际worker，实际模型语义质量仍需真实样本验收。

TASK-0021生命周期前置：initializeDb返回本根AbortSignal；同role与同env引用重入复用，不同声明仍须先关闭。closeProcessDb先登记共享关闭Promise，再撤销注册和signal，监听器同步重入不能打开新根或使用旧能力；新根独立，未改队列正常drain的时点。signal不包含控制器、连接或URL；生命周期本身不代表许可存储或网关强制已激活。

未激活的sources/permissions与providers/permissions提供显式Ed25519签发/校验工厂：私钥只在sources闭包，验证端固定公钥/issuer/root。当前许可查询、可信完整输入重建、根signal与时钟必须由组合根提供，无默认allow。现有应用尚未调用工厂；合成端口测试不是数据库权限接线，模型/cache/写回仍待原子接通。

### content/source-time（TASK-0022）

共享纯规范化函数 `normalizeSourceTime` 位于 `@amp/contracts/time-assertion`，不猜格式、时区或来源事实；content 的 `sourceDateVerdict(lane, evidence, currentBinding, now)` 显式接收时钟与当前身份，返回日期的 reliable/pending，policy 则仅返回 not_applicable 并交 BR-POL-11。复用 `@amp/contracts/time` 的日历与北京日函数；只有新闻发布依据能通过，官方登记/正式刊发须使用相应证据口径，系统/更新/生效日期不能顶替。这是日期判定，不是总体公开资格；纯函数不访问数据库、网络或模型，当前已供材料日期写回使用，publication 和 HTTP 尚未接入日期门。

来源日期取得/保存通过既有 `@amp/backend/admin/sources` 的当前来源快照、配置锁、用途判定和纯日期 parser 端口衔接；不增加 backend 子路径白名单。`content/materials` 的实际写回先锁当前许可版本，再锁相关来源配置和材料，保存不可变原始观察及多候选依据；迟到观察不提升当前版本，不把它重绑到不存在的新修订。相同事实的重复采集不刷新当前证据版本，也不重新排分析；需要更新投影的元数据变化单独走重新发布队列。公众号观察引用实际取得回执，关闭的外部上报入口不能凭传入 Date 建立来源日期证据。

2026-10-21日期复核补强：网页列表没有配置日期字段时，空列表观察不能覆盖同来源、同材料修订和当前配置下仍可靠的日期证据；原始空观察与最近看到时间仍保留。明确新日期、已配置字段的失效、冲突以及绑定变化继续按既有判定处理，人工日期更正和撤回优先。已误覆盖的弱缺失可在后续自然列表提交时复用同绑定最新非弱可靠证据；明确缺失/冲突阻止恢复，退出列表不保证触发。

这一步仅接通取得和材料保存；公共 TimeAssertion、统一新闻日期门与自动补取在后续能力联合启用。现有 fetch/store_metadata/process_locally 判定是该次日期取得/写回的边界，不代表全链 ProcessingPermit/所有付费 provider 强制已经完成。




lockCurrentSourcePolicies在调用方的事务中按source_id顺序取得共享咨询锁并核对版本，编辑使用同key独占锁；锁持有至事务结束。围栏仅接受READ COMMITTED，明确拒绝可能在等待后继续看旧快照的其他隔离级别。正式消费者必须先锁全部许可、再锁材料，并在锁内校验实际用途/资源后写回；该端口只保证版本围栏，不能代替ProcessingPermit或范围判定。当前函数尚未接入模型/内容消费者，不声称已实现完整网关强制。


`readCurrentBody` / `commitBodyResult`是content的正文派生窄端口：读取正文身份，写回时锁定相同revision与HTML；不改变分析状态、错误、次数或重试时间。显式`runBodyTranslation`由已核验准入、来源许可和外文条件的worker调用，网络在事务外，检查点与实际attempt的完成/标坏同事务提交，完整manifest另行晋升。旧revision/recipe迟到停止后续片段；旧attempt不能覆盖新attempt或被当作正常结果交给旧调用者。

Gateway保存每个实际attempt的原响应/用量/成本，receipts只在CAS当前尝试时更新response_attempt_id；缓存沿该指针核验所属回执、尝试与原响应，不猜MAX或给历史记录补造身份。新翻译显式启用同一调用键最多3次坏输出限制，claim前检查，重复结算不重复计数；旧能力默认不启用这个限制。缺usage的坏响应仍received，unknown不重发，明确截断不晋升；stop或空finishReason也须严格text与结构检查。不能证明历史缓存的attempt时保持私有待处理，不重新购买。当前严格text消费者复用这些身份；网关强制ProcessingPermit仍由Task21完成。

### 静态列表与监管披露

`json_list` 的 HTML 属性/窗口变量列表可显式配置 `literalFormat: "static"`，解析单引号、裸键与尾逗号组成的数据字面量；只接受有界数据，不执行表达式、函数或脚本。默认仍是严格 JSON。

列式披露配置使用 `itemsShape: "columns"`，所有列必须等长，按同行配对标题、日期与文件。`includeValues: {path, values}` 限定需要的文书类型；`titleTemplate` 可使用 `{raw:字段}` 组合原始字段。URL 中 `{compact:字段}` 仅接受数字和连字符，并去掉连字符，适用于已核实规则的公告编号；它不证明生成的地址可访问，真实预览仍需检查。列长度异常会失败，不错配下一行日期。

无时区的发布时间只有在 `sourceDate.timezone` 与真实 `timezoneEvidence` 已配置时才转成确定时刻；只有日期的来源保持日期精度。缺少时区不会按服务器所在地补造。


列表的首次历史导入有数量与时间范围限制；后续当前窗口不再按前60条截断后保存RSS校验器。已收录资料继续接收更正，首次接入窗口以外的新历史条目不在普通轮询中无限导入。

详情字段采用按来源身份保存的成功检查点：失败与单轮额度不足会在后续轮询补齐，待补详情存在时不接受RSS的304跳过整份列表。规则变化重新检查；相同规则每天有界复查一次。详情HTTP失败不能记作成功检查点；仅日期、标题或摘要未匹配的成功页面则保留诚实缺项。采集暂停、权限变化和配置变化的原有检查继续执行。


### 结果与费用分别核对

真实响应已收到且绑定当前物理尝试时，缺少 token 用量只留下费用缺项，不阻断资讯或法规后续处理。响应、材料修订、输入清单、模型身份及完整性仍逐项验证；坏输出重试和法规每部分上限按真实尝试计数，不能靠省略用量绕开。

未知结果自动放行后，翻译定向进入原修订的翻译队列。原段恢复成功并由后继物理响应验证后，可继续下一段；原未知尝试、费用和观察记录不清零。旧整篇次数保留，入口与定时补排共用恢复证明判断；冷却等待不累加失败次数，明确的处理边界保留部分译文，不反复购买。

自动放行与人工核对使用同一原任务续接入口：归组和翻译恢复不重走评分；当前材料修订不匹配的旧回执不安排新任务。人工确认未计费的翻译恢复保留原尝试次数，并允许从实际完成段落继续。事件队列名称独立定义，恢复管理不加载事件执行器，避免跨进程入口的循环依赖。

结构化结果区分 single/composite/unknown；旧结果缺失范围时保持 unknown，不据缺字段推定单一事件。明确综合稿的fact为空，归组只记录对可信候选的mention，不创建自身事实或热点信号；从旧事实移出后保留旧地址和人工标题，清除无有效报道事件的过期自动综述。

### 模型自行配置与切换

用户可在后台添加兼容接口及模型版本，完成连接测试后按处理环节直接选择。对比评测可附在切换记录中，但不再是普通指派的强制前置；这不改变独立确认的矿业评分标准。旧切换入口会推进共享修订号，登记模型入口拒绝陈旧版本，避免其旧表单覆盖较新的选择。文字环节接受同时支持图片的模型，视觉环节仍要求图像能力。

名称或价格等非运行参数修改保留已有连接证明；密钥和实际运行配置变更仍须重新测试，旧结果/账目不重算。修改使用中的运行配置前可复制配置、测试新接入后切换，原接入继续可用。表单不回显密钥，读取接口只返回安全元数据。

正式发布在模型写入方停止后准备加密主密钥，仅在不存在旧加密接入时生成；已经存在的有效密钥原样保留，缺失或冲突的旧密钥拒绝自动替换。回退环境同时保留解密能力，并另外保存修改前的环境备份。该步骤只在最终发布执行，本地验证不接触生产秘密。


评分输入在正文空白或只有标点时使用有效摘要。来源分级变更沿既有重投入口，对时间线最近7天且记录门槛已变化的条目复用保存的两次合法评分；采用当前已确认门槛，人工精选选择优先，不修改原分析或付费回执。缺少旧门槛记录时保留原判断，不从显示分推断；已重算提名离开时间窗后保持，不因改回原分级复活。新获提名的历史稿若旧归组仅做日期归档，先转为待归组并由现有补排恢复，正式覆盖比较完成后才可占精选席位。

归组与精选确认：`events/group` 同时记录关系、材料/分析输入证据和新增信息判断，`publication/publish` 仅接受当前修订的明确确认；已打分候选继续作为普通动态等待，时间经过不构成确认。公告及配套解读即使另一天发布，解释同一已发布文本的既定分类、数量或安排仍属同一次发生；后发、篇幅更长或摘要省略细节本身不是新进展，须有可核对的独立新行动或结果。综合稿只能提及事件，旧缺失范围需明确补判。国家标签、对象别名及阶段标签不替代原文关系判断。

历史稿中的当前精选提名也与已公开内容比较覆盖范围，复用正式的身份和增量判断。确认重复后保留原日期和普通阅读入口；有新增覆盖的历史稿仍按旧时间归档。这条路径不创建事实、发展线或热度信号，通知仍受历史稿门槛约束。完成记录保存当前配方，避免无回执的正常历史结果反复补排。

`events/recovery` 经既有事件入口提供持久分批补排，领取和队列写入同一事务，等待时间存于 content；每两分钟调度，普通待处理补排单批默认50条、上限100条。其中，最近14天发现、当前修订已完成的旧配方 SAME_STORY 分裂席位，以及尚未比较覆盖的旧 historical 无回执独立席位，合计每轮最多重审5篇，并占用同一批次额度；只读当前公开席位和必要身份，正式消费者决定结果。停用来源、人工归属、独立决定、撤回、暂停、有效队列和未知回执保持原限制，旧评分、回执、尝试和费用保留。修订、分析及显式归组请求的输入变化会拒绝旧回答；已有相同输入回执仍复用，不重新评分。

事件召回先核对当前材料修订、自动归属确认、综述范围和明确撤回，再取前10个事实；代表稿、根事实、同URL候选及落库校验沿用同一资格。单篇向量缓存随 publication revision 重新读取公开标题和摘要，文本哈希未变时复用原向量与回执，避免纯元数据变化重复购买；材料修订仍由独立的归属与输入围栏核对。


精选出口：发布事务同时结算同事实的唯一seat及selected_state/selected_ledger；代表稿替换、撤回、恢复和人工独立都重新选择受影响的旧、新事实。API/RSS精选与推送使用seat，网站保留完整报道组。代表稿优先级由发布端读取来源身份计算，落入publications.representative_priority；公开读者不读取私有来源配置。旧数据默认3（未证明更高优先级），由重建投影补齐。

日期恢复共用content/timeline的首次发现规则：未知时间自动归档，真实日期补齐后重新判断新旧，明确导入原因保留。日期精度保存内部日历锚点，TimeAssertion.utc仍为空；返回的backfill与实际落库同步。等价日期写法只改变证据，时间事实变化才清空自动归组确认。归组候选和写回均检查当前确认状态，待重新确认的首选稿不会挡住同事实其他有效成员。公开日期精度的消费与投影仍须统一接线验收。

### 当前报告编排（统一升级）

`reports/edition`只读取publication的公开候选和当前归组身份，按事件编排日报；七日记忆包括相关报道和快讯。事件模块通过内容修订、来源当前角色、人工排除和公开撤回端口核对参与证据。日报及日报更正为规则处理，不调用模型；周月报使用已刊日报主条目，`period-writing`只生成总述及栏目导读，引用和排序由程序确定。读者层逐一核对相关报道可读性，内部恢复结构不出现在公开DTO。

无筛选全部动态的网页、API/MCP及RSS使用同一事实成员、代表优先级及事实最早锚点；具体检索仍返回匹配材料。新API游标绑定facts-v1投影。暂停业务线在unknown恢复候选筛选前排除，领取仍复核控制，未知原费用不改变。审计读取与人工未计费解除由身份模块在当前权限围栏内检查；后台不开放全部/分类批量重放。

独立正文链接卡片在分析输入中排除：只识别figure内仅含一个无cite的blockquote，且其中仅一个HTTP文章链接、没有其他正文的结构；普通引文、内文链接、图注和表格保留。原始正文/完整译文不改写，读者仍可追溯引用链接。合格中文摘要不再经机械长度截句删掉后文；短摘要由原写作要求约束，保留已有回答中的条件及否定。完整模型结果保留仍不等于已证明未来每条模型输出正确。

已批准备用流程的可用性冷却以服务+实际模型配置指纹隔离，不把一个模型的连续故障扩散到同服务的其他模型；服务请求次数仍共用预算。原10次/5分钟及独占恢复探针不变，旧服务键记录保留，当前无备用配置时不启动该健康追踪。

正文清洗保留且规范化blockquote的安全HTTP(S)引用出处，恶意协议继续移除；分析输入用此语义保护真实引文，原始保存材料不因相关阅读识别被改写。

含CDATA声明的外部正文先按浏览器HTML语义规范化，再应用原有允许列表，避免解析器分歧把noscript内的隐藏内容变成可见链接；正常字面文本、表格和引用保持。资讯与法规清洗入口都执行该边界，不扩大允许标签或来源权限。

公开MCP逐请求建立独立server/transport，在Fastify解析层与SDK同时限制256KiB，工具参数最多16个元素（当前最大合法输入9个平面字段）；私有运维MCP保持64KiB、最多8个元素（合法输入3个字段）。其他上传入口的容量与Owner/CSRF要求保持原样。

分析与国家投影共用纯正文识别规则。旧地理证明只有原材料绑定仍一致、引文仍位于当前正文时才能沿用；相关阅读中的地点不因历史证明被重新接受，人工地理覆盖仍按原始材料核验。
