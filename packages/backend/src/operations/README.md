# 运维读取与固定采样

未知回执日报按 `receipts.attempts` 区分仅尝试一次与已尝试多次；尝试次数不证明自动重试，也不证明是否计费。日报提示未知结果可能阻塞对应的新内容处理，不再统一声称不影响读者或无需处理。人工放行仍要求供应商确认最新尝试未计费，未知费用继续保留；自动恢复规则见 DEC-70 / ADR-0028。

信源周报压缩错误文本使用 PostgreSQL 的 `[[:space:]]` 字符类，保留英文单词和错误原因；最多显示160字符。日期许可拒绝同时记录用途、判定原因和文书域名，方便区分资源范围不匹配与用途禁止，不输出查询参数。

TASK-0323的`scripts/source-health-repair.ts`仅用于已核实的三处官方文书域名，默认展示计划，显式`--apply`才通过来源模块的版本围栏与审计写入。新证据限定文书路径和fetch/store_metadata/process_locally，不改变既有deny/unknown、全文、外部模型和公开用途。旧权限版本永久保留；目标已登记或来源受限时停止，避免重复或覆盖人工变更。

`operations/reports`沿既有出口提供`refreshOperationalSnapshots`和`readOperationalSnapshot`。worker每两分钟顺序读取各模块自有的固定聚合端口，单查询2秒上限；数据经严格的`@amp/contracts/ops-mcp`结构验证后写入ops.operational_snapshots。原始错误不写入快照，采样失败保留最后成功时间并标明失败时间；超过5分钟的样本显示陈旧。

private-api的`POST /mcp-ops`只接受当前具名Owner与既有CSRF，提供`read_operations`一个工具和固定13数据集，每次最多100行。服务最多2个并发读取，每位Owner每分钟30次；不接受订阅、任意查询、任务或命令。专用ops_read仅SELECT快照；缺专用地址不退回private_ops。身份与调用审计仍由auth承担，当前Owner能力锁持有到读取与审计完成；角色被撤销即拒绝后续读取。

数据集包括心跳/备份记录时刻、任务运行、来源、材料处理、采集、月内实际回执汇总、费用预警与熔断、发布投影、脱敏审计动作、账号汇总、反馈汇总、评测数量和队列汇总。返回均带采样时刻、覆盖与排除说明，不能把采样成功解释成服务健康、法规质量合格或全来源完整覆盖。原始正文、提示词、任务载荷、错误原文、密钥、个人信息和审计前后值均不进入投影。

Web入口在所有主机名上拒绝/mcp-ops，public-api不注册它；不会新增公网入口或日常运营总览页面。部署时仅为private-api配置独立只读地址，凭据不进入仓库或聊天；Owner通过私网与现有具名登录通道使用。本次开发未创建真实服务账号或生产连接。

## 读者反馈投递

`operations/feedback`的`submitFeedback`只收件并在同一事务写入pending标记；`forwardPendingFeedback`供worker每分钟调用。仅worker设置`FEISHU_FEEDBACK_ENABLED=true`及专用`FEISHU_INTERNAL_CHAT_ID`后发送，沿用消息应用凭据，不回落到告警群。历史反馈不补发；并发领取、截图上传结果和飞书消息编号均持久保存。明确失败五分钟后重试，发送结果未知或进程中断后保留unknown供核对，禁止盲目重发。后台截图与处理记录保留；删除与发送用行锁排序，删除后不再投递。本站180天留存不自动撤回飞书副本，隐私说明明确由负责人处理副本。

未确认送达的反馈向现有运行提醒群发一次数量提醒，不包含正文、联系方式、截图或相关页面；提醒成功后持久标记，重试期间不反复提醒。同一群同时被配置为反馈和告警目标时，不发此异常提醒。
