# 站点配置

`site.ts`保存品牌、读者文案和北京时间出刊配置；`models.ts`保存可选环境模型预设及默认映射。默认映射保持为空，后台选择和环境变量优先，预设声明不代表已接通或启用供应商。实际密钥只通过部署配置或后台受保护的录入流程保存。

`industry/site`保留兼容转发，现有页面、接口、脚本与旧链接继续使用同一份对象。行业分类、实体、提示词和信源仍在`industry`。modules/index.ts声明已安装扩展，modules/server.ts提供API和worker启动时安装的服务端清单。当前已接入金属价格定时任务；页面、API与其余矿业实现归属继续迁移。站点配置不承担后台鉴权或内容许可判定。

工作区变化只同步锁文件中的本地链接。外部包解析和快照保持原样，生产安装仍使用冻结锁。发布程序备份会在目录存在时包含`site`和`modules`，同时兼容此前没有这些目录的版本。
